## 4. 纪律（不变的那几条 + 本轮新增）

- 真实配置根 `~/.purescience-project` **只读**；一切写入落 `/tmp` 的隔离根；收尾停进程、确认端口无监听、删临时目录、
  `git status` 干净。
- **缺失的测量不许当测量**：拿不到就写 `not reported` / 「未复核」，**绝不写 0、绝不编**。
- 单测不算实机；能取真机读数就取，取不到就**具名立案**。
- 禁用死的/无消费者的代码；「有代码没入口」由 `renderer-contract-entry-coverage.test.ts` 挡。
- **门禁一律按退出码判，且必须跑仓库级 `npm run lint`**（只跑改动文件证明不了全仓；CI 的 `Verify` 吃全仓）。
  `tsc … | tail -3` 的退出码是 `tail` 的 ⇒ 前面加 `set -o pipefail`。
- **版本一 bump 就冲掉 eslint 缓存**：全仓 lint 的时机放在 bump 之后、打 tag 之前；从未碰过的文件里冒出错误时，
  先怀疑缓存（`git log --oneline -1 -- <file>`），再怀疑自己的 diff。
- 提交信息用文件（`git commit -F`），不用 `-m` + 反引号（会被 shell 替换）。
- **本仓品牌/借用术语扫描的正本是 `scripts/brand-patterns.sh`** —— 词表**只存在于那个脚本里**，任何文档都不要抄写它
  （抄写本身就会命中）。被跟踪文件里出现禁用词即被 **pre-push 钩子拒绝**（`HUSKY=0` **不跳过**）；
  需要判断某个词是否禁用时，去读那个脚本，不要在聊天或文档里复述词表。
- 拍板表与验收清单**同时贴在会话内**（不只写进档）。
