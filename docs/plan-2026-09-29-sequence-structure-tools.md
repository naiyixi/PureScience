# 序列与结构工具补件 — 切片计划

来源：对标代码级审计 `reference #6`（一批小件，组学工具箱面）。**本文件不出现任何对标产品名。**

我方现状锚点：连接器描述符目录 `src/main/connectors/descriptors/`（已有 `genes-enrichr`、`genes-gprofiler`、`omics-ena`、
`genes-proteins`(UniProt)、`structures-*`、`genomes-ncbi/ucsc/ensembl`、`protein-annotation`）；
引擎在 `src/main/connectors/engine.ts`（单请求 30s / 整调用 120s / 响应 64MiB / 重试 2 次 / 退避 400ms，
并从错误与日志剥离 email 与 api_key）；缺 **BLAST / Clustal / HMMER / InterProScan / Zenodo / GDC / ClinPGx / 富集统计**。

## 1. 差异化红线（交付判据，逐条可核验）

1. **异步作业类一律两段式**：提交调用 **`retry:false`**（绝不重放，避免重复建作业）；轮询与取结果**可重试**。
2. **结果落产物并带 provenance**：连接器 id + 查询参数 + 响应指纹（sha256），可在产物面板追溯到「这份结果由哪次调用产生」。
3. **批量映射必须显式回报未命中**：清单 + 计数，绝不静默丢弃（UniProt 10 万级标识符映射尤其如此）。
4. **只读作业类不建/不取消作业**：InterProScan 只读作业状态与 TSV 结果，**不与用户自助提交的作业冲突**。
5. **失败具名**：远端拒绝、超时、作业失败、结果为空、响应过大 —— 各自具名错误，不糊成一句「失败了」。

## 3. 通用实现要求

- 描述符写法照目录内同类（`descriptors/*.ts` + 同名 `.test.ts`），登记进连接器目录与计数门禁。
- 所有新工具必须有：输入校验（标识符/序列格式）、超时与响应上限、错误剥离 email/api_key、具名失败。
- 结果产物走既有产物设施（不新造存储），provenance 指纹用既有 `provenance-repository`。
- 文档：每个工具写清「提交/轮询/取结果」三段与限流假设；不承诺未验证的能力。
