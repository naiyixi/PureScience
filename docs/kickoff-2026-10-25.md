## 1. 硬规矩（违反会浪费整轮）

- 提交：`git -c core.hooksPath=/dev/null commit -F <消息文件>` —— **消息里有反引号时必须写进文件**，
  直接用 `-m "…\`xxx\`…"` 会被 bash 当命令替换吞掉（本轮真踩过，提交正文变成空白）。
- 推送前：`bash scripts/pre-push-checks.sh`。
- 四样齐了才提交：`npx prettier --write <files>`；`npx eslint --cache=false <files>`；
  `NODE_OPTIONS=--max-old-space-size=8192 npm run typecheck`（node+web 必须都过）；改动域 `npx vitest run <dir>`。
- `npm run build` 与 `bash scripts/publish-release.sh` **必须带 `NODE_OPTIONS=--max-old-space-size=8192`**，否则 tsc OOM。
- 共享树 Prisma client 过期会让双 typecheck 红在 `citedAt`/`citedSessionId`：先 `npx prisma generate`。
- 判 CI 必须用**完整 40 位 SHA**：`gh api "repos/naiyixi/PureScience/actions/runs?head_sha=$(git rev-parse HEAD)"`。
  `cancelled` 不等于绿。有 Release 页的 tag 不要删重打；**不要单独重跑 publish job**（同名产物冲突）。
- 纯文档提交（`docs/**`、`**/*.md`）在 CI 的 `paths-ignore` 内，不触发 CI——「没跑 CI」不等于失败。
- 发版四文件：`package.json` / CHANGELOG 新段（覆盖自上一 tag 起**全部**提交，含「成熟度自陈」「真机读数」
  「明确没做 / 未验证」）/ 双语 README 横幅（两处**逐字一致**）/ `dist/notes-X.Y.Z-zh.md`（必须含未签名声明，
  `dist/` 在 .gitignore 内，只本地用）。
- 内容纪律：**不许编造**任何数字/耗时/覆盖率，读数必须来自真实命令输出；没跑过就写「未验证」；
