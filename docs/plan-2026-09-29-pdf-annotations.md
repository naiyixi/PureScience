# 文档标注层（PDF 标注库）— 切片计划

来源：对标代码级审计 `reference #4`（中—大，文档智能面）。**本文件不出现任何对标产品名。**

我方现状锚点：`src/shared/bookmark.ts`（会话书签，用户侧私有，锚点含 `pdf-region` + `artifactVersionId`）、
`PdfRegionOverlay.tsx`、`src/main/references/pdf-doi-import.ts`（PDF 导入与 DOI 识别）；
`src/main/**/annotation-repository.ts` 是**设置项注解**，与 PDF 无关；PDF 标注类锚点 **0 命中**。

## 1. 差异化红线（交付判据，逐条要可核验）

1. **标注绑「文件版本 + 内容哈希」，不绑会话**：定位是 `(源文件 id, 版本 id, checksum)`，同一 PDF 换版本时旧标注**不静默迁移**——要么显式重锚，要么进入「版本已变」的具名状态。
2. **导入幂等 + 回执独立存活**：原生阅读器的标注导入必须幂等（重复导入同一份不产生重复项），且**回执记录独立保存**（清掉标注不清回执，反之亦然）。
3. **导出两条独立通道**：`annotated PDF`（把标注**烧进副本**）与 `notes`（纯文本/结构化清单）各自独立；**永不改写源字节**——必须有**字节级断言**（导出前后源文件 sha256 不变，且副本的子类型集合符合预期）。
4. **标注能进证据链**：标注可挂进审查证据与 **GB/T 7714 引文链**（与文献分诊的入选结果衔接）。
5. **显式声明「标注不进模型上下文」并有测试约束**：任何送模型的输入装配都不得包含标注文本；用测试钉住（不只是文档声明）。

## 2. 数据模型（我方命名）

| 表                    | 关键字段                                                                                                                                                                                                      | 不变量                                                                                       |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------- |
| `PdfAnnotation`       | `sourceFileId` + `versionId` + `checksum` 定位版本；`kind`（`highlight`/`underline`/`squiggly`/`strikethrough`/`area`/`page-note`/`document-note`）；`selectorJson`（带 `version` 信封）；`body`；`createdAt` | 索引一律以 `(sourceFileId, versionId)` 为前缀；kind 与 selector 形状必须一致（不一致即拒绝） |
| `PdfAnnotationImport` | `sourceKind` + `sourceFileId` + `versionId` + `importedAt` + `digest`                                                                                                                                         | 幂等键唯一；回执可独立查询与删除                                                             |

## 3. 切片

| 片     | 内容                                                                                          | 验收                                                                                                               |
| ------ | --------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| **A1** | 模型 + 运行期 DDL + 仓库（版本锚定、kind/selector 一致性校验、导入幂等与回执）                | 单测：不一致的 kind/selector 被拒；重复导入不产生重复项；回执与标注可分别清理                                      |
| **A2** | 导入通道：从 PDF 自带标注导入（含扫描/无标注的诚实回报）                                      | 单测 + 真机：带标注的 PDF 导入后条数与种类对得上；无标注 PDF 明确回报「无标注」而非静默成功                        |
| **A3** | 界面：`PdfRegionOverlay` 扩为可增删标注（高亮/下划线/便签），列表与跳转；版本变化时的具名状态 | 渲染用例 + 真机：点得动、能创建/删除、版本变更后显示「版本已变」并可重锚                                           |
| **A4** | 导出两条通道 + **字节级断言**                                                                 | 真机 e2e：导出前后源文件 sha256 不变；annotated 副本含标注且 PDF 子类型集合符合预期；notes 导出条数与库内一致      |
| **A5** | 检索 + 证据链接线（挂进审查证据与 GB/T 7714 引文链）+ 「不进模型上下文」的测试约束            | 真机：标注可被全局检索命中（只读已存文本，不解析 PDF）；引文链能看到关联标注；测试断言送模型的输入装配不含标注文本 |

## 4. 与既有功能的关系

- 与**文献纳排分诊**（S1–S5）衔接：入选文献的 PDF 标注可作为决策证据引用（红线 4）。
- 与**会话书签**（既有、用户侧私有）是不同东西：书签锚在会话，标注锚在**文件版本**。
- 导出走既有 PDF 处理设施，不新增依赖。
