# IC52 立项：会话级只读重放 + 对某一步提问

> 状态：**立项（待开工）** · 2026-10-06 · 对应排期档 IC52、对标台账 reference #13（#3140）
> 前置：无（本文件即该行要求的「单独立项文件」）

## 1. 背景与对标现状（台账原文）

- **对手**：把重放抬到**会话级**，并允许对着**录制的步骤**发问（#3140，对手 v0.35 窗口，2026-10-02 快照）。
- **我方现状**：只有**产物级**重放 —— `src/main/artifacts/replay-runner.ts` + `replay-composition.ts` + 通道 `artifacts:replay-version`，做的是「同一份产物重跑 + 逐字段比对」。**会话级重放 / 逐步讨论：全仓 0 命中**（`grep -rli` 已核）。
- ⇒ 判定：**真差距（中至大）**。本单元把「只读地逐步走一遍某个会话」做出来，并把「对某一步发问」接上。

## 2. 范围（做 / 不做，逐条）

**做**：

1. **只读重放视图**：选一个已结束的会话 → 按时间线逐步走它的**步骤**（一轮 = 它的工具调用序列 + 写审计 + 运行标记），每步显示：它在做什么、输入是什么、产出是什么、来自哪个产物版本。
2. **对某一步提问**：选中某一步后可以就该步提问，回答**只由该步自己的记录**（工具名与入参、返回摘要、写审计条目、运行标记、以及该步引用的产物/文献/pin）组装，并**逐条给出它读的是哪条记录**（不许凭空生成）。
3. **诚实空态**：某步没有可读记录时，明说「这一步没有留下可读记录」，不是显示空白。
4. **只读**：视图内**没有任何**会改变会话/产物/存储的动作（按本仓「只读是断言出来的」体例，测试要钉住控件集合与可调用通道）。

**不做（明确划界，避免半做）**：

- **不做整会话确定性复现**（对手自己也列为未做）——重放**不重跑**任何工具、不重算任何产物、不声称「结果可复现」。
- 不做「对整会话提问」的通用问答（那会把本单元变成另一个产品面）；本单元只做**对某一步**。
- 不做导出/分享重放录制的格式（后续单独立项）。

## 4. 数据从哪来（先说清，再动手）

每一步的**可问内容**只允许来自这些落点，且答案要**点名它读的是哪一条**：

- 该步的工具调用（名 + 入参 + 返回摘要）——来自会话记录里的工具调用条目；
- 该步的写审计条目 —— 来自既有写审计存储（`WriteAuditPanel` 的同一个来源，不另造第二套）；
- 该步的产物引用 —— 通过 `artifacts:replay-version` 读到的版本元数据；
- 该步的文献/pin 证据 —— 既有引用与 pin 表（同一台机器的存储）。

**服务/模型不报的量不许假装**：回答里出现的每个数字都必须能指向上面某一条记录；无法指向的写「未记录」。

## 5. 验收判据（真机为准；单元/渲染测试不算完成证据）

1. **真入口**：从工作台能打开重放视图并选中一个**真实跑过的**会话（不是夹具造的假会话）。
2. **逐步**：时间线能走到某一步，且该步的「工具调用 / 写审计 / 运行标记 / 产物引用」四项里**至少三项**在屏上可读，值与该会话的记录一致（逐字段比对，不钉死手写数字）。
3. **对某一步提问**：就某一步提问后，回答里**每条事实都带它读的记录位置**；构造一个「该步没有记录」的步骤，断言回答具名为「未记录」而不是编造。
4. **只读**：断言视图内控件集合**恰好**是只读动作（零个改变性控件），并逐条断言它调用的通道都在只读白名单内。
5. 证据落 `docs/evidence/`（真实事实 / 本轮观测值 / 服务不报什么 三块）。
