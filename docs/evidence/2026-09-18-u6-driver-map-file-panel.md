# U6：驱动地图（为什么前两轮都是 0 样本）—— 文件面板在**项目内部**，不在顶部导航

- 日期：2026-09-18 / 实例：dev 带窗口 44105 + CDP 9336（真实语料副本）

## 一、结论：前两轮的 0 样本是**驱动走错层级**，已定位到确定路径

| 层级 | 实测 |
|---|---|
| 首页（Home） | 可点元素 119 个 / 唯一 64；顶部是 `PureScience`、`搜索会话和产物… ⌘K`、语言、`新项目`，其余是**项目行**与**会话行**。**没有**任何名为 `文件` 的入口 |
| 点一个项目（`分子动力学`） | **点击成功**，URL 变为 `http://localhost:5174/?project=cmtzcgz1i0000wfspkc`；此时可点元素里**首次出现 `文件`**，另有 `全部项目`、会话行（`Session status: Error …`） |
| 点 `文件` | 点击成功（进入文件面板），但**面板内容在 2.5 s 内未挂载出可点文件行** ⇒ 需要在面板内做**第二层**点击（点具体文件行）才会触发预览 |

⇒ 我前两轮的驱动都停在"首页找 `文件`"这一层：U5 报 `clicked:false`（找不到），U6 报 `rowsFound:0`（首页没有带扩展名的行）。**这不是应用的问题，是驱动少走了一层。**

## 二、确定性的驱动路径（下一轮直接用）

1. 点项目行 → **等待 URL 含 `?project=`**（DOM 条件，不用超时）；
2. 在项目内点 `文件`（此时它才存在）；
3. **等待文件面板内容挂载**（轮询面板容器里出现行，或等待稳定选择器，而不是固定 2.5 s）；
4. 点一个带扩展名的文件行 → **断言预览元素增长**（`iframe/img/canvas/video` 计数）后才计入样本。

## 三、本轮仍未取得样本

`preview-resources:acquire` 在本次运行中**依然 0 次出现**（连同"任何 acquire"计数也是 0）。按纪律：**没有样本就不报事件循环数字**，U5 交付的仪器（`monitorEventLoopDelay`）仍在原处，等确定性驱动跑通即产出。

## 四、本轮唯一产物

这张**已经实测过的驱动地图**（含项目 id 形态、`文件` 入口出现在项目内、首页无 `文件`）。它的价值是把"0 样本"这个歧义**彻底消掉**：以后 0 样本只能来自驱动失败，且失败点会被点名。
