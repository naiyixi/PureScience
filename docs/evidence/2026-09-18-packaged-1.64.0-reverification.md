## 三、过程中的一个真坑（写进流程）

**打包版在隔离根里会卡在 `compose-runtime` 且不打任何错误**：第一次启动只到 `phase: 'compose-runtime'` 就停住、44101 不监听、日志无 error —— 根因是副本里没有 `runtime/`，环境就绪闸门找不到可用的运行时。修法（瞬时、不复制字节）：`cp -al ~/.purescience/runtime <copy>/runtime`（连 `.env-ready` 一起硬链接）⇒ 同一启动流程随即走完 `read-index → fetch-manifest → reconcile-derived-state` 并开始监听。

## 四、诚实边界

1. 本档只覆盖 **macOS arm64** 的打包产物。
2. 测量期间**用户的 dev 实例（44100）在跑**（CPU 有争用），打包实例单独用 44101/独立 user-data-dir；两条实例互不干扰，但 p95 数字含这一份背景负载。
3. 未量：UI 交互帧率（本轮只驱动了会话菜单这一条交互链）。
4. 守卫那条判据仍是**单次行为开关**（拒绝 → 放行），不是统计量。
