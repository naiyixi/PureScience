# 知网自有格式导出（v3.0 单元 0.2）——两种标签世代的实文件读数与真窗口闭环

**提交**：`f8809c75`（解析器 + 计划层 + 九语文案 + 单测 + 认证 spec）
**日期**：2026-11-19
**结论**：知网「导出/参考文献」给的**默认**格式（`English-中文` 标签文本，`DataType`/`Title-题名` 这一族）
现在能直接导入，并能被中文检索命中、生成引用。此前这条路只在用户自己把导出格式改成 RIS 时才通。

## 一 缺口与判据

| 项 | 读数 |
| --- | --- |
| 弹窗是否接受 `.txt` | 早就接受（`accept=".json,.ris,.enw,.nbib,.txt,…"`）⇒ 缺的不是入口 |
| 计划层认哪些方言 | `planReferenceImport` 只认 Zotero JSON / RIS / EndNote / MEDLINE ⇒ 真实知网文本被判 `not-an-export` |
| 判据 | 用**真实导出文件**完成一次「导入 → 中文检索 → 引用」闭环，且不得凭空造字段 |

## 二 两份真实文件（不是我按文档编的）

两份都取自公开仓库里的**真实导出文本**，只读不改；`sha256` 与条数是本机现算的。

| 文件 | 来源（公开仓库 / 路径） | 字节 | sha256 | 记录 |
| --- | --- | --- | --- | --- |

| 2021 世代 | `dearfad/mrhelper` / `mrhpkg/filters/demo_cnki_202101.txt` | 31,871 | `e6b7af6514c0c1d8b00fecea6af1aa8b7068dc96b301b7dcde843d134122cdc8` | 20 |

**两代标签不是同义词**（这正是「按标签名松匹配」会读错的地方）：

| 语义 | 2022 世代 | 2021 世代 |
| --- | --- | --- |
| 期刊 | `Source-文献来源` | `Source-刊名` |
| 时间 | `PubTime-发表时间` | `PubTime-出版时间`（可到分钟） |
| 卷 | `Volume-卷` | `Roll-卷` |
| 页码 | `PageCount-页码`（`70-74`） | `Page-页码`（`168-170`） |
| 页数 | — | `PageCount-页数`（`3`，**是页数不是页码**） |
| 单位 | `Organ-单位` | `Organ-机构` |
| 链接 | `URL-网址`（可能是被抹掉的 `[Link]`） | `Link-链接`（真 https） |
| 记录分隔 | 空行 | **无分隔**，下一条从 `DataType: 1` 重新开始 |

因此记录按**复合标签**（`English-中文`）取键，不按裸英文名：裸 `PageCount` 会把「本文 3 页」写成页码 `3`。

## 四 真窗口闭环（认证车道）

`e2e/certification/cnki-format-import.spec.ts`，在**该提交自身的隔离工作树**
（`git worktree add /tmp/ps-cnki f8809c75` + 软链 `node_modules` + `npm run build:e2e`）上跑，不碰主树的
`out/`，也不碰正在运行的 dev 实例。

```
npx playwright test e2e/certification/cnki-format-import.spec.ts
1 passed (9.6s)
[cnki-format-import] imported=3 refused=0 search="桥梁智能建造" count="1 of 3 records match"
  venueOnCitation=true affiliationOnCitation=false
```

断言的是四件事（缺一不算过）：

1. 界面弹出「Imported 3 records …」，并且**旧的那句**「既不是 Zotero JSON 也不是 RIS」在屏上**为 0**；
2. 中文子串（无空格）`桥梁智能建造` 命中 1 条，行上标明命中字段是 `title`；
3. 该行的引用文本里有期刊 `世界桥梁`、年份 `2022`、第一作者 `文武松`；
4. 引用文本里**没有**作者单位 `中铁大桥局集团有限公司`（把 `Organ-单位` 当出版者就是编造一个事实）。

## 五 边界（不许读成更强）

- **没有**接入知网的在线检索：本单元只做**离线导出文件**的读取，机构订阅的检索接口不在本轮范围（排期本来就写「离线导入优先，不做爬取」）。
- **只覆盖**上面两种真实世代的标签。万方 / 维普 / 超星各自的**自有**格式没有实文件，未做、也未声称。
- 2021 世代的第 2 条记录没有作者行 ⇒ 作者列表为空；这是如实状态，不补 `[Anonymous]` 一类占位。
- 被抹掉的链接（`[Link]`）与带方括号的 DOI 一律**不存**，因此这类记录的「按 DOI 去重」不生效，只按标题去重。
- 单测（24 例）与全量文件读数（67 + 20）不等同于真窗口：真窗口那半以第四节那次 `1 passed` 为准。
