## 二、交付：`zh_medical_terms` 连接器（源 = Wikidata，CC0）

**为什么是这条**：差异化的前两条（每条带出处、缺失不写成阴性）要一个**可引用的身份**；而第三条（中文术语
归一化）的落点在**检索之前**。Wikidata 是唯一探测到「公开 + 机器可读 + 可引用（QID/修订号）+ 允许再用（CC0）」
的中文术语索引 ⇒ 用它做**跨语桥**：中文术语 → 实体（QID）→ 英文标签（PubMed / OpenAlex / PubChem / ChEMBL
真正索引的那种写法）。连接器**不自带术语表**（那是共享层的单一来源），只做「这个词是什么、id 是什么、这条读数
从哪来」。

| 工具 | 作用 |
| --- | --- |
| `zh_term_resolve` | 中文术语 → **服务排序的候选列表**（每条带 QID / 中文标签 / 描述 / **匹配在 label 还是 alias** / 实体 URL）；归一化步骤逐条上报（去空白、折叠空白、全角→半角、剥离剂型后缀）；归一化后为空则**按原样重试一次** |
| `zh_term_crosswalk` | QID → 中文标签（zh / zh-hans / zh-hant）、中文别名、**英文标签**、中英文维基链接、**出处**（实体 URL + 修订号 + 实际请求 URL + CC0）；缺哪一语言就列进 `missing` |

### 2.2 这些读数定下的三条设计（都有真机依据，不是推断）

1. **排序不是解析 ⇒ 一律返回列表，绝不替你选一条。** `非小细胞肺癌` 的第 1 名是**另一个实体**（`腺癌`，按
   别名匹配），正确的是第 2 名；`乙肝` 的前三名里**根本没有**乙型肝炎（`Q6853`）——第 1 名是「乙肝歧视」，
   另两条是论文条目。静默取第 1 名就是替源说了它没说的话。
2. **剂型后缀与品牌名会让检索整个失手**（`阿司匹林肠溶片` 原样 0 条、`拜阿司匹灵` 0 条）⇒ 先归一化再检索，
   把「做了什么」逐条上报，并且**归一化只许增加命中**：归一化后为空时按**原样**再发一次。
3. **没查到就是没查到**：报「Wikidata 里没找到」并附上实际发出的检索串，不说成「该术语不存在」——
   Wikidata 是社区维护的，检索是字面匹配。

### 2.3 两处「源说 200、真相不是 200」的坑（已按具名拒绝写死并有用例）

- `wbgetentities` 对**不认识的 id** 回 **HTTP 200** + `{"error":{"code":"no-such-entity",…}}` ⇒ 只读 `entities`
  的实现会返回一张「全是 null 的对照表」，看起来像一条已验证的读数。本连接器按名拒绝（用例钉住）。
- 同一响应若缺 `entities[qid]`，同样**具名拒绝**，不把「读不出来」变成「没有标签」。

## 三、覆盖面（诚实边界，具名）

- **品牌名（如「拜阿司匹灵」）解析不了**：检索 0 条。Wikidata 里确有品牌条目（`Q10420388`「阿斯匹靈」，
  English label `Aspirin`，别名 `Bayer Aspirin`），但**没有一条中文品牌名能命中它** ⇒ 本单元不声称品牌名可用。
- **`乙肝` 这类简称**：源里确有别名路径可命中别的词（`阿斯匹灵` → `Q18216`，按 alias），但简称的召回**不稳定**
  （上表第 4 行），因此连接器只保证「候选 + 匹配字段」如实给出，不保证第一名正确。
- **速率与网络**：连续请求（约 0.4 s 间隔）会撞 **HTTP 429**；`wbgetentities` 在本机网络上偶发 **SSL 握手超时**。
  引擎自带 429/5xx 重试；仍失败时抛错（**不会**退化成空结果）——这两条是实测事实，不是设计目标。
- **未取**：本条没有界面入口（连接器是 agent 面工具，按仓规不需要窗口入口），因此**没有 e2e/窗口读数**；
  唯一读数来源是上面这条真机路径（应用自己的引擎 + 真实服务）。工具在**会话外**（web 面）是否可达未测。

## 五、与共享层的关系（防重复造表）

本单元与**同一批次里会话交付的**共享层工作是**两个面**：共享层（`f2dac485`：`src/shared/chinese-terms.ts`，
217 词条 / 285 键）是「应用已知术语的规范中文 → 英文对照表（单一来源）+ 查询规划，不可映射即具名拒答」；
本连接器是「表里没有的术语解析成什么、id 是什么、这条读数从哪来、英文标签是什么」。
描述符头部已写明**本连接器不带术语表**，以免长出第二份会漂移的词表；两会话接口是
「表命中 → 共享层直接映射；表未命中 → 本连接器解析成 QID 再取英文标签」。
