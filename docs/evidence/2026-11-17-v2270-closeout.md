## 二 Homebrew cask（第 3 条前半）—— 直接读远端 tap，不从记忆里补

```
$ gh api repos/naiyixi/homebrew-tap/contents/Casks/purescience.rb
cask "purescience" do
  version "2.27.0"
  sha256 arm:   "c90065bc6756e4e44f51c043024751220ee13b209abf27a9663017f045890bdc",
         intel: "630858c39663adeb49b75327ffeef2879da56ba0a80a4d47dec1016125b090ef"
  …
  caveats <<~EOS
    PureScience is signed with a Developer ID Application certificate and notarized
    by Apple as of 2.27.0, so a quarantined copy should pass Gatekeeper. Earlier
    versions (2.26.0 and before) were ad-hoc signed and were not notarized.
    …
```

三条判据：

1. `--no-quarantine` **不再是安装步骤**，只在「已经公证还被拒」这种缺陷情形下作为变通出现；
2. 两架构 sha256 与 `RELEASE-CERTIFICATION.json` 里同名 dmg 的 `sha256` **逐字相同**
   （`c90065bc…` = mac-arm64、`630858c3…` = mac-x64）⇒ tap 与发布页是两个独立来源，对上了；
3. `livecheck` 走 `github_latest`，页已是 `Latest` ⇒ 下一次发版不必改 cask 的结构。

## 三 mac 原地自动更新（第 3 条后半）—— 代码已开，真机读数仍空

- **代码侧已成立**（2026-11-13 那轮交付，本轮只复核）：`src/main/update/create-strategy.ts` 的
  `macCanAutoUpdate(isPackaged, version, expectedTeamId)` = 打包 **且** 版本号不含 `-`（非预发布）
  **且** 安装包的 `Identifier=com.zerolink.purescience` / `TeamIdentifier=<本项目 Team>` 都读得到；
  三者成立才走 `ElectronUpdaterStrategy`（原地更新），否则回落 `UpdateService`（手动安装）。
  Team 由打包时注入的 `__PURESCIENCE_MAC_TEAM_ID__` 提供（Finder 启动的包没有环境变量，靠这个常量）；
  本地包与 nightly 是 ad-hoc ⇒ 永远回落，这是设计本意。
- **缺的是应用级真机读数**，而且卡在一条外部条件上：它要一台**已装签名稳定版**、且有一个**更新的签名稳定版**的机器。
  v2.27.0 是第一个签名稳定版 ⇒ **解封条件 = 下一次签名稳定版发布**（v2.27.1 起）。判据与配方见
  `docs/evidence/2026-11-13-signed-mac-installer-flow-certification.md` §三。
- 不许用 `stubUpdateManifest` 去驱原地更新求「绿」：那个替身拦的是 `/version.json`，而原地更新根本不请求它
  （同一份证据档已写明）。

## 四 本轮顺带发现、**未修**的一条（等 i18n 在制品落地）

`src/renderer/src/i18n/*.ts` 的 `update.macManualInstallNote` 现在写的是：

> macOS builds are ad-hoc signed for now, so macOS refuses to replace a running app in place …
> macOS 版目前是 ad-hoc 签名，系统不允许原地替换正在运行的应用 …

**「for now / 目前是 ad-hoc」对 v2.27.0 已经不成立**。这句话只在「装的那份不是签名稳定版」（nightly、ad-hoc、旧版）
时才会出现，所以正确的说法应当描述**这一份**的状态，而不是给整个平台贴一个已过期的定语。同处
`src/renderer/src/components/UpdateDialog.tsx` 的代码注释（"The signed-in-place path does not exist on macOS yet"）
也一并过期。

**为什么这一轮不改**：九份字典与 `main-message-catalog*` 现在**带着别人的未提交在制品**
（connector 导入导出的原生文案批，11-16 17:37–17:51 落盘），改同一批文件会把对方那一批卷进本次提交。
⇒ 立案到下一版：改 9 语言文案 + 那条注释，并加一条断言「这句不再声称平台是 ad-hoc」，跑 translation-quality。
