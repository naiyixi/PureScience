# 整行短文案收口（45 处 → 既有 `common.*` 键）+ 审计器补上两种漏检形状（2026-10-12）

本单元 = 上一轮在 `docs/evidence/2026-10-12-settings-copy-i18n-zh-reread.md` 第六节第 2 条**自己记下的
仪器缺口**：`Cancel` 这类**整行短文案**审计器看不见。本单元把缺口做掉，并把**看得见的那些**改走字典。

判据（与上一单元同一条）：**修复前的版本重放必须命中；修复后的必须沉默**，且**屏上必须真的换了字**
（不是只有字典文件里有值）。

## 一 被测缺口（先量再动）

| # | 形状 | 旧扫描器为什么看不见 | 量出来的规模 |
| --- | --- | --- | --- |
| 1 | **整行短标签** | 短词被 prettier 折到自己一行 ⇒ 该行既没有 `>text<`（`>` 在上一行的标签上）也够不到 `jsx prose line`（那条要求 ≥10 字符且句末标点） | **101 处 / 55 个不同的词**（全树，判据＝前一非空行以 `>` 结尾、后一非空行以 `</` 开头） |

## 二 交付（三类，各自可独立复核）

### 1. 45 处整行短标签改走**既有** `common.*` 键（零新键、零新通道）

只取**已有通用键、且中英值已到位**的八个词：`common.cancel` / `common.retry` / `common.back` /
`common.edit` / `common.close` / `common.delete` / `common.dismiss` / `common.open`。

| 词 | 处数 | 词 | 处数 |
| --- | --- | --- | --- |
| Cancel | 22 | Close / Delete / Dismiss | 各 2 |
| Retry | 8 | Open | 1 |
| Back | 5 | | |
| Edit | 3 | **合计** | **45 处 / 31 文件** |

- 逐处预检（脚本自带，任一不成立**整体不写**）：① 该行 `strip()` 后必须**恰好等于**目标词（不是已改过的表达式）；
  ② 该行所在组件体里必须已绑定 `t`（45/45 命中，逐个列出核对过）。
- 不用新键、不用新通道 ⇒ **零契约计数涟漪**；键是否真的存在由 `tsc` 兜底（`ZhKey` 联合：写错键名当场 `TS2820`）。

### 2. 屏上真的换了字（不是只有字典里有值）

上轮那条中文复读用例（删除专才的确认框）**就地加强**：除保证句外，再断言该框自己的取消控件
读到 **`取消`** 且**不再出现 `Cancel`**。那是这 45 处里的一处真实窗口态（专才面板 → 操作菜单 → 删除 → `alertdialog`）。

### 3. 审计器补上两种形状 + 一个可复跑的重放入口

- `scripts/i18n-hardcoded-audit.mjs`：新增 `jsx short label line`（**邻居判据**：前一非空行以 `>` 结尾且
  后一非空行以 `</` 开头；**保留大写起首**这条——量出来小写变体在同样邻居判据下全树 **0 命中**，
  放宽只会加噪声）、`attr template literal`（要求值**以字母开头**且插值两侧只有散文字符 ⇒
  以 `${` 开头的 CSS 工具类模板天然被排除）。两条判据都写进脚本注释，标明是**量出来的**、防后人放宽。
- 邻居形状**不改动既有形状的过滤器**（既有注释里那条纪律：过滤器跑未 trim 的原始捕获，本单元一个字节没动）。
- 新增 `scripts/i18n-audit-replay.sh <rev> <路径…>`：把某个提交下这些路径的副本物化到临时目录再跑审计
  （支持目录，自动展开）。**没有这个入口，"我修好了仪器"这句话无法取证**——坏版本不在树里。

## 五 刻意的边界（不许读成「已做」）

1. **没有真机窗口读数**：内存闸门仍关（开工前 `vm_stat` 空闲物理页 7,593 ≈ **119 MB** / swap 已用
   **4,793.69 MB of 6,144 MB**）⇒ 界面那半边由**渲染用例**作证，**不冒充窗口读数**。
2. 本单元**只改了 45 处里有通用键的那八个词**。审计器摊开的其余 **56 处整行短标签**（`Download` / `Done` /
   `Rename` / `Upload` / `Write` / `Specialist ID` …，47 个不同词）与 **59 处模板字面量读屏名**，各自需要
   先定「用哪个键」——**是可见，不是已修**。工具输出里那张 distinct-texts 表就是这两份清单。
3. 本单元没有把审计器做成门禁（脚本头注释写明它不是门禁），它的产物是**待办清单**；
   `dquote` 一族 70 条包含刻意不本地化的文本（agent 指令 / 日志），**不都是缺陷**。
