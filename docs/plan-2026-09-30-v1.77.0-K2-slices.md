## 1. 切片

| 片 | 内容 | 交付物 |
|---|---|---|
| **K2-U1** | 触发质量分进详情：把 `SkillEvalResult` 接到 `SkillDetailView`，逐条列出每个检查的「缺什么」（首句不自足 / 缺动作词 / 主语不具体 / 填充词 / 长度），并注明**本地可复算、不靠发布方** | 详情载荷 + 面板区 + 九语言 |
| **K2-U2** | 可用性矩阵：每个智能体/专家一行 × 技能列，勾选即写设置；矩阵值参与会话装配（该会话里确实不再出现）| 数据 + 通道 + 界面 + 装配接线 |
| **K2-U3** | 守门技能与许可证空值：先核「守门」标记（有则显示不可关闭 + 原因），许可证为空显示「未知」而不是留白 | 面板 + 九语言 |

## 2. 差异化红线（逐条可在真机核验）

1. 分数**当场可复算**：同一描述在离线状态重算一致（评分为纯规则），且列出「缺什么」而不是只给一个数。
2. 矩阵不是装饰：勾掉之后**在真机会话里**该技能确实不再加载（这条必须真机跑一次）。
3. 空值一律有词：「未知」不等于留白。

## 3. 真机验收（与排期一致）

| # | 断言 |
|---|---|
| ① | 自带技能与本机技能分别打开详情，触发质量分与其「缺什么」逐条列出，且同一描述离线重算一致 |
| ② | 矩阵每个智能体/专家一行；勾掉某技能后，**跑一次该专家会话**确认该技能不再加载 |
| ③ | 守门技能显示为不可关闭并给出原因（若无此标记，如实记为「本仓无守门标记」并撤下该断言）|
| ④ | 许可证字段为空时显示「未知」而不是留白 |

## 4. 明确不做

- 不引入外部模型给技能打分（评分的价值就在于**本地确定性**）。
- 不把发布方自评分搬进来（对标做法；我们展示的是你自己能复算的东西）。

## 5. 诚实边界

- U2 的矩阵接线会触及会话装配路径，属**半迁移**风险区：若一个单元内做不完，只落 `wip/<slice>` 临时分支，默认分支保持绿（见 `references/contract-inventory-ripple.md`）。
- ③ 若「守门技能」标记不存在，**不新建概念来满足断言**——按排期如实标注为「本仓无此标记」并撤下。
