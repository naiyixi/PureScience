## 2. 差异化红线（逐条可在真机核验）

1. 每行说清**生效模型 + 来源服务 + 回落路径**（对标只说「首个服务会自动用于这两项功能」）。
2. 检测按钮跑**真实往返**，显示**实测耗时与用量**，不是只给通过/失败（对标没有这一步）。
3. 每次回落写一条**可查事件**：会话里能翻到「这次归类为什么没用模型」（对标无此留痕）。
4. 「本地解析模型」分区只作为**壳**出现，并写明「内容由 v1.78.0 提供」，不摆假开关。

## 4. 明确不做

- 不给「文献归类」配模型位（功能不存在）。
- 不做「本地解析模型」的真实下载/校验（那是 M2；M1 只给分区与说明文字）。
- 不改动密钥删除语义（沿用「移除服务会恢复默认」）。

## 5. 诚实边界

- 检测按钮消耗真实额度：界面上必须写明「本次检测会真的调用一次模型」。
- 事件只记**回落原因与模型名**，不记录提示词内容。
