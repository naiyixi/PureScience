# M2 本地解析模型资产：现状核实与顺延（v1.81.0 决策备忘）

> 日期：2026-10-03。对应 `docs/plan-2026-10-03-v1.81.0-queue.md` 的 **V16 / V17**。
> 设计正本在 `docs/plan-2026-09-30-v1.77.0-search-models-skills.md` §155-164（目标、现状、差异化四条、五条真机验收、风险），
> **本档不重写设计**，只做三件事：核实现状、指出阻塞、给出顺延结论。

## 1. 现状核实（都在树上，逐条验过）

| 事实 | 锚点 |
| --- | --- |
| 校验式下载原语存在，且**仍无任何生产调用方** | `src/main/engines/model-weight-cache.ts`；`grep -rn "model-weight-cache\|downloadModelWeights" src --include=*.ts`（除自身与测试）→ **0** |
| 原语已含"不校验就不下"的语义 | `:64-68` 规格里的 SHA256 不是 64 位十六进制 ⇒ 视为未解析、**拒绝下载**；`:96-97` 取回后**重哈希比对**，不符即拒 |
| M1 留下的**入口壳**存在（设置→模型页的「本地解析模型」分区） | `ProvidersPanel.tsx:404-410`（`settings.localParsingModels` / `…Hint` / `…Planned`，文案明示"计划中"） |
| 本地 PDF 解析目前只有 pdfjs 文本/书签/图片对象检测 | `src/main/settings/pdf-service.ts` |
| **没有任何候选资产的已发布校验值** | 全仓 `sha256` 命中只出现在 `model-weight-cache.ts` 自身的规格字段与 `scripts/fetch-micromamba.mjs` 的 micromamba 清单里 —— **没有一条是"本地解析模型权重"的发布方摘要** |

## 2. 阻塞点（为什么本轮不能往下做）

M2 的纪律是**「无已发布 SHA256 的权重不下载」**（写进 v1.77 计划的差异化第 ① 条，也是本仓一贯口径）。
而现实是：**我们还没有任何一份"权重 + 发布方校验值"的清单**。这不是代码没写，是**数据前提不存在**：

- 若从模型作者方取权重：多数作者不发 SHA256（或不发稳定 URL），那我们只能"下完自己算一个"——
  那**不是发布方校验值，是自己给自己盖章**，等于把纪律作废。
- 若由我方发布：需要在某个 release/资产渠道托管权重并发布 manifest（含 sha256、字节数、版本、许可），
  这是一个**发布决定 + 托管位置**，不是一版代码能定的。

⇒ 因此本轮**不能**做 S1 的"资产获取"，也不能做 S2 的"接入"：两者都必须先有真实校验值。
硬做的话只剩两条路，都不接受：
1. 写一个只有拒绝路径、永远拒绝任何东西的模块 —— 那就是**没有消费者的死代码**（本仓明令禁止）；
2. 先下一个权重再补校验 —— **违反纪律**，且会让"断网可用/篡改即拒"的验收变成无法自证。

## 3. 结论：**顺延，且不改设计**

- **V16 / V17 本轮不做**，M2 **顺延**（v1.82.0 起，视权重的发布方与托管位置拍板结果）。按计划自带的退路执行：
  「若在本版排不下 ⇒ 在 2.5 里写明顺延并保持立项档已建，**不要留半截代码在树上**」——本档即该立项档的现状与阻塞记录。
- **触发解锁的三个前置**（按顺序，缺一不可）：
  1. **拍板权重的发布方与托管位置**（我方 release 资产 / 作者方官方分发）——产品决定；
  2. **产出 manifest**：每条含 `id / revision / url / sha256(64 hex) / bytes / license`，随应用发布（离线可读）；
  3. 只有在 1、2 完成后，S1（资产目录 + 校验式获取 + 拒绝路径）才有意义，S2（接入解析）也随之可测。
- M1 的壳**保持现状**（文案明示"计划中"），**不加"假安装"按钮**：一个点了什么都不会发生、或假装在下载的入口，
  比没有入口更坏。

## 4. 与对标的关系（差异化没有丢）

对标产品该项在动（下载 234.5 MiB 权重、校验失败可重试）。我们的差异化四条（无校验即拒 / 权重与派生结果解耦 /
离线可用为验收项 / 派生结果带模型 revision + 输入指纹）**一条都没让步**，只是**顺序**改成"先有可信的校验值再谈下载"。
这一条本身就是差异化第 ① 条的字面含义。
