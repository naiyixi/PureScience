# 人源 KRAS PDB 结构比较：4OBE、6OIM、8E8X

- **数据请求日期**：2026-08-22
- **数据来源**：RCSB PDB（经 structures 连接器，`pdb_get_structures` / `pdb_get_entities` / `pdb_get_ligands`）
- **请求的 PDB ID**：`4OBE`、`6OIM`、`8E8X`
- **获取结果**：3/3 均可从数据源取回（`retrieved = [4OBE, 6OIM, 8E8X]`），无 "not found" 失败记录。

## 关键说明：8E8X 不是人源 KRAS 结构

`8E8X`（标题 "9H2 Fab-Sabin poliovirus 3 complex"，冷冻电镜，2.91 Å）被成功取回，但其内容为
脊髓灰质炎病毒 3 型（Sabin 株）衣壳蛋白 VP1–VP4（UniProt P03302）加人源 9H2 Fab 重/轻链——
**不包含任何 KRAS/KRas（UniProt P01116）多肽**。因此它无法作为 KRAS 结构参与比较，
在 CSV 中以 `comparable_in_kras_comparison = False` 标注，图中以灰色斜纹柱显示并被排除在比较与汇总统计之外。

## 记录支持的观察（仅限可被数据直接支持者）

1. 三个请求的 ID 全部可取回；但三者中只有 **2 个（4OBE、6OIM）是人源 KRAS 结构**，`8E8X` 虽可取回却并非 KRAS 条目，故比较仅在 4OBE 与 6OIM 之间进行。
2. **实验方法与分辨率**：两个 KRAS 条目均为 X 射线衍射，报告分辨率 4OBE = 1.24 Å、6OIM = 1.65 Å，即 4OBE 的分辨率数值上更高（更低 Å）。
3. **链数**：4OBE 的非对称单元含 2 份 KRas 链拷贝（A、B），6OIM 含 1 份（A）。
4. **配体**：两条 KRAS 记录都报告结合 GDP 与 Mg²⁺；6OIM 额外报告结合 MOV（AMG 510 抑制剂）。8E8X 报告无配体。
5. **释放日期**：4OBE 2014-06-04、6OIM 2019-11-06、8E8X 2023-06-21，与沉积日期一致（均先沉积后释放）。
6. **条目分子量**：4OBE 39.59 kDa（2 条 KRas 链 + GDP/MG）、6OIM 22.07 kDa（1 条 KRas 链 + GDP/MG/MOV）、8E8X 120.09 kDa。

## 限制（重要）

- **PDB 条目之间不能直接推断生物学结论**：分辨率反映的是该特定晶体/样品的衍射或成像质量，
  并不表示某结构在生物学上"更好"或更具功能意义；链数、配体与分子量反映沉积时的结晶条件与样品组成，
  不能据此推导 KRAS 在细胞内的功能状态、抑制剂效价或 G12C 突变的临床意义。
- **可比样本不同**：4OBE 与 6OIM 在构建体长度（记录分别 170 与 183 残基）、突变状态（0 vs 4 处突变，标题为 G12C）、
  非对称单元拷贝数（2 vs 1）与结合配体（有无 AMG 510）上均有差异，因此两者并非相同样品，其差异是描述性的而非对同一样品不同处理的直接对照。
- **配体列表 = 沉积的非聚合物组分**：配体存在反映结晶/实验条件；"无配体"（如 8E8X）不等于生物体内不相关。
- **单一来源、时点数据**：全部元数据来自 RCSB PDB，取回于 2026-08-22；PDB 条目可被修订
  （三个条目的 revision date 分别晚于各自释放日期），数值以取回当日为准。
- **实验方法差异**：8E8X 为冷冻电镜，即使它是 KRAS 条目，其 2.91 Å 也不与 X 射线分辨率直接可比；本报告中它已被排除，故不构成混淆。
- **样本量**：可比条目仅 2 个，未进行任何统计检验。
