## 2. 级别定义（诚实口径，写进契约）

保护级别按**最弱一面**判定，两面分别可读：

- `os-sandbox`：文件系统面（运行时写保护）**且** 网络出口面（允许表）同时成立。
- `network-allowlist`：只有网络出口面成立。
- `unprotected`：网络出口面未过滤（文件系统面即使有也降级，**降级原因具名**）。

`scope` 两个轴恒随快照输出，所以「级别降了但写保护还在」这件事在界面上读得到，不会被级别标签吞掉。

## 4. 判据（真机断言 → 单元）

1. 笔记本/终端/后台三种执行面各跑一次，运行前都能读到保护级别当前取值与来源 → U1/U3/U4
2. 关掉网络允许表再跑一次：证据里级别下调且界面给出**具名**原因 → U1/U2/U4
3. 远程执行必须在**批准前**写出「无保护」，并在执行证据里留痕 → U4/U5/U2
4. 平台能力缺失时给**可执行修复路径**（不是只报错） → U1/U4
5. 记忆授权不得静默覆盖无保护执行（默认每次显式确认） → U5

- 不引入 OS 级沙箱原生组件进主包（本片只做**观测/展示/留痕/门**，真隔离另立片）。

- 不并行新建第二套「网络允许表」语义：网络轴一律读既有 `EgressSettings`。
