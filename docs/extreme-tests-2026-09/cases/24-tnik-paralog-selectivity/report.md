## 1. 数据来源与方法

### 1.1 蛋白序列（UniProt，人源，均在 2026-09 检索）
- **TNIK** (MAP4K7)：UniProt **Q9UKE5**，全长 1360 aa
- **MAP4K4**（HGK/NIK-like）：UniProt **O95819**，全长 1239 aa
- **MINK1** (MAP4K6)：UniProt **Q8N4C8**，全长 1332 aa

三个激酶域的 UniProt 注释完全一致：**Protein kinase，残基 25–289（265 aa）**。

### 1.2 晶体结构（PDB，实验验证）
- **PDB 5AX9**：人 TNIK 激酶域 + compound **4KT**，X 射线 2.4 Å（配体 4KT = 4-甲氧基-3-[2-[(3-甲氧基-4-吗啉代苯基)氨基]吡啶-4-基]苯甲腈）
- **PDB 2X7F**：人 TNIK 激酶域 + Wee1/Chk1 抑制剂 **824**（9-羟基-4-苯基吡咯并[3,4-c]咔唑-1,3-二酮），X 射线 2.8 Å

> 两结构经 SIFTS/PDBe 映射均为 **Q9UKE5（人 TNIK）**——"受体网格"前提本身成立（这正是问题所在：连 5AX9 与 2X7F 里真实共晶的配体 4KT/824 都是**非亚型选择性**的多激酶类抑制剂）。

### 1.3 方法
1. **序列/结构锚定**：三激酶域无内部插入缺失（VAIK 27、HRD 127、DFG 147、APE 172 四个基序在三者中起点逐位一致），采用直排位置索引；域位 p ↔ UniProt p+24（催化 Lys = K54 验证）。
2. **ATP 口袋接触定义**（真实结构）：以 5AX9 中 4KT 为探针，统计所有与配体重原子 ≤4.5 / ≤6.0 Å 的蛋白残基（20 / 29 个），并识别骨架氢键供/受体（N/O…N/O < 3.6 Å）。
3. **微环境物化距离**：每残基用（侧链体积、Kyte-Doolittle 疏水、电荷、芳香性、极性）加权欧氏距离表示侧链微环境差异（0 = 完全一致；仅 31 个可变列非零）。
4. **静态构象偏倚量化**：5AX9 与 2X7F（同一 TNIK）先以 129 对刚性核心 Cα 叠合（RMSD 1.41 Å），再逐残基计算 P-loop/铰链/活化段位移。
5. **RDKit**：SAScore（RDKit Contrib）、Bredt/桥头烯烃筛查、环尺寸/张力筛查、物化描述符。
6. **选择性预算**：以每类接触相互作用的经验自由能上界（脂肪族堆积 ~0.3、H 键/极性 ~0.5、芳香 ~0.8 kcal/mol）对每个"可到达且 TNIK≠MAP4K4"的残基作**乐观**求和，对比 1000× 所需 4.10 kcal/mol。此为量级论证，非亲和力预测（见 §6）。

### 2.3 为什么单纯 ATP 位点接触在物理化学上不可能给出 >1000×

**热力学标尺**：在 37 ℃，1000 倍选择性要求
ΔΔG ≥ RT·ln(1000) ≈ 0.593 × 6.91 ≈ **4.10 kcal/mol**（1 个数量级 ≈ 1.36 kcal/mol）。

选择性只能来自**结合时"碰得到且碰不到"的不对称**。可编码不对称的仅有序列可变残基。而数据表明：

1. 在真实配体 4KT 的**直接接触半径**内没有任何可供利用的序列差异（20/20 保守）；
2. 最近的序列差异 L30V（P-loop 起点）距配体 5.64 Å，且为 Leu→Val 保守脂肪族收缩（侧链微环境物化距离 ≈ 0.13，近乎等容等疏水），最多贡献 ~0.2–0.3 kcal/mol（≈1.6×）；
3. 第二个最近的差异 V113/I113 侧链距配体 **7.98 Å**，在 5AX9 中**不与配体接触**——声称的"背袋微裂隙接触"在真实复合物中并不存在；且该位点仍需跨越 ~4 Å 空腔，即使做成接触，Val/Ile 的差别也仅 ~0.3 kcal/mol；
4. 所有具实质物化差别的位置（如 αC 前 U60 G→E、αD U68 Q→L、U128 E→D、U134 C/S/C 等）距配体 **10.7–19 Å**，处于可溶性外周表面或活化段，ATP 位点配体不可达。

因此，"铰链双齿氢键 + 背袋疏水接触"这一组合**从第一性原理上没有任何能产生 1000× 的序列差异可供其编码**。±4.6 kcal 的刚性打分差在序列同一位点根本不存在热力学来源。

### 2.4 致命漏洞定性：晶体诱导契合 / P-loop 塌陷的静态偏倚

**（a）对接打分不是结合自由能。** AutoDock Vina 类打分的系统误差常在 ±1.5–3 kcal/mol 量级，跨蛋白、跨结构的横向比较（不同晶体、不同 construct、不同配体诱导构象、不同分辨率）尤其如此。−12.8 与 −8.2 的 4.6 kcal 差值恰好落在"不同静态受体快照"的打分噪声带内。

**（b）同一蛋白的两个共晶结构本身即可证明构象噪声。**

| 区段 | 5AX9·4KT vs 2X7F·824（均为 TNIK）Cα RMSD |
|---|---|
| 刚性核心（用于叠合） | 1.41 Å |
| **铰链 + 看门 103–115** | **0.85 Å**（刚性，佐证主链 H 键逐原子一致） |
| **Gly-rich P-loop 28–50** | **1.97 Å（最大 5.32 Å）** |
| 活化段 140–210 | 2.40 Å（最大 6.9 Å） |

P-loop 是 STE20/GCK 家族中最"软"的元件之一。抑制剂结合常诱导其"塌陷/闭合"以包埋疏水基团；不同抑制剂产生不同塌陷构象（fig2）。一个把分子"对接进 5AX9 的闭合 P-loop"而 MAP4K4 用另一个 P-loop 开放构象的流程，会系统性地把 ~2–4 kcal 的**构象差**记到"TNIK 选择性"账上——这就是 **P-loop induced collapse / crystal artifact** 的定量化表述。

**（c）Rotamer 塌陷。** 直接接触壳 20 个保守残基合计 **31 个侧链 χ-可旋转自由度**（K54=4、E69/M105/E106/Q157=3 等），在单晶中各自只锁定一个 rotamer。所谓"亚型特异微裂隙"，往往只是某侧链在特定晶型下的一个 rotamer 形成的瞬态空腔；MAP4K4 对应结构的同一侧链取另一 rotamer，空腔即消失。**用单一构象做口袋形状/子口袋识别是高假阳性来源。**

### 2.5 前提内在不一致点
- 声称"利用 Glu106/Arg113 区域静电场"：按 UniProt 编号 **Glu106 在三个激酶中完全保守（EEE）**，且与 Glu106 位置对应的 **113 号残基是 V（TNIK/MINK）/ I（MAP4K4）——不是 Arg**，也不带可形成"TNIK 特异静电场"的电荷。所谓"外周静电特异性矢量"指向的实际是保守残基，属无效锚点。

## 3. 任务 2 · 变构逃逸与生成语法缺陷

### 3.1 亚型特异亚口袋 / Rotameric 灵活度定量评分（方法）

脚本实现 `rotamer_report()`、`subtype_vectors()`、`subtype_discrimination_score(axis)`：

- **Rotameric 灵活性**：对每个口袋/外周残基按其侧链类型给出可旋转二面角数 χ（如 K=4, R=4, E/Q/M=3, V/L/I/F/Y/W/H/D=1–2, G/A=0）。单晶构象 = 每个 χ 一个值的采样；**构象退简并** = Π(各残基 rotamer 状态数)，用于评估"由单构象推断亚口袋"的不可靠度。直接接触壳 20 残基合计 χ-DOF=31。
- **亚型特异亚口袋打分**（可达性 × 差异性）：
  - 可达性 = 该残基侧链到真实配体/铰链锚点的最小距离（真实 5AX9 坐标）；
  - 差异性 = 三激酶该位点残基身份间的物化距离；
  - 若一个"特异亚口袋"由 0 个**可达且序列可变**残基构成，则其特异性得分 = 0（Lead-01 的背袋即此情形）。

| 可变残基 | TNIK→MAP4K4 | 侧链到 4KT 最小距离 | 到铰链锚点(质心) | 是否可作特异性接触 | 备注 |
|---|---|---|---|---|---|
| U30 | L→V | 5.64 Å | 14.1 Å | 仅边缘 | 保守脂肪族，信息量≈0 |
| U113 | V→I | 7.98 Å | 12.2 Å | 需长臂 | Val/Ile 尺寸差 ~0.3 kcal |
| U117 | I→V | 9.49 Å | 16.6 Å | 需长臂 | 同上 |
| U68 | Q→L | 10.75 Å | 23.3 Å | 需极长臂 | 实质性差异但远离 ATP 位点 |
| U128 | E→D | ~25 Å | — | 否 | 同为酸性，E/D 无静电梯度 |
| U129 | W→W | 14.9 Å | 17.6 Å | 否（vs MAP4K4 无差异） | 仅 MINK1 为 C |
| U134 | C→S | 17.5 Å | 19.5 Å | 否（vs MAP4K4 有 Cys/Ser 差） | 可溶性 αD 区，需外周策略 |

**结论**：在 ATP 位点几何可达范围内，不存在任何足以支撑 1000× 的"亚型特异微裂隙"。真正的非保守残基（U113/117/128/134 及更远的 αD/活化段）都在口袋外周的可溶性表面，属于**变构 / 外周延伸**才能到达的空间。

- **SAScore**：Lead-01 2.56（<3，易合成区间；与真实共晶配体 2.37–2.42 同级），骨架为文献常见的咪唑并吡嗪/苯胺偶联，不存在"生成语法"级合成不可行问题。

### 3.3 针对非保守外周残基的几何导向矢量 → 重构生成损失函数
