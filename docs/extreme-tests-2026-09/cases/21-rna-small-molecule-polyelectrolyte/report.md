# RNA 靶向小分子构象受挫与聚电解质熵陷阱审查研报

**审查对象**：靶向难治性 RNA 病毒核心结构域（~45 nt，含动态发卡三联体与内环）的拟肽类小分子。
**宣称结论**：骨架富集芳香平面扩展基团与阳离子侧链；体外 ITC 实测 Kd = 0.15 nM、ΔH < −18 kcal/mol；荧光偏振显示其对常规发卡 RNA 亲和力弱 >10⁴ 倍；故该分子在活细胞中必然高度精准锁定病毒 RNA 功能构象、抑制翻译并克服抗原漂移，且不影响宿主全转录组折叠网络。

**审查判定（置信度：中—高，结论分级为“证据不足以支持 + 存在系统性反证”）**：

| # | 宣称 | 审查裁决 | 置信度 |
|---|------|---------|--------|
| C1 | “亚纳摩尔 + 极负 ΔH ⇒ 高特异性结合” | **系统性假象**：低盐缓冲中的 Kd/ΔH 无法外推至胞内离子强度；其中约 1/2 的结合自由能是非特异性反离子释放；极负 ΔH 伴随 **负 ΔS**，是“结合诱导折叠/刚性化”而非凹槽互补指纹 | 高 |
| C2 | “必然锁定病毒 RNA 功能构象” | **不成立**：低盐无 Mg²⁺ 折叠系综中被该分子“诱导锁定”的更可能是**非天然错折叠态**（构象捕获伪增益）；其胞内净效应是把 RNA 拖入热力学死端而非稳定天然态 | 中—高 |
| C3 | “绝不影响宿主全转录组折叠网络” | **不成立**：rRNA/tRNA 等结构 RNA 是 µM 级的聚阴离子竞争池；非平衡态模拟给出宿主丰度升高时“有效靶向自由度”呈数量级暴跌，且在靶 RNA 自身也被拖入错折叠死端 | 高（在给定模型假设下） |
| C4 | “克服抗原漂移” | **离题**：靶向 RNA 顺式元件与表面抗原漂移无逻辑关联；且病毒可通过结构突变/核糖体状态逃逸该“锁定” | 中 |

> **方法学局限声明**：本研报以给定的少量参数（0.15 nM、ΔH、>10⁴ 选择性、多阳离子+芳香骨架）为前提做机理与数量级审查。**未提供**实际缓冲成分、净电荷、晶体/共晶结构、细胞靶标占有数据；凡依赖这些缺口的断言均按“不可证实”处理并在 §6 给出可证伪实验清单。所有数字为参数化模型估计（误差范围以数量级计）。

## 1. 聚电解质机理驳斥：反离子释放熵与“超高亲和力”的系统性假象

### 1.1 结构前提：RNA 是高线电荷密度的 Manning 聚电解质

RNA 双链（A 型，11 bp/圈、每 bp 上升 ~2.8 Å、22 个磷酸/30.8 Å）沿轴投影的磷酸间距 b ≈ 1.40 Å，Bjerrum 长度 lB(H₂O,25 °C) ≈ 7.1 Å，因此：

$$\xi = l_B/b \approx 5.07 \gg 1 \qquad(\text{ssRNA } b≈3.8\text{ Å} \Rightarrow \xi≈1.87)$$

Manning 判据（ξ > 1/|z|）意味着反离子凝聚：双链 RNA 上每磷酸有 ~80% 电荷被局域凝聚反离子所补偿（ψ ≈ 0.80，对含内环/单链凸起的 45-nt 基序取有效值）；Mg²⁺ 二价阳离子凝聚更强。**任何阳离子配体要“接触”磷酸骨架，都必须置换这些凝聚反离子——该置换释放的平移熵正是结合自由能里“免费”的最大单项**。

### 1.2 反离子释放的结合自由能审计（Record–Manning / Lohman 离子计数）

对做 m′ 个离子对接触、结合后置换 ~m′ψ 个热力学关联反离子的配体：

$$\Delta G_{\rm ion} = m'\psi RT\ln\big([\mathrm{M}^+]_{\rm eff}\big),\quad K_d(\mathrm{eff}) = K_d(\mathrm{eff}_{\rm ref})\Big(\frac{\mathrm{eff}}{\mathrm{eff}_{\rm ref}}\Big)^{m'\psi}$$

其中胞内等效一价盐用经验换算 $[\mathrm{M}]_{\rm eff} = [\mathrm{K}^+] + \gamma[\mathrm{Mg}^{2+}]$，γ ≈ 70（二价 + 凝聚偏好）。若体外缓冲取 20 mM K⁺/0.5 mM Mg²⁺（eff ≈ 55 mM），胞质取 150 mM K⁺/1.5 mM Mg²⁺（eff ≈ 255 mM）：

| 有效离子对数 m′ | 胞质 Kd（25 °C 外推） | 相对宣称 0.15 nM 的劣化倍数 |
|---|---|---|
| 3 | ~6 nM | ~40× |
| 4 | ~20 nM | ~135× |
| 5 | ~69 nM | ~462× |
| 6 | ~236 nM | ~1.6×10³× |
| 7 | ~0.8 µM | ~5.4×10³× |

对多阳离子拟肽（侧链“阳离子富集”，净电荷常 +5~+8），m′ 取 5–7 是保守区间 ⇒ **胞质中真实 Kd 大概率在 0.1–1 µM 量级，而非亚纳摩尔**；37 °C 再加 ~3.5×（240 nM @ m′=5）。Mg²⁺ 单独波动即足以移动一个数量级（150 mM K⁺ 固定，Mg 0.5→3.0 mM：Kd 19→275 nM @25 °C、m′=5）。

**关键反证——依赖缓冲的成分**：把“锚定缓冲”改为更接近生理的 50 mM K⁺/1 mM Mg²⁺，胞质 Kd 立即只剩 3.1 nM @25 °C；换成 100 mM K⁺ 无 Mg，也只有 6.3 nM。**即体外测得的“0.15 nM”本身强烈依赖缓冲盐，这不是分子的固有属性**。

### 1.3 熵审计：ΔH 极负 + ΔS < 0 = “诱导折叠”，不是凹槽互补指纹

Kd = 0.15 nM ⇒ ΔG = RT ln Kd ≈ **−13.4 kcal/mol**（25 °C）。若 ΔH < −18 kcal/mol，则总熵 TΔS = ΔH − ΔG < **−4.6 kcal/mol**，即 **ΔS_obs < −15 cal·mol⁻¹·K⁻¹**。

反离子释放本应贡献**正的** ΔS（这是聚电解质结合的标志性熵驱动项，如氨基糖苷-RNA 体系）。总 ΔS 反而显著为负 ⇒ 必须存在更大规模的“自由度冻结”来压倒它：**配体转子锁死 + RNA 骨架/末端由动态系综折叠进一个深而窄的势阱**。这正是“配体把低盐下未折叠的 RNA 拉成某个非天然刚性结构（折叠-结合偶联）”的热力学指纹，与“配体以形状互补识别一个已存在的天然凹槽”的指纹（ΔS 应更有利/中性）截然相反。一个已天然折叠的凹槽无须支付如此高的重排熵。

### 1.4 ITC 可测性旁证

0.15 nM 的直接 ITC 属可疑区间：Wiseman 参数 c = [位点]·Ka，要 c≈50 需位点浓度 ~7.5 nM——在此稀释度下结合热与稀释热同量级，直接拟合 Kd < 1 nM 通常超出一体化 ITC 动态范围，除非用竞争/置换 ITC。且 ΔH 含缓冲质子化耦合项（对含可电离胺的多阳离子配体几乎必然存在），不加质子联接校正的“ΔH < −18”不能直接归因于 RNA 接触。

### 1.5 选择性（>10⁴）同样被盐稀释

若该分子 51%（模型值）的结合自由能来自非特异性反离子释放（见 §1.2/§4 相图），那么这部分**对所有结构 RNA 是公共项**：低盐下靶 RNA 与“对照发卡”在 FP 上的差异被各自的静电项整体放大，10⁴× 的“选择性”主要编码的是电荷密度/局部静电聚簇差异，而非唯一三维形状；进入胞质盐后长程静电被屏蔽、公共项收缩，**选择比随之坍缩**。细胞层面不存在 10⁴×——只有少量几何上相近的“真正互补”残余。

**小结 §1**：声称的“亚纳摩尔+极高选择性”在胞质离子条件下无法成立（数量级 0.1–1 µM 而非亚 nM）；ΔH/ΔS 指纹更支持“诱导刚性化折叠”而非天然凹槽互补。

## 2. 构象系综受挫与动力学陷阱：强力诱导折叠 → 错折叠死端

### 2.1 RNA 的低垒高异构化速率 vs 配体的深阱

RNA 二级结构重排（发卡成核/解链、错配滑移）活化能在 3–10 kcal/mol，毫秒—秒级完成；45-nt 含内环/三联体的基序在 37 °C/生理 Mg²⁺ 下处于 U（展开）、N（天然功能态）、M（潜伏错折叠，基线占 ~6%）的动态系综。**配体结合并不能“选择”N——它选择系综里与它互补最好的那个成员**。

### 2.2 “伪增益”的来源：低盐测定态 ≠ 胞内天然态

把模型锚定于宣称的 ITC 数据（§1.2）：天然位点 N 胞质 Kd ≈ 240 nM（37 °C）；**而该配体几何上真正贴合的那个诱导态 M（错折叠/熔融样、芳香平面完全暴露、阳离子多点接触）胞质 Kd ≈ 13 nM、低盐缓冲中 ~20 pM**。含义有二：

1. 低盐 ITC/FP 测到的“超高亲和力”很可能就是**配体诱导形成的 I·L 复合物**——一个 M 类构象，不是胞内天然功能构象（ΔS<0 正是诱导折叠的证据）；
2. 在胞质条件下该配体对 **M 比 N 强 ~18×**。于是对每条靶 RNA：N ⇌ M ⇌ M·L 的净效应是把 RNA 拖离天然态、锁进**错折叠死端**——这不是“稳定功能构象”，而是构象捕获伪增益（conformational-capture pseudo-gain）。

### 2.3 动力学陷阱的时间结构（模型：U⇌N⇌M + L 结合）

模拟中速率取 k₀=10⁶ s⁻¹、N→U 解折叠势垒 ~6 kcal/mol（N 寿命分钟级）、N→M 直接滑移 k≈0.02 s⁻¹，配体再结合 M 快于其回到 N ⇒ 时程呈现：
① 毫秒级 U→N/M 折叠；② 秒级 N·L 平台 + M·L 缓慢爬升；③ **分钟—小时级 N→M→M·L 净转化**。即配体的占位随暴露时间持续恶化，慢性给药下功能态被持续抽干——这与“必然锁定功能构象”相反。

### 2.4 转录组层面：数万个相似基序的灾难性混淆与核糖体应激

宿主结构 RNA 的丰度以 µM 计（HeLa 每细胞 ~10⁷ 核糖体 ≈ 2–5 µM，rRNA 占总 RNA 质量 ~80%；tRNA ~10⁷/细胞且高度折叠）。一个对“任何 RNA 发卡/内环”都带 ~1/3 静电公共项 + 中等凹槽亲和的多阳离子芳环配体，其**可能的脱靶位点总数远超靶 RNA**（10²–10⁵ 倍），且 rRNA/tRNA 基序几何上与病毒基序高度雷同。后果：

- **核糖体应激**：占据 18S/23S rRNA 功能环、核仁装配中间体 → 核仁应激/核糖体病样表型（氨基糖苷在 16S 的既定先例说明此类占用真实存在，非选择性的阳离子配体只会更宽）。
- **tRNA / sn(o)RNA / lncRNA** 动态中间体被锁定 → 错误装载、剪接/加工紊乱。
- **全转录组“假阳性展开”**：配体在成千上万位点诱导局部错折叠，结构组学（DMS/SHAPE）与翻译组表型会给出“广泛折叠扰动”信号；若只用靶 RNA 探针分析，极易把这种全局扰动误读为“高特异性抑制”。

## 3. 转录组竞争：非平衡结合相图模拟

### 3.1 四态动力学 + 反离子活度梯度 + 100 竞争位点

- **4 态动力学系综**：U ⇌ N ⇌ M，配体结合 N（N·L=“预期占位”）与 M（M·L=死端），全部反应可逆、满足细致平衡，速率先验依赖温度与盐。
- **反离子活度梯度方程**：每个位点 Kd 用 §1.2 的对数盐公式由 (m′_i, ψ) 与等效盐 [K⁺]+γ[Mg²⁺] 解析计算——低盐下所有位点（靶与脱靶）同时变“粘”，即低盐高亲和普遍化。

## 4. 结论

1. 宣称的“亚纳摩尔、>10⁴ 选择性”来自低盐缓冲中的反离子释放熵（模型归因 ~1/2，且随 m′ 增高单调变大），**不能外推至胞质离子强度**；真实靶位点 Kd 数量级为 0.1–1 µM。
2. 极负 ΔH + 负 ΔS 指纹指向**配体诱导的刚性化折叠**，低盐测定态本身可能即非天然构象——分子的“互补表面”更像贴合错折叠/熔融态（模型 Kd(M)/Kd(N) ≈ 1/18），因此“锁定功能构象”的断言被逆转：它优先把 RNA 锁进**错折叠热力学死端**（构象捕获伪增益），并随时间把天然态抽干。
3. 在 µM 级宿主结构 RNA（rRNA/tRNA/lncRNA 动态中间体）的竞争与离子波动下，有效靶向自由度降至 ~10⁻³，脱靶占用主导，构成核糖体应激与全转录组折叠扰动的物理基础——**“绝不影响宿主折叠网络”不成立**。

**整体裁决**：在给定的表征证据下，“必然精准、不影响宿主”的结论不成立；该分子更应被描述为**胞质环境下以中低亲和（µM 级）非特异性黏附于整个结构 RNA 组的构象干扰剂**，其抑制表型无法与转录组毒性解耦。

## 5. 建议的证伪/验证实验（若团队想挽回主张）

1. **生理缓冲竞争 ITC/荧光**：在 150 mM K⁺/1–3 mM Mg²⁺ + 2 mM 亚精胺/RNA 稳定背景中重测 Kd 与 1/Ka vs log[M⁺] 斜率（得真实 m′ψ），报告胞质 Kd 与“选择性比 vs 盐”曲线。
2. **置换/竞争 ITC + 质子联接校正**，确认 ΔH 归属；用与 Mg²⁺ 竞争实验区分“配体替代 Mg²⁺”与“形状互补”。
3. **结构证据**：共晶/冷冻电镜或 NMR 证明胞质折叠条件下的天然态复合物（而非低盐诱导态）；做 SHAPE/SELECT 显示靶 RNA 在 +配体时仍占天然拓扑。
4. **活细胞靶点占有**：可点击类似物 + 化学交联/亲和富集测序（如配体-生物素+RNA 下拉），定量“占天然病毒位点 vs 占 rRNA/tRNA”的比例；配核糖体谱/RUNX 等应激读表。
5. **转录组结构扰动**：细胞内 DMS/SHAPE-MaP 差异比较病毒感染 ± 配体，验证是否出现广谱折叠扰动（预测：是）。
