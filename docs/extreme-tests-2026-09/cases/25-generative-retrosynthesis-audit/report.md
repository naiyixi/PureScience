# 基于扩散模型的 TNIK 抑制剂生成算法：病态几何与反合成阻遏审查研报

**审查对象声明**：某生成化学平台宣称其基于 SE(3)-等变扩散模型在 TNIK 口袋内生成了 10 个"前所未见全新拓扑、Glide/AutoDock < −11 kcal/mol、高度类药、3 步内可快速化学合成"的候选分子。

**方法学工具**：`generative_molecule_reality_audit.py`（RDKit 2026.03 + MMFF94s 力场 + PAINS/Brenk/NIH FilterCatalog + REOS 子集 + SAscore contrib）。

**数据诚实性第一原则（必读）**：本研报**不做分子对接、不运行显式溶剂化力场**。演示集中的
`dock_claimed` 列为"仿真输入"，代表平台宣称值（审查对象），全部 14 个分子均为**为方法学演示构造的仿真替代物**
（真实平台输出应通过 `--csv` 入口替换）。因此：① 表中任何"声称得分"不是本工具的测量值；
② 所有应变/张力数为真实计算的 MMFF94s 气相值，可作为 OPLS4/AMBER 显式溶剂精修后"构象崩塌"方向与量级的内在判据。

## 2. 方法学总览（管线 = 六道反向物理闸门）

`generative_molecule_reality_audit.py` 对每个分子依次执行：

1. **一维/二维类药性**：MW / cLogP / HBD / HBA / TPSA / RotB / Fsp3 / 芳香环 / 立体中心 / **QED** / 类药五规则违例数；
2. **合成可达性**：**SAscore**（RDKit contrib）+ **模板化反合成可达性**：仅枚举药学上常用的生产性偶联切断（酰胺、酯/硫酯、磺酰胺、联芳基 Suzuki、C(芳)–N 胺化 Buchwald/SNAr、芳基–羰基），每个切断把产物拆为两段"补氢砌块"，用"两片段 SAscore ≤ 3.0 ⇒ 商业/简单可得"近似判据，得 `route_score = 可行切断/候选切断` 与"3 步可合成启发式"；
3. **结构警示**：RDKit **PAINS_A/B/C** + **Brenk** + **NIH**（FilterCatalog 共 765 条）＋ 自定义 **REOS 反应性子集**（烷基卤、Michael 烯酮、醛、环氧、异硫氰酸酯、叠氮、过氧、硝基、酸酐等）；
4. **环系拓扑与张力**：环大小直方、**7–9 元中环**/3–4 元小环标记、螺/桥/稠合计数、环系复杂度审计指数、文献环张力估值（按环尺寸与环内 sp3 占比折算）；
5. **构象/扭转张力（MMFF94s）**：ETKDG 构象系综 → 最低能构象；对每个可旋转的**非末端重原子扭转**做"固定 4 原子"的 relaxed 扫描（12–18 点），输出每键扭转能垒、π-共轭键平面化惩罚，并做分子级求和 `planar_strain_kcal`；
6. **帕累托审计**：在声称目标 (QED↑、声称对接↓、SAscore↓) 与"现实修正目标"（对接 + 应变、闸门化）上分别求非支配集 → 图 2。

硬闸门（任何一条即 `gate`）：命中 PAINS 或 REOS、环张力估值 ≥6 kcal/mol、SAscore>4.2、MW>550、cLogP>5.5、QED<0.45、Brenk/NIH 命中提示（NIH/Brenk 计入警示但不单独成门）。

## 3. 机制审查：为什么等变扩散天然产出"病态几何假象"，为什么刚性对接会给高分

### 3.1 连续坐标空间采样的几何病态 —— 物理化学/量子化学可达性视角

SE(3)-等变扩散模型在**连续三维坐标**上对原子位置加噪/去噪，其训练目标通常是坐标空间的
(去噪) 损失与等变网络势；这类目标**不直接最小化价键能面**，于是采样几何的病态是系统性而非偶然的：

1. **目标函数错位**：扩散损失衡量"预测坐标 vs 晶体/生成坐标"的距离，属于几何统计量，不含键伸缩/键角/二面角/非键排斥的物理势。模型学到的是"蛋白口袋条件坐标的总体分布"，而不是能量驻点。去噪末态因而大量落在**价键能面的鞍点与高能斜坡**上（坐标可达、化学不可达）。
2. **范德华重叠**：非键相互作用是**多体、短程、指数式**的。坐标空间的均方损失对"某两原子距 1.4 Å（正常应 ~2.9–3.4 Å）"只施加有限梯度，两个球重叠只要在训练分布里不罕见就会被"容忍"。等变性只保证"旋转平移一致"，不保证"不重叠"。
3. **非平面芳香环**：芳香性是一种**非定域电子结构**，无法由单个原子的坐标分布表达。模型以原子为单位采样，环上各原子面外位移的统计方差并不收敛于 0；"看起来是苯环但有一个 C 抬出平面 0.6 Å"的结构在去噪末态里常见——其能量代价（环面外扭曲常达 10+ kcal/mol 量级）不在生成目标里。
4. **超张力中环（7–9 元）**：环张力是**拓扑**属性（跨环 H···H、角张力、扭转张力；环烷烃：环丙 27.5、环丁 26.3、环戊 6.2、环己 0、环庚 6.2、环辛 9.7、环壬 12.6 kcal/mol，见 §3.3 表）。扩散模型以坐标拟合新颖拓扑，没有"成环 = 成键＝满足环内距离边界"的硬约束，极易产出"中环当作铰链连接"的伪新颖——环看起来闭合了，但跨环原子实为**空间重叠**。
5. **不可判据的附带项**：电荷、互变异构、质子化态、立体化学在坐标采样里都不稳定；"新颖"在此意义上多为**坐标拼接的新颖**而非可合成分子的新颖。

> 一句话：SE(3) 等变扩散产出的是**"在蛋白口袋条件概率下最像药的坐标点集"**，而不是**"在价键能面上可达的分子"**。二者在 GAN/扩散类生成化学中的鸿沟就是本次审查的对象。

### 3.2 为什么刚性对接网格会给这些病态几何"极高得分"

- 刚性子网格（Glide 早期阶段/经典 AutoDock 评分）在给定"固定蛋白 + 固定配体采样构象"时，
  打分项对**配体内非键排斥采用软化势**、且**不（充分）惩罚配体内部键/角/扭转应变**；
  打分主要奖励蛋白-配体接触（疏水、氢键几何、静电）。于是"两个芳环在网格里能塞进疏水槽"这一条
  足以给 < −11 kcal/mol 的分数，而"塞进去的那个几何要把芳环扭出平面 40°、把中环跨环压到 1.9 Å"
  的成本**不进入刚性打分或只以软化项轻微体现**。
- 缺乏显式水与结合熵：去溶剂化惩罚不完整、构象熵被忽略——脂溶性刚性片（如 G04 型轮烯）"埋入疏水区"得分虚高。
- 由此，**对接得分轴的数值在"几何真实性修正"之前是不可信轴**。

### 3.3 为什么显式溶剂化力场（OPLS4/AMBER）最小化后构象"崩塌"（应变 > 15 kcal/mol 的路径）

一个可对接的"高姿态"必须自付其内部应变。一旦换用显式溶剂力场做**无约束局部能量极小化**：

```
ΔE_bind(可维持) = ΔE_protein-ligand(刚性子网格宣称) − ΔE_ligand_strain(pose) − ΔE_desolv …
```

我们把能算的配体内部项（MMFF94s，kcal/mol）量化于下——它们的方向在 OPLS4/AMBER 中一致：

| 几何病态 | 量级（文献/估值） | 本审查实测 |
|---|---|---|
| 芳香环面外扭曲 | 每 10° 面外 ~2–5 | —（模型原子坐标病态，需 pose 级检查） |
| 中环张力 7/8/9 元 | 6.2 / 9.7 / 12.6（环烷烃） | G09(8 元) 环应变估值 7.3；G04(7 元) 2.7 |
| 4 元小环/β-内酰胺 | ~26.3（环丁烷）；β-内酰胺酰胺共振损失 + | G05 环应变估值 13.2 + NIH:betalactam |
| 扭转能垒（中位） | — | 对照 6.9 vs 生成 9.3 kcal/mol |
| π-共轭键平面化惩罚 | — | 对照 0–3；生成物最高 49.5；G10 累计 69.9 |
| 旋转阻塞扭转（>35） | 相对转动在结合温度下不可达 | 生成物 1 处 / 对照 0 处 |

以配对 G03 为例：其"平面铰链姿态"相对自身最低能构象要付出 **14.3 kcal/mol** 的内部应变，
而它宣称比对照多赢的幅度只有 12.2 − 8.6 = **3.6 kcal/mol**。也就是说：**分子为"显得很适配口袋"所扭曲的几何，
其可测量应变是它能"赢得"的表观结合增益的近 4 倍**。任何认真的力场最小化都会让这类姿态松弛回低能
折叠/扭转构象——蛋白接触随之丢失，即所谓"结合构象崩塌"。把 15 kcal/mol 作为"崩塌判据"是保守的：
G01/G03/G10 的应变修正（9.4 / 14.3 / 69.9）都进入或超过该量级。

## 5. 反合成可行性拦截（量化）

- 方法：仅对"生产性偶联断键"做切断 → 两片段"补氢砌块" → 片段 SAscore ≤3.0 ⇒ 可行。对照与多数近类似物生成物 route=1.0；
  **G04（刚性稠环无偶联断点）与 G07（烯酮无偶联位点）route=0**，即"没有任何常用偶联路线可 3 步组装"。
- 重要补充：SAscore 与"断键可行"只回答"能不能造"，不回答"造出的姿态是否可维持"。G01/G03 证明——**可以买到 2,6-二甲基苯胺 /
  2,6-二甲苯基硼酸，但接上骨架后几何即失格**。因此对"3 步可合成"的验收必须 = 合成路线 × 中间体商业可得 × 结合姿态应变三项同时通过。
- 真实工业替换：将"片段 SAscore ≤ 阈值"换成对 ZINC/REAL、eMolecules 等砌块库的精确匹配（见 §7），阈值与断键模板可按机构内部规则调整。

---

## 6. 结论与建议

1. **桌面审查对"10/10 全部高活性新颖类药可合成"的系统性反驳成立**：6 个直接出局，2 个（G01/G03）在应变修正下表观优势被吞掉，1 个（G02）优势缩小到统计噪声内，仅 1 个（G04）二维无法证伪、只能要求真实重对接与活性验证。声称的**帕累托前沿是建立在不可信轴上的假收敛**。
2. **必须向平台索取的可复现证据（验收清单）**：
   - 每个候选的**原子级 3D pose（SDF/PDB）+ 去噪轨迹与最终几何散度**；我们可据此用 `strain_of_pose()` 直接算 E(pose)−E(global-min)；
   - 用**同一分子 SMILES 重对接 + 重打分**（非生成时坐标），并报告 Glide/内部分数函数；
   - **显式溶剂力场（OPLS4/AMBER）局部最小化与约束 MD** 的应变报表；以 ΔE_strain < 5 kcal/mol 为可接受门槛；
   - **实测合成路线 + 商业砌块报价**（反对 3 步宣称）；对每步给出可达性依据；
   - 报告**PAINS/REOS/Brenk/NIH 命中清单**与 SAR 数据点（剂量-活性曲线），而不是单个对接数；
   - 声明所用**扩散目标函数是否含价键/应变项**、坐标噪声幅度、芳香环平面性约束与成环图约束。
3. 建议在生成管线的损失/重采样后处理中加入：价键与范德华最小化、芳香性/共平面惩罚、环尺寸与张力约束、PAINS/REOS 硬过滤、反合成模板预检——否则"新颖+高分"仅是坐标空间假象。

## 7. 局限与声明（方法论边界）

- **输入为仿真**：分子集与声称得分是为演示审查流程而构造；任何指向真实平台的结论必须以真实输出复跑后作出。
- **力场**：应变/扭转值为 MMFF94s 气相代理量。OPLS4/AMBER + 显式水会更严厉（加去溶剂化与熵），方向与本报告一致；
  未跑 MD 与 QM（如平面化精确值需 DFT），故所有 kcal/mol 数字标注为"代理量/估值"，并只在**同一分子内相对比较**时使用。
- **环张力**为文献单环值按 sp3 占比折算的估值，非逐分子 QM 计算。
- **反合成**为"生产性偶联断键 + 砌块 SA 近似"启发式，未接入真实砌块/模板库（给出替换接口与说明）。
- 桌面二维审查只能**证伪**（指出硬伤），不能**证实**活性：唯一能证伪 G04 型分子的，是真实重对接、力场最小化与实验活性。
