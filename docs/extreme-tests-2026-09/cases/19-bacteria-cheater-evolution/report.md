# 合成生物治疗中作弊者突变体反噬与群体感应解耦的生态演化审查

**对抗性工程假想审查报告（机制驳斥 + 空间演化动力学推演）**

- 审查对象：SLC 同步裂解释药工程菌（原位合成高细胞毒性嵌合纳米抗体-胞嘧啶脱氨酶等载荷，AHL 群体感应触发同步裂解，形成“扩增-裂解-再扩增”脉冲释药）。
- 被审查声明（团队原话）：*“该回路在数学上具有绝对稳定的周期性释放节律……只要瘤内存在营养供给……绝无可能在临床疗程中发生治疗耐药与药物释放衰竭。”*
- 审查结论（预判摘要）：**该声明不成立。** 其失效并非来自营养供给波动或线路动力学失稳，而来自工程菌群作为一个“社会群体”在演化博弈意义上的内在脆弱性——由复制错误自发产生的“作弊者（cheater）突变体”经由同步裂解这一**周期性强选择瓶颈**被指数放大，在临床时间尺度内几乎必然导致群体感应—裂解回路的“生态坍缩”与有效释药归零。三维/二维空间结构（致密实体瘤的物理阻隔与生态位局限）能**推迟但无法豁免**这一坍缩。

## 1. 结论摘要与判定表

| 团队声明点 | 判定 | 依据 |
|---|---|---|
| “数学上绝对稳定的周期释放节律” | **不成立** | 只有在突变负荷 μ→0 的极限才近似成立（本工作 μ=0 对照组确实稳定）。任何现实 μ≥10⁻⁶/代的损失功能突变通量，都使“稳定不动点”只是亚稳状态（metastable）。|
| “只要存在营养供给即可稳定数月” | **不成立** | 坍缩瓶颈不是营养，而是**自私突变体通过裂解瓶颈的逐脉冲富集**与**空间生态位被作弊者占据**。营养充足只保证作弊者有资本扩张。|
| “绝无可能在疗程中发生耐药与释放衰竭” | **不成立** | ①临床量级接种物（10⁶–10⁹ 个细胞）以 μ 携带**预存作弊者储备**；②每个裂解脉冲对非裂解突变体构成 ~1/s（s 为存活分数，典型 2%–5% → 20–50 倍/脉冲）的选择放大；③一旦作弊者分数跨过临界分界线 q_c，脉冲振荡在 **2–4（理想混合）至 ~8–32（空间实体瘤）个周期内熄灭**。|

**风险等级：高（设计级缺陷，非工艺级缺陷）。** 这是演化生物学第一性原理（群体感应 = 公共品合作，天然易被“搭便车”剥削）在合成线路上的必然体现，已在铜绿假单胞菌 lasR 作弊（Sandoz 2007）、群体感应合作与冲突（Diggle 2007）、群体控制线路“激活数天后出现逃逸突变体”（You 2004）等实验中被反复验证。

## 2. 机理推演：演化博弈论与复制子动力学

### 2.1 表型定义与收益矩阵

设正常菌群由两类个体组成：

- **合作者 Cooperators (C)**：合成 AHL（luxI⁺）、表达裂解盒与治疗载荷，支付双重代价——**合成代谢负担**（生长速率乘性折扣 `1−p`，p≈0.2–0.25）与**裂解风险/利他代价**（每个周期以概率 `1−s` 死亡并释放内容物）。
- **作弊者 Cheaters (D)**：因自发功能丧失突变而失去信号合成（luxI⁻）或/且失去对 AHL 的响应与裂解/载荷（luxR⁻ / 裂解盒⁻ / 载荷⁻）。**不产信号、不裂解、不释放载荷、不付负担**；仍占用营养与空间，且在裂解脉冲后**几乎全部存活**。

单周期（生长相 + 裂解脉冲）内的“收益”由两个效应构成：

1. **生长相收益差**（负担驱动）：合作者比作弊者慢 `p`。
2. **脉冲瓶颈收益差**（死亡不对称驱动，决定性）：脉冲只清除合作者（含其投入生态位的部分回收），作弊者不死亡。

复制子动力学（生长相内）写作：

```
dC/dt = g0·(1−p)·N/(Kn+N)·C − (裂解损失)
dD/dt = g0·N/(Kn+N)·D + μ·g0·(1−p)·N/(Kn+N)·C   （μ 为每次合作者分裂产生作弊者的概率）
dA/dt = α·C − γA·A                              （共享 AHL 库，仅合作者分泌）
```

其中“作弊者无偿窃取的公共品（public good）”在本情境中具体化为：合作者维持的**可定殖生态位**（肿瘤坏死核心内有限的营养/空间），合作者周期性裂解所**释放并回收的营养物质与空位**，以及全体共享的群体感应公共信号。作弊者零成本享用这些，却不为载荷释放贡献分毫。

### 2.2 逐脉冲富集映射：为什么“几个周期就熄灭”

这是本审查最核心的单步动力学。设某次裂解脉冲前作弊者分数为 q = D/(C+D)。脉冲清除合作者的 `(1−s)`，作弊者不变。脉冲后的分数满足：

```
q' = D / (D + s·C) = q / (q + s·(1−q))                      (1)
```

当 `q ≪ 1` 时：`q' ≈ q / s`。即**每个裂解脉冲把作弊者分数放大 ~1/s 倍**。s=0.05 → 每脉冲 ×20；s=0.02 → 每脉冲 ×50。反向看，脉冲本身就是一个**对“非裂解表型”逐周期施加恒定强选择系数**的演化屏幕——这不同于任何无选择压力的随机漂变；即使作弊者初始为零，只要在某一脉冲前出现过哪怕一个作弊者克隆，其后 2–4 个脉冲内即可跨过临界线。

非线性分界线（“跨过之后信号永远无法再越过激活阈值”）来自“作弊者稀释信号 + 占据承载”的双重效应：

- **信号稀释**：AHL 分泌仅来自合作者；当作弊者占多数而合作者绝对数不足时，A 的稳态值 `α·C*/γA` 无法达到激活阈值 Ath，**裂解永不触发**——振荡器死亡。
- **承载排挤**：肿瘤生态位承载 K 有限（空间/营养）。合作者要达到阈值需 `C ≥ C* = Ath·γA/α`。若作弊者已占分数 q > q_c，则剩余承载 `(1−q)·K < C*`，合作者无法凑足触发规模。

在全局 logistic 生态位中，临界作弊比例

```
q_c ≈ 1 − C*/K                                     (2)
```

本工作两个尺度：临床混合模型 K=10⁹、C*/K=0.25 → q_c≈0.75；同承载 0-D 随机模型 K=3.2×10³、C*/K=0.625 → q_c≈0.375（图 1b 竖线）。

由 (1) 迭代，作弊者由初始比例 q₀ 增长到 q_c 所需的脉冲数：

```
n* ≈ ln(q_c / q₀) / ln(1/s)                         (3)
```

q₀ 的两个来源：**去新突变累积**（生长相每代以 μ 产生，跨过若干脉冲积累）与**预存储备**（接种物中已存在，q₀ ≈ μ·N_inoc/K 或制造批次的真实作弊比例 cheat0）。图 1 以 cobweb 图显示该映射的发散性：对 q₀=2×10⁻⁵、s=0.05，只需约 3 个脉冲 q 即从 10⁻⁵ 跳到越过 q_c——**这正是“短短几个周期内彻底熄灭”的数学根源**。

### 2.3 为什么“突变率只有 10⁻⁶/代”也不安全

- 单基因功能丧失突变率 ≈ 10⁻⁷–10⁻⁶/碱基/代；使 luxI/luxR/裂解盒/载荷多基因任一同源失活的功能丧失率 ≈ 10⁻⁶–10⁻⁴/细胞/代，恰为审查设定范围。
- 去新突变由**每次分裂**的复制错误产生，而菌群每脉冲发生数千至数千万次分裂：临床菌落（K≈10⁹）每个周期产生 ≈μ·(1−s)·C* ≈ μ×2.4×10⁸ 个新作弊者——即使 μ=10⁻⁶ 每周期也有数百个，作弊者**确定性**出现（本工作 well-mixed ODE 在所有 μ≥10⁻⁶ 于 2–4 脉冲内坍缩，图 4 黑色菱形）。
- 在小菌落（K≈3×10³，更贴近单菌落实体瘤灶）中，每脉冲分裂 ~2×10³ 次：μ=10⁻⁶ 时新作弊者期望 <0.003/脉冲 → 出现时间是随机的 Luria–Delbrück 等待（本工作 μ=10⁻⁶ 多数种子 200+ 脉冲后才坍缩；空间版 μ=10⁻⁵ 在 650 τ 内甚至未出现）。**但这并不构成安全**——临床接种物规模（10⁶–10⁸）意味着作弊者在注射时已预存（q₀≈μ），且制造与扩增批次的“携带菌群”随每代持续产生作弊者。本工作 cheat0=1% 与 3% 场景显示：即使 μ 再低，只要预存作弊者 ≥1%，坍缩分别发生在 8 与 3 个脉冲（~103 τ 与 ~62 τ）。结论：**“突变率低所以安全”混淆了突变产生率与选择放大率**。

### 2.4 低氧/坏死核心微环境的放大作用

实体瘤核心的坏死、低氧、营养梯度对合作者/作弊者的博弈有三个方面的影响（图 3 的空间模型即以此构建）：
1. **合作者代价上浮**：坏死核心中载荷合成与维持裂解线路的代谢负担难以回收，合作者有效生长率进一步下降，作弊者的相对优势 p 增大。
2. **生态位供给有限**：致密 ECM/缺氧限制了可定殖承载 K，使 C* 更接近 K（q_c 更低），临界线更容易被越过。
3. **空间避难所**：作弊者一旦在局部成簇，可在空间上屏蔽自身区域内的 AHL 信号/裂解（自我庇护），而合作者区域仍周期性裂解——作弊者持续存活的**空间异质性**（Nadell 2016; Xavier & Foster 2007）在短时间反而给了合作者小生境，但长期仍被作弊者扇区吞并。

## 3. 仿真方法

### 3.1 三个互补模型

| 引擎 | 类型 | 用途 | 承载/规模 |
|---|---|---|---|
| **Well-mixed ODE**（`run_wellmixed`） | 0-D 事件驱动常微分方程，logistic 承载，裂解为阈值事件，确定性突变源 | 临床尺度（K=10⁹）“无限混合/确定性”上界 | K=10⁹，s=0.02，C*=0.25K |
| **Well-mixed stochastic**（`WellMixedStochastic`） | 0-D 整数出生-死亡 + 裂解事件，泊松出生、二项式存活/突变 | 与空间格点**同承载、同随机性**的“完全混合”对照 | K=3200，s=0.05，C*≈2000 |
| **Spatial lattice**（`SpatialLattice`） | 2-D 格点 Monte Carlo：营养扩散+血管再灌注+Monod 吸收；接触抑制分裂（空邻位）；共享 AHL 库 + 阈值裂解事件；分裂时功能丧失突变；作弊者以**空间克隆扇区**扩张；有限肿瘤生态位盘 | 致密实体瘤空间环境 | L=140 格点，肿瘤盘半径≈52，C*≈2000，s=0.05 |

三个引擎共享同一套“表型规则”（负担、s、C* 由 Ath·γA/α 标定），差异仅在**是否引入空间结构**，从而可直接对比空间效应。时间单位 τ = 未负担细菌的倍增时间；长度单位 = 细胞直径（格点边长）。

脉冲（有效剂量）定义：一次裂解事件释放的载荷 ∝ 本次裂解的合作者数量 `(1−s)·C_before`。
**功能失效（有效剂量熄灭）定义**：脉冲幅值 < 平台期幅值中位数 ×10%，**或**振荡停滞（脉冲间隔 > 中位间隔 ×4，即“振荡器死亡”——幅值未衰减但不再触发）。用 `analyse_pulses()` 稳健识别（报告各处 n\* 即按此定义统计的“有效剂量脉冲数”）。

### 3.2 关键参数（表，均为无量纲化示意值）

| 参数 | 含义 | well-mixed ODE | 0-D 随机/格点 |
|---|---|---|---|
| g0 | 最大比分裂速率 (=ln2/τ) | 0.693 | 0.693 |
| burden p | 合作者合成负担 | 0.25 | 0.22 |
| s | 单脉冲存活分数 | 0.02 | 0.05 |
| γA, Ath | AHL 衰减率、激活阈值 | 1.0, 2.5×10⁸ | 0.5, 0.5 |
| α | AHL 分泌率/合作者 | 1.0 | 1.25×10⁻⁴ |
| C* | 触发脉冲所需的合作者数 | 0.25K | ≈2000 |
| μ | 功能丧失突变率/分裂 | 扫描 10⁻⁶–10⁻⁴ | 扫描 10⁻⁶–10⁻⁴ |
| cheat0 | 接种物预存作弊比例 | 0（去新） | 0 / 0.01 / 0.03 |
| 承载 | — | 10⁹ | 3.2×10³ / 肿瘤盘 |

营养：格点中营养场 `nut` 以血管再灌注 `k_sup·(N0−nut)` + 扩散 + Monod 吸收演进。营养梯度/坏死核心本身不是本模型坍缩的主要驱动（调节供给速率可改变脉冲周期而不改变定性结论），空间效应的主要载体是**接触限制分裂、克隆扇区扩张与有限生态位排挤**。

## 4. 结果

### 4.1 对照组（μ=0）：节律确实稳定
- 空间格点 μ=0：**57 个稳定脉冲 / 500 τ**，幅值平台稳定（≈0.84→1.0 归一化）；0-D 随机 μ=0：**342 个脉冲 / 3000 τ** 不熄灭。
- 这证实模型本身能复现团队声称的“稳定周期释放”——**从而把坍缩的责任明确指向突变负荷，而非线路/营养问题**。

### 4.2 Well-mixed ODE（K=10⁹，临床确定性极限）
μ=10⁻⁶、10⁻⁵ → 仅 **3** 个有效脉冲；μ=10⁻⁴ → **2** 个。与式 (3) 的解析估计 `n*≈ln(q_c/[μ(1−s)])/ln(1/s)` 吻合（q_c=0.75, s=0.02 → 2–4）。**理想混合、营养无限供给下亦在 2–4 周期内熄灭**——直接反驳“绝对稳定”与“只要营养充足即可稳定数月”。

### 4.3 完全混合（0-D 随机）vs 致密实体瘤（空间格点）：有效脉冲数的 μ 依赖

| μ (功能丧失/分裂) | 0-D 随机 well-mixed（K=3.2×10³，8 种子中位数±IQR） | 空间格点（L=140，6 种子） |
|---|---|---|
| 0 | 稳定（≥342，无熄灭） | 稳定（≥57，无熄灭） |
| 10⁻⁶ | 224（155–274） | 未测（去新几乎不发生） |
| 10⁻⁵ | 15（6–22） | **650 τ 内不熄灭**（≥76 个脉冲，截尾） |
| 3×10⁻⁵ | 7.5（4.5–20.5） | **32**（全种子一致） |
| 10⁻⁴ | 4（3–6.75） | **14**（全种子一致） |
| 10⁻⁵ + 预存 1% | — | **8**（~103 τ） |
| 10⁻⁵ + 预存 3% | — | **3**（~62 τ） |

**空间效应（图 2、图 4）**：
1. **推迟但不豁免**：同样 μ 下空间格点将有效脉冲数延长约 3–4 倍（μ=3×10⁻⁵：8→32；μ=10⁻⁴：4→14）。原因：作弊者以克隆扇区缓慢推进、受接触抑制与空间黏滞，且需先填满有限生态位（空间黏滞延缓作弊者扩散的机制与 Nadell 2016 / Xavier & Foster 2007 一致）。
2. **“静默接管”现象（图 3，重要工程含义）**：空间模型中作弊者分数 q 可在脉冲间升至 0.3–0.97，而每次脉冲仍以接近满幅释放（图 3 底部：脉冲 5–13 归一化剂量仍 ~1.0–1.08），因为只要还有可扩张的空生态位，合作者仍能各自凑足 C\*。**幅值不衰减 ≠ 没有作弊者**；坍缩以“生态位饱和 → 振荡器骤停”方式发生在 ~t=150 τ（约 14 个脉冲），此前幅值曲线几乎平坦。若以“脉冲幅值监测”判断耐药，将完全失效。
3. **去新突变下限**：在小菌落中 μ≤10⁻⁵ 的去新作弊者出现属随机等待，空间版 650 τ 未见坍缩；但这仅说明单菌落规模的随机性，**不代表安全**——预存储备场景（1%→8 脉冲，3%→3 脉冲）显示临床现实（大接种物以 ~μ 携带作弊者）仍指向快速坍缩。真正“安全”只存在于 μ·N_inoc/K 低到可以忽略且逐代去新突变被压制的极限。

### 4.4 空间突变分布相图（图 3）
图 3 顶部七帧给出 μ=10⁻⁴ 去新突变下实体瘤盘的细胞相图演化（蓝=合作者、红=作弊者、白=空位）：
- t=15–60 τ：合作者菌落扩张，无作弊者（q=0），脉冲规律；
- t≈85 τ：边缘/内部出现首个作弊者小扇区（q≈0.03）；
- t=105–130 τ：作弊者扇区在历次脉冲中“杀不死”地扩张（q 升至 0.8），每次脉冲后作弊者保留、合作者重建；
- t≈150–160 τ：作弊者占据肿瘤盘主体、生态位饱和，合作者无法再凑足 C\*，**脉冲时钟死亡**（t≈152 τ 后无脉冲），有效剂量归零。

## 5. 局限与审慎声明

1. 本工作为**机理演示型仿真**：参数无量纲化、以 τ 为单位；数值量级（如“坍缩于第 n 个脉冲”）用于刻画**时间轴的数量级与定性规律**，不可直接外推为特定菌株/患者的临床预言。真实体内细菌倍增更慢、菌落结构更复杂、宿主免疫清除会施加额外选择压力（可能加速作弊者/敏感株清除）。
2. 空间格点中 AHL 以共享池近似（3OC6-HSL 小分子自由穿膜、瘤内混合快于裂解周期）。显式 AHL 扩散会引入“信号遮蔽”式的局部庇护（ECM 阻隔使作弊者簇局域稀释 AHL），在本报告为**增强**作弊者局部存活、方向性上不改变结论；更精细的屏障几何属于后续工作。
3. 未建模宿主免疫、肿瘤异质性生长、菌株定殖竞争与基因组多拷贝质粒丢失等；这些通常只会引入**额外**的逃逸/退化通道（如质粒丢失本身即一种“作弊”）。
4. 预存储备 cheat0 为人为设定场景，用于代理临床量级接种物中必然存在的低频作弊者；其与 μ 的换算见 §2.3。

## 6. 工程含意（简要）

1. **剂量监测指标须更换**：不能依赖脉冲幅值（其坍缩前平坦）；应监测作弊者分数 q 或信号/承载比例，或设计“作弊者敏感”的报告通路。
2. **降低可演化性而非仅降低 μ**：μ 压到 10⁻⁷ 以下只能把去新等待推后，不消除预存储备与 1/s 逐脉冲放大。需用“演化防火墙”（如必需基因回路、程序化成瘾/毒素-抗毒素对、多靶点载荷使单一基因失活不足以完全脱靶）抬高功能丧失的代价与多基因协同门槛（参见 You 2004 对逃逸突变体的早期警示）。
3. **减小脉冲选择压**：降低每脉冲富集因子 1/s 的办法（如提高存活分数 s、不彻底同步）会在**释药效率**与**演化稳定性**间形成张力；彻底解决需要让“存活”与“贡献载荷”耦合（作弊者存活即失效的绑定），这是设计上的开放问题。
4. 复发监控：若采用 SLC 平台，需将作弊者比例纳入 PK/伴随诊断指标，并预设“作弊者接管”后的补救策略（如次级可诱导自杀开关作用于非裂解表型）。
