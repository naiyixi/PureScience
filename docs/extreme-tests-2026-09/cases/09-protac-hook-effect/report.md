## 2. 数学模型的严密推导

### 2.1 体系与变量

密闭均相单反应器，总浓度给定：`E_tot`（E3，CRBN 或 VHL:VCB）、`T_tot`（靶点 BRD4，取单一有效结合位点）、`P_tot`（PROTAC）。自由浓度 `[E],[P],[T]` 为未知量。

平衡（质量作用定律）：

```
E + P ⇌ EP        Kd2 = [E][P]/[EP]                     … 二元（E3 臂）
P + T ⇌ PT        Kd1 = [P][T]/[PT]                     … 二元（靶点臂）
EP + T ⇌ PET      Kd1' = [EP][T]/[PET]                  … 三元（经 EP 路径）
PT + E ⇌ PET      Kd2' = [PT][E]/[PET]                  … 三元（经 PT 路径，同一物种）
```

热力学循环（微观可逆性）自动给出 `Kd1·Kd2' = Kd1'·Kd2`，故两条三元路径一致，且可定义唯一的**协同性因子**

```
α := Kd1/Kd1' = Kd2/Kd2'         (α>1 正协同；α<1 负协同；α=1 中性)
[PET] = α·[E][P][T] / (Kd1·Kd2)   （质量作用，唯一表达式）
```

**三条非线性质量守恒方程**（*不含* 任何 `P_free ≈ P_tot` 之类近似）：

```
T_tot = [T] + [PT] + [PET]
E_tot = [E] + [EP] + [PET]
P_tot = [P] + [PT] + [EP] + [PET]
```

未知量 `{[E],[P],[T]}`；每条方程都含有全部三个自由浓度（三元项把三条方程耦合），构成 3×3 非线性代数方程组，须数值求解。把 `[P]≈P_tot` 代入会系统性低估低剂量区自由 P 的消耗、错估峰值区质量分配（见 §2.3）。

### 2.2 参考性解析最优浓度公式（受控近似）

在 *P 相对两种蛋白大大过量、三元复合物只占质量一小部分* 的极限（即 `[E]≈E_tot/(1+x/Kd2)`, `[T]≈T_tot/(1+x/Kd1)`, `x=[P]≈P_tot`）下：

```
[PET](x) ≈ α·E_tot·T_tot·x /[(Kd1·Kd2)(1+x/Kd1)(1+x/Kd2)]
```

对 `log x` 求一阶条件 `d ln[PET]/d ln x = 0`：

```
1/x = 1/(x+Kd1) + 1/(x+Kd2)   ⇒   x² = Kd1·Kd2
P*_ana = √(Kd1·Kd2)
```

**该解析峰值位置不依赖 α、不依赖蛋白浓度**；α 只进峰值幅度的前置因子。dBET6 场景 `P*_ana = √(50×134) = 81.9 nM`；ARV-771 场景 `√(8×100) = 28.3 nM`。

> 标注（重要）：此公式是受控近似解，仅在图示 Panel A 中作为参考竖线（黑虚线）与精确数值峰（彩色圆点）并置对比；精确解保留全部质量守恒项，二者在蛋白浓度与 Kd 同量级时出现可测偏移（见 §3）。

### 2.3 为什么必须保留质量守恒（数值证据）

在 `P_tot=10⁻¹² M ≪ E_tot=T_tot=40 nM` 时，精确解给出游离 `[P] ≈ 2.2×10⁻¹³ M`——近 80% 的 PROTAC 已被大量过剩的 E/T 以二元复合物吸走，`[P]≈P_tot` 假设**在该区直接失效**。这正是 Hook 曲线**上升沿的物理来源**：低剂量时 PROTAC 是稀缺组分，被蛋白竞争性消耗。

### 2.4 Hook 右肢的解析渐近（"不可消除性"的量纲论证）

当 `x` 大到 E 全被占为 EP（`[EP]≈E_tot`）时，T 在 `PT` 与 `PET` 间分配：

```
T_tot = [T](1 + x/Kd1 + α·E_tot/Kd1)
[PET] ≈ α·E_tot·T_tot/(x + Kd1 + α·E_tot)·…   ⇒  x→∞:  [PET] ~ α·E_tot·T_tot / x
```

即 **Hook 右肢按 ~1/x（log-log 斜率 −1）衰减，永不归零**；α 只把"Hook 拐点"推向 `x ~ α·E_tot`。**无论 α 取多大，下坡臂都存在**；α 能抬高峰值、展宽窗口、把衰减起点右推，但无法"消除"衰减本身（数值证明见 §3.3）。

## 3. 数值求解、验证与敏感性分析

### 3.1 数值方法
- 变量做 `log10` 变换并加箱约束（保证正定性、`0<[P]≤P_tot` 等），用 `scipy.optimize.least_squares` 求解；沿 `log P_tot` 网格用上一格解做初值（continuation），保证在 12 个数量级上稳健收敛。每点 3 条质量守恒残差至 `≤1e-13` 相对量级。
- **自洽验证**：① 三方程残差 `≤1e-14~1e-15`；② 用求解出的自由浓度反算 `α_recovered = [PET]·Kd1·Kd2/([E][P][T]) = 10.000000`（精确还原输入的 α，验证微观可逆性与公式一致）。
- 峰位/峰幅用 `minimize_scalar` 在精确求解器上精修；半抑窗口 `Δlog10 P = log10(P_right_half) − log10(P_left_half)` 由 `[PET]=½[PET]_max` 两个交点线性插值得到。

### 3.2 主场景（dBET6-like, Kd1=50 nM, Kd2=134 nM, E=T=40 nM）

| α | [PET]_max (nM) | P\* (nM) | 左半峰 logP | 右半峰 logP | 半抑窗口 W (decades) |
|---|---:|---:|---:|---:|---:|
| 0.1（负协同） | 0.450 | 121.9 | −7.60 | −6.24 | 1.36 |
| 1（中性） | 3.77 | 121.9 | −7.62 | −6.19 | 1.43 |
| 10（正协同） | 16.2 | 121.9 | −7.71 | −5.95 | 1.76 |
| 50（强正协同） | 26.4 | 121.9 | −7.75 | −5.59 | 2.16 |
| **解析参考** | — | **P\*_ana = 81.9** | | | |

### 3.3 关键定量发现

1. **α 控制峰幅与窗口，几乎不移动峰位。** `P*` 在 α=0.1→50 间仅从 121.85 漂到 121.88 nM（万分级）；精确峰 ≈122 nM 与解析 82 nM 相差约 1.5×——源于 40 nM 蛋白浓度相对 Kd 不可忽略（质量守恒导致的有限浓度修正），方向、大小均符合理论预期。
2. **α 抬高峰值有硬天花板。** `[PET]_max ≤ min(E_tot,T_tot) = 40 nM`；α=50 已到 26 nM，α=10⁴ 时精确解 = 38.8 nM（仍差 1.2 nM 到上限）。协同性不可能把三元浓度推过蛋白当量的化学计量上限。
3. **Hook 不可消除（直接数值证明）。** 在 P_tot=10⁻⁴ M 高剂量下残存三元浓度占各自峰值的比例：α=1 → 0.42%；α=10 → 0.98%；α=50 → 2.9%；**即使 α=10⁴ → 也只有 63%**（其拐点已推到 ~α·E_tot=0.4 mM，故 10⁻⁴ M 仍在平台内，但随剂量继续上升必按 1/x 衰减）。**任何有限 α 都无法让右肢消失**，只改变它出现的浓度标度。
4. **半抑窗口随 α 展宽**（1.36→2.16 个 log 单位）：正协同"撑开"右侧剂量窗口——这与"负协同 PROTAC 在高剂量更像抑制剂、细胞学 Hook 更明显"（JMC 2018，四氢喹啉负协同物 1–10 µM 出现 BET 蛋白回升）一致。

### 3.4 次场景（ARV-771-like, Kd1=8 nM, Kd2=100 nM）
峰幅 0.93/6.7/21.3/30.1 nM（α=0.1/1/10/50）；`P* ≈ 68.3 nM`（解析 28.3 nM，偏移 ~2.4×）；窗口 1.22→2.08 decades。**结论同上**：峰值位置几乎与 α 无关，α 只调幅度/窗口。

## 4.【机制审查与反思】对"极短极硬 Linker → α 最大化 → 消除 Hook"假说的批判性反驳

该假说的逻辑链是 *短而刚性 ⇒ 双臂几何预组织 ⇒ 三元复合物协同性 α→∞ ⇒ 高剂量下三元复合物不减反增，Hook 消失*。三条独立的批判路径均使其不成立：

### 4.1 数学上：Hook 是化学计量的必然，α 无法消除（一等反驳，无需生化即可证伪）
- 三元复合物是 **1:1:1 化学计量**的桥接物种：它要求*同一个* PROTAC 同时挂住一个 E 与一个 T。剂量一旦使自由 P 的浓度高到"T 更可能撞上一个**游离** P（生成 PT）而不是一个**已被 E 占据**的 EP（生成 PET）"，T 就被吸进二元库，三元必然下降。
- 由 §2.4：右肢按 `~α·E_tot·T_tot/P` 衰减。**α 增大只把衰减起点右推到 `~α·E_tot`**；极限 `P→∞` 时 `[PET]→0` 对任意 α 恒成立。要做到让 Hook 在生理可达剂量之外，需 `α·E_tot ≫ C_max`——以 E_tot=40 nM、C_max~10 µM 计需要 α ≳ 数百到上千，超出任何实测体系（最好的 JQ1-VHL 体系 α=18）。**假说预设的 α"最大化"在数学上不存在极限值可"彻底消除"下坡臂。**

### 4.2 空间位阻/几何失配：短而硬恰恰经常 *降低* α（经验事实 + 结构机理）
- α 的正值来源于**连接臂两端出射矢量能同时朝对方蛋白表面伸展、并在界面形成"新生蛋白-蛋白/蛋白-配体接触"（de novo PPI）**。Linker 过短时两端出射矢量根本无法跨越 E3–靶点的口袋间距，二元占位相互排挤 → 三元构象处于高能应变态甚至不能共存 → α 反而崩塌回 ≤1；过硬则失去扭转自由度去匹配非共线出射角。
- **JMC 2018 直接实验证据**：同一三氮唑并二氮杂䓬（JQ1 型）系列内 **PEG-2（最短）协同性最低**、PEG-3 最高；四氢喹啉系列 PEG-2 亦最低；两系列**短 linker 都更不利于成三元与降解**（"PEG-2 linker length was too short for optimal PROTAC activity"）。而该系列负协同物（α<1）恰好在高剂量显示**更强的 Hook**。
- MZ1 结构（PDB 5T35, Gadd 2017）表明高 α 来自 PROTAC **"折叠嵌入"两蛋白间碗状界面并贡献 1933 Å² 新生埋藏面积**——这要求 linker 长度/柔性把两个配体送到能互相触碰的位置，再靠蛋白侧残基（Brd4 Glu383/Ala384 等 PPI 热点，突变 α 18→4 或 2→8）锁定。几何与界面热点共同决定 α，**不是 linker 越硬越高**。

### 4.3 诱导贴合能垒 + 熵-焓权衡：刚性化提高的不是稳定性而是自由能垒
- 诱导贴合模型下，三元稳定化 = 结合焓收益（新生 PPI）对 构象熵/去溶剂化 的净胜。过度刚性化把体系"预组织"到一个单一全伸展构象：若该构象与两蛋白真实界面并非完美互补，则每步结合都要先翻越把蛋白/配体从结合前状态推向该刚性格点的**能垒**——热力学上表现为对伴侣蛋白构象的苛刻选择（构象选择惩罚），动力学上表现为结合**活化能升高**。
- 柔性 linker 的熵代价换来的是"先绑一端、再在表面搜索到最优桥接构象"的多步可达性；这正是 SPR 三元动力学（Roy/Ciulli 2019, ACS Chem Biol）强调的：**决定降解速率的是三元复合物寿命（k_off），而能否快速形成取决于 k_on 与质量运输**。一个热力学 α 巨大但 k_on 被能垒拖垮的三元体系，在生理时间尺度上无法把 E3 募集到靶点，泛素化速率不升反降。

### 4.4 动力学（k_on / k_off）反例
- 极硬 linker 若带来"同时精确对齐"要求，使三元结合从两步级联（`E+P→EP` 再 `EP+T→PET`）退化为要求一次碰撞即满足全部几何约束的事件，k_on 受扩散—取向因子压制（小分子驱动的蛋白募集 k_on 量级 10⁵–10⁶ M⁻¹s⁻¹，二次结合步尤其脆弱）。
- SPR 数据显示：**相同靶点、正/负协同截然不同的三元解离速率**；MZ1 与 Brd2BD2/Brd4BD2 的长寿命三元对应更快初始降解，而与 Brd3BD2 因单氨基酸差异(E/G)而被**去稳定化**、半衰期缩短 ⇒ 降解率下降。**平衡 α 高 ≠ 动力学上可用的复合物**；降解系统实际"读出"的是三元复合物在 E3 泛素化机器旁滞留的时间窗，而不只是稳态丰度。
- 因此"把 α 推到最大"即使热力学上把 Hook 右推，也没有解决高剂量窗口外 T 以 PT 形态与 E 竞争、以及细胞内三元寿命有限这两件事；临床要管理的是 **Cmax 对活动窗口的越界**，而非指望一个不存在的"无 Hook"分子。

### 4.5 建设性结论（反假说的正面表述）
Hook Effect 的本质是 **PROTAC 的多价化学计量 + 两种二元复合物对有限蛋白的竞争**，在平衡层面**任何单分子参数都无法根除**，只能：① 提高 α（设计出射矢量/界面热点，合理 linker 长度，而非"越短越硬越好"）把活动窗口向右拓宽；② 保证 E3 丰度/可得性（E_tot 抬高即把 `α·E_tot` 拐点右推）；③ 从给药/药代端使体内浓度落在窗口内（剂量、控释、避免过高 Cmax），或利用亚化学计量催化剂量。临床上真正该担心的是"窗口很窄且负协同的分子"——那才是 Hook 放大、高剂量失效的分子。

> **一句话**：Kd1/Kd2 的 dBET6/ARV-771 场景参数有可追溯的实测锚点；α 与体内蛋白浓度属"仿真自由度/假设"；机制结论（Hook 不可由 α 消除、短硬 Linker 反而伤三元）同时得到数学必然性、实测 SAR（PEG-2 最差）与结构证据支持，不依赖任何未证实的参数值。
