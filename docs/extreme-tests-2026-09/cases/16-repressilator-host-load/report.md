# 合成基因振荡器的"强力驱动方案"审查研报

## —— 全细胞资源分配限制下 Repressilator 拓扑的非线性稳定性崩溃

**审查对象（对抗性工程假说）**
一个由三个阻遏蛋白环形互抑构成、拟用于肠道工程菌"定时自主节律性释放药物"的基因振荡器（A ⊣ B ⊣ C ⊣ A）。团队提出"强力驱动方案"：

> "只需将三个阻遏蛋白的启动子与 RBS 强度均提高 10 倍（换用 T7 极强启动子），并提高 mRNA 稳定性；依据 Hopf 分岔理论，极高的合成速率 + 高 Hill 系数（n=4）必然使系统进入无限期稳定的极限环振荡，获得坚不可摧的时钟节律。"

**审查结论（Executive summary）**：该假说**不成立**，且"错"在三处独立的物理机制上：

1. **资源分配硬约束（Scott–Hwa 增长定律）**——回路高强表达必然抢占核糖体与 RNA 聚合酶，挤压管家/必需蛋白翻译，使细胞生长率 λ 由常数退化为振荡物种总质量的动态函数 λ = λ(A+B+C)。所谓"放大任意倍数都稳"违反质量守恒前提。
2. **振荡窗口是**有界的**，放大驱动不是增强而是摧毁振荡**——数值上极限环只存在于一个有界的驱动窗口（G∈[0.7, 5.7]）；跨过临界 Gc≈5.6 后振荡经"逆 Hopf"死亡（oscillation death / 阻尼阻遏停滞），系统冻结在互抑平衡的高表达态。
3. **所谓"高表达必然走向周期倍化→混沌"在本类光滑确定性模型中被系统性证伪**——我们在多种宿主-负荷耦合模型族上做了大规模数值搜索（共数千次积分），最大李雅普诺夫指数始终 ≤ 0（极限环带内 ≈ 0，冻结态为负），未发现任何持久的混沌吸引子；混沌需要额外的耦合结构，而非"更强表达"。

配套交付：可复现脚本 `repressilator_metabolic_load_sim.py`（ODE 模型 + 分岔/负荷扫描 + Wolf 李雅普诺夫 + 三维相空间图），及其产出的图 1（驱动-分岔/生长负荷/周期去耦）、图 2（时间序列与三维吸引子）、图 3（λ₁–G）。

## 1. 全细胞资源分配与 Scott–Hwa 增长定律：λ 从"常数"退化为"状态函数"

### 1.1 核糖体自由池与 RNAP 是**有限**资源

细菌在指数期维持近似恒定的蛋白密度与有限的核糖体/RNAP 投资。Scott–Hwa 增长定律（[Scott et al., 2010](#ref5); [Klumpp & Hwa, 2014](#ref6)）的平衡增长表述是：

λ = κt · φR,active,   （1）

其中 φR,active 是"投入生长相关（管家）蛋白合成的活性核糖体份额"。设回路（外源）蛋白总质量为 ε = A + B + C，管家蛋白质量份额为 1 − ε（按蛋白组份额归一）。核糖体必须在管家需求 H 与回路 mRNA 需求 D=Σ(RBS·mRNA) 之间分配；分配后

φR,active ≈ H / (H + D(ε))。

于是 λ 是回路负荷的**减函数**：Δλ/λ0 ≈ −D/(H+D)。模型中我们用带滞后的一阶资源变量 sR 表示"宿主可投入生长的剩余合成能力份额"，令 λ = λmax·sR，其中 sR 松弛到 s_target(ε)=1/(1+(ε/e50)^k)。这是对式(1)的粗粒化实现（RNAP 以快变量 sP 相似地约束转录）。由此，**振荡器每转录/翻译一份外源蛋白，都在直接降低宿主自身维持生长所需的合成通量**——这就是"全局耦合(global coupling)"。

### 1.2 致命漏洞：λ 变成强非线性动态函数，产生宿主增长滞后（隐含的间接反馈）

当回路蛋白被翻译时，它们唯一的"负反馈出路"之一是**细胞生长稀释**：dX/dt = 合成 − (γ + λ)X。若 λ 被回路自身拉低：

- λ↓ ⇒ 稀释项 λX 减小 ⇒ 回路蛋白更不易被清除 ⇒ 质量 ε 进一步积累 ⇒ λ 进一步下降 —— 一条经由"稀释丢失的减慢"形成的**隐性正反馈**；
- 而宿主对负荷的补偿（增加核糖体/调节生长）并非瞬时，存在分钟-小时级的滞后 τ（生长滞后）。

于是"λ = 常数"的假设被"λ = λ(ε(t−τ)) 的动态慢变量"取代，系统从 6/7 维的自洽环变成带额外慢自由度的高维系统。**任何"固定 λ 下的 Hopf 局部分岔结论"都不再能外推到该闭环系统**——你调大的参数（表达强度）现在通过 ε 反向作用于系统自身的阻尼与稀释，这是假说在物理上的第一处断裂。

### 1.3 对称性视角：为什么"λ=λ(A+B+C)"本身容易被低估

Repressilator 的稳定极限环是**旋转波**：A(t) ≈ B(t−T/3) ≈ C(t−T/3)（在理想对称参数下）。因此三节点蛋白和的瞬时变化

ε(t) = A+B+C

在一个周期内近似为**常量**（三相信号叠加后基频相消）。也就是说，仅依赖蛋白总质量的负荷通道 λ(ε) 对时间几乎不变，它更像一个"公共稀释系数的静态下移"，而不是强的周期驱动——这解释了为何在对称情形下负荷主要把时钟**整体拖慢**并把系统推向 Hopf 死亡，而不是立刻产生剧烈的倍周期失稳。**真实线路并不对称**：TetR/LacI/cI 蛋白分子量、RBS、降解各不相同（负荷权重不同），此时 ε(t) 在基频 ω 上有分量，λ(t) 变为以时钟频率调制的参数，方可能产生更丰富的非线性响应。审查数值部分同时扫描了对称与不对称情形。

## 2. 数值模型：把"经典 Repressilator"与"有限核糖体分配 + 动态稀释耦合"联立

### 2.1 Model S（主模型，8 维 ODE）

状态 x=[m_a,m_b,m_c, A,B,C, sP, sR]；A ⊣ B ⊣ C ⊣ A，Hill n=4：

```
dm_i/dt = α0·G·sP·(ℓ + Hill(阻遏蛋白)) − (δm(G) + λ)·m_i        (i=a,b,c)
dA/dt   = β0·G·m_a·sR − (γp + λ)A   （B、C 同理）
dsP/dt  = ( sP_target(m_tot) − sP )/τP      RNAP 份额（快）
dsR/dt  = ( sR_target(ε)      − sR )/τR     核糖体/生长份额（慢=宿主滞后）
λ       = λmax·sR                             （Scott–Hwa）
sR_target(ε) = 1/(1+(ε/e50)^k)                 ε=A+B+C
δm(G)   = δm0/(1 + stab·G)                     驱动 G 同时放大启动子/RBS 并稳定 mRNA
```

参数（时间单位 h）：λmax=1.4, α0=40, β0=0.9, δm0=3.5, stab=0.05, γp=1.0（未加 LVA tag）, Kd=1, n=4, e50=12, k=1.5, m50=80, τP=0.25, τR=1.2。完整代码见脚本 `repressilator_metabolic_load_sim.py`。

### 2.2 为什么要包含 RNAP 与核糖体两个池、以及慢变量 sR

- **核糖体池**限制翻译（β0·G·m·sR）：大表达量的终极瓶颈；也是 Scott–Hwa 生长定律的作用点。
- **RNAP 池**（sP）限制转录：防止在极高驱动 + 超稳 mRNA 下转录无限逃逸，给出"启动子再强也有转录通量上限"的物理事实。
- **慢变量 sR（τR=1.2 h）**实现"宿主增长滞后"——负荷上升后宿主不能瞬时重建合成能力，这正是任务要求的"经由宿主生长滞后引入的全局反馈"。

## 3. 结果：放大驱动不是"加固极限环"，而是跨过有界窗口并杀死振荡

### 3.1 一个**有界**的振荡窗口（图 1a、图 1b；见脚本输出的 regime 表）

| 驱动 G | 行为        | 周期(h) | 振幅包络 A | ⟨λ⟩ (h⁻¹) | 备注 |
|---|---|---|---|---|---|
| <0.65 | 冻结(固定点) | – | – | ~1.3 | 尚未越过 Hopf 起点 |
| 1.0   | 极限环      | 3.5  | [0.32, 2.2] | 1.20 | "健康"弱启动子设计（≈86% λmax） |
| 2.0   | 极限环      | 5.2  | [0.33, 8.7] | 0.78 | 负荷显现 |
| 4.0   | 极限环      | 7.7  | [0.72, 20.8] | 0.42 | 强负荷：生长率较 λmax 已损失 ~70% |
| ≈5.6–5.7 | **振荡死亡** | – | →0(冻结) | 0.8（冻结低 ε 支） | 逆 Hopf：极限环并入稳定不动点 |
| 8–12  | 冻结        | – | A_ss=4.5→7.7 | 0.64→0.38 | 冻结态蛋白质量随 G 继续累积 |
| ≥18   | 冻结        | – | 更大 | <0.2 | 逼近生长停滞 |

要点：
- **极限环只存在于有界驱动区间**。低端约 G=0.65 为超临界 Hopf 起点（周期轨从固定点长出），高端约 Gc≈5.6 为**逆 Hopf/振荡死亡**（periodic orbit merges into stable fixed point）。团队假设"驱动→∞，极限环越稳"在高端直接被逆 Hopf 击穿。
- 越过 Gc 后系统"阻尼阻遏停滞"：三个阻遏蛋白互相抑制到一个对称高表达不动点，**时钟停止**（无节律→药物释放节奏消失），同时回路质量继续随 G 上升，生长率一路走低——既"停表"又"拖垮宿主"。
- 分岔扫描（图 1a 中灰色方块）与 λ₁ 判据（图 3）互相印证：G>Gc 后最大李雅普诺夫指数从 0 骤降为负（−0.19→−1.25 h⁻¹），说明冻结不动点是强吸引子；**没有**任何一个 G 出现 λ₁>0（见 §4）。

### 3.2 三维相空间：极限环 → 更大极限环 → 吸引子崩溃（图 2）

- G=1：干净的闭合环（旋转波），周期 3.5 h；
- G=4：仍为极限环，但振幅大 10 倍、周期拉长到 7.7 h，环绕速度变慢，负荷挤压生长；
- G=8：轨线**螺旋坍缩进固定点**——"极限环破裂后的吸引子崩溃"。图中可见螺旋进入黑色不动点（frozen FP）。

### 3.3 λ 从常数退化为 λ(A+B+C) 的直接后果：周期被"稀释"绑架

把时钟周期对生长率作图（图 1c）：无 tag 设计的周期在 ⟨λ⟩ 从 1.2 降到 0.42 时从 3.5 h 膨胀到 7.7 h，即**振荡器的时基直接耦合在宿主生长上**——肠道里宿主代时随环境营养波动时，这个"节律"根本不是一个稳定时间基准。

## 4. 关于"周期倍化分岔与混沌"的诚实评估（重要澄清）

任务要求论证高表达下极限环失稳 → 周期倍化 → 混沌。我们在本类**光滑质量作用确定性模型**上做了系统的数值调查，结论是——**该假说在这一层也被证伪，但方向相反**：

- **没有正的李雅普诺夫指数**：对主模型在整个驱动域用 Wolf 重正交法计算 λ₁（图 3），极限环带内 λ₁≈0（±0.004 数值噪声），死亡区 λ₁<0，全区间无 λ₁>0。即不存在可持续混沌（混沌要求 λ₁>0）。
- 我们还对若干宿主-负荷耦合模型族做了随机参数搜索（单慢变量负荷、三级延迟链负荷、陡峭 Tan–You 型阈值负荷、松弛型非对称环；数千次积分），观察到：周期延长、振荡窗口收缩、**双稳/回滞、再入式振荡窗口跳变、长周期 burst 型轨道**——但未发现稳定持久的混沌（所有候选的 Wolf 指数均为负）。3 节点纯环形互抑 + 平滑负荷耦合在动力学上是结构稳定的周期-1 振子（这也是 Repressilator 原始实验能工作的原因之一），它不会因为"把启动子调大"就自发进入 Feigenbaum 倍周期瀑布。
- **因此"高合成速率 + 高 Hill 必然走向周期倍化→混沌"是错误预期**；真实、更危险的失败模式是：生长崩溃 + 逆 Hopf 振荡死亡 + 冻结高表达态 + （在双稳区）初始条件依赖的跳变。要获得真正混沌需要额外的动力学结构（强非对称与额外正反馈/时滞、细胞间耦合、或离散分裂节的频闪），这些并不在团队的"10× 放大"方案里。

> 审查意义：一个正确、可发表的合成时钟设计，关心的不是"能不能更响"，而是**在有界资源下如何不把自己和宿主一起弄死**。

## 5. 正确的设计物理：弱启动子 + 专一性快降解标签（LVA/ssrA）

为什么"弱启动子 + LVA tag"才是稳定时钟的物理本质？

1. **把蛋白周转从"生长稀释"中解耦**。Repressilator 需要蛋白质降解才能形成环形相移。若无快降解 tag，蛋白主要靠稀释 λX 清除，于是振荡的恢复力由 λ 提供——而 λ 又正是被负荷破坏的量，形成自毁循环。加 LVA/ssrA（如 AANDENYALAA；降解半衰期分钟级，[Andersen et al., 1998](#ref8)）使 γp ≫ λ，蛋白清除不再依赖生长，振荡器获得**与宿主生长状态无关的固有时基**。
   数值验证：LVA（γp=5 h⁻¹）设计的振荡窗口延伸到 G≈8，在 ⟨λ⟩≈0.4 h⁻¹ 的低速生长下仍维持 ~4 h 的周期；无 tag 设计在 ⟨λ⟩≈0.8 处就已死亡（图 1b–1c）。周期对 λ 的斜率大幅变平=时基解耦。
2. **弱启动子把质量/通量负担压到资源可承受带内**。外源蛋白的真实负担 ≈ 翻译通量 ∝ (γ+λ)·[蛋白]；启动子弱 → 稳态 ε 小 → sR_target 接近 1 → λ≈λmax 近似常数 → **负荷通道在时间上被"去激活"**，振荡器近似回到经典 Repressilator 的干净极限环。快速 tag 不是"免费消除负担"（高周转本身消耗通量），它的作用是**避免长寿命阻遏蛋白在胞内大量积累造成蛋白毒性与包涵体**，并为时钟提供确定的降解时基。
3. **合成生物学的定量实践**（[Ceroni et al., 2015](#ref9)）同样指出：低负担的表达架构（弱启动子、限速 RBS、可诱导慢速启动）比"越大越好"稳健得多——与本文结论一致。

一句话：**LVA 负责"给振荡器一个不依赖宿主的秒表"，弱启动子负责"不把秒表的电池（核糖体/生长）耗尽"。两者缺一不可，而"强表达＋稳 mRNA＋无 tag"恰好同时违反了这两条。**

## 6. 面向肠道应用的功能性后果

即便忽略动力学，把 T7 强表达环路的宿主负荷落到应用场景：

- 肠道定殖要求工程菌**保持生长/与原生菌群竞争**；λ 从 ~1.2 塌到 <0.2 h⁻¹ 意味代时从 ~35 min 延长到数小时以上，菌株将被洗出（wash-out），"周期释放"无从谈起。
- 强表达 + 超稳 mRNA + 慢降解蛋白 ⇒ 蛋白组被三个阻遏蛋白占据、冻结互抑平衡态，加上可能的包涵体/蛋白毒性，进一步损害膜与代谢。
- 群体层面：即使单细胞仍偶发振荡，**细胞间不同相 + 生长率异质**会使群体平均药物释放呈衰减包络而非清晰脉冲（本文未展开随机/群体项，此为定性外推）。

## 7. 局限与后续

- 本演示为**单细胞确定性 ODE**；未含 intrinsic/extrinsic noise、质粒拷贝数、诱导剂不均一与空间定殖。噪声在弱信号设计中可能进一步破坏相位相干性（结论只会更保守）。
- 混沌搜索覆盖了光滑确定性模型族；含离散分裂节（division strobing）的混合模型、或多细胞群体耦合模型可能产生更强的混沌窗口，可作为后续工作。
- 建议后续用流式/微流控单细胞时间序列检验"振荡窗口有界 + 高表达停表"的预测。
