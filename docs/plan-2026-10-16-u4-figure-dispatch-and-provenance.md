# U4 方案（v2.6.0 首单元）：插图理解**按图形类别分派** + 派生结果挂**既有**溯源面

> 会话认领（2026-10-16 20:0x–）。口径来自台账 §一百六十三 §五 与 §一百六十四 §五：**通用描述只覆盖最后一类，不许拿它冒充前三类**；化学一路**≥2 个独立引擎一致才算高置信**，低置信即拒答并给人工核对入口；派生结果挂 **模型 revision + 输入指纹**，换 revision/输入即标过期且可复算。

## 一 要接的缝（读源确认，不是推测）

- 插图候选现在由 `PdfService.figures()`（`src/main/settings/pdf-service.ts:330`）产出：每个候选带 `{page, index, bbox, caption?, captionSource, warnings}`，**没有任何理解步骤**。
- 该方法的解析注入点是 `this.options.parsePdf ?? parsePdf`（`open()` 里那一处在 `:187`）；它同时给出 `items`（带坐标的文字项）与 `images`（插图落位）⇒ **分类所需的两类证据本机已有**，不需要新模型。
- 派生结果的落点是**既有**的 `src/main/structure/structure-observation-journal.ts`（会话一条 JSON、主进程独占写、临时文件 + rename、有界 + `dropped`）与它的读侧 `artifacts/provenance-repository.ts`。**不另起一套**。

## 二 分派表（与 §一百六十三 一致；这里的「证据」是本机能拿到的）

| 类别            | 判定证据（都是确定性文本/几何）                        | 允许派生                           | 不许               |
| --------------- | ------------------------------------------------------ | ---------------------------------- | ------------------ |
| 化学结构式      | Scheme 号、化学词与取代基/试剂记号、产率形态           | OCSR ⇒ SMILES/InChI（**需引擎**）  | 用通用描述冒充     |
| 蛋白/生物结构图 | 图注/图内出现库号（PDB / UniProt），且带结构性上下文   | **查真实数据**绑定库号             | 用模型「读」出结构 |
| 图表/曲线/热图  | 轴/统计标记（IC50、%、HR、95% CI、p=、n=）与图内数值项 | 图内数值抽取，**每一项带页级几何** | 把数值算成结论     |
| 通用示意图      | 图注明写 示意图/schematic/flow/workflow                | 留给描述模型（本轮**不接**）       | 默认落到这一类     |
| 判不出          | 无信号 / 信号互相矛盾                                  | **具名拒答**                       | 猜一个类别         |

## 三 切片与验收（每片各自可跑、可读）

- **U4-a 分派器 + 具名拒答**（无模型即可落地）：纯函数，输入 = 图注文本 + 图内文字项，输出 = 判别联合 `{class, basis[], …}`，`basis` 逐条写明**是哪条证据判的**；判不出 ⇒ `undetermined` 带 `no-signals`/`conflicting-signals`。**验收**：单元用例逐类 + 反例（把「示意图」当默认落点必须红）；真机读一条真实 PDF 的图注/图内文字。
- **U4-b 蛋白一路**：把图注/图内的库号接到**既有**连接器（PDB/UniProt 读侧）取真实数据；库号不在图上 ⇒ 拒答，绝不生成一个。
- **U4-c 图表一路**：图内数值项逐条给 `{值, 页, 几何, 来源: 'pdf-text-in-bbox'}`；**不给结论**。
- **U4-d 溯源面接线**：把 a–c 的派生结果写成一条观察（复用 `recordStructureObservation` 的载体与串行化；新 kind 与既有判别联合一起收紧守卫），字段含 **模型 revision（化学）/连接器读数（蛋白）/几何来源（图表）** 与**输入指纹**（图候选的 bbox + 页 + 图注哈希），换输入即标过期、可复算。
- **U4-e 化学一路（OCSR）**：**≥2 个独立引擎一致**才给高置信；低置信 ⇒ 拒答 + 人工核对入口；结果挂引擎 revision + 输入指纹。

## 五 硬判据（不许松）

1. 判不出就拒答，**不设默认类别**；
2. 化学/蛋白/图表三类**不得**由通用描述兜底；
3. 派生结果**必须**带来源（模型 revision / 连接器读数 / 页级几何）与输入指纹；
4. 数值与结构**不给结论**，只给可核验的表示；
5. 录制永不把异常抛回调用路径（沿用既有载体的规矩）。
