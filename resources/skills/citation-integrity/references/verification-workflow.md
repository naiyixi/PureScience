# 引文验证操作细节

## DOI 验证

- 解析方式：`https://doi.org/<DOI>` 应重定向到出版商页面；核对返回页面标题与引用题名一致。
- 常见坑：
  - 大小写/前后空格：DOI 区分大小写，复制粘贴易错（`10.1000/xyz` vs `10.1000/XYZ`）。
  - 把期刊文章 DOI 用于书籍章节/数据集（不同类型对象各有 DOI 前缀规律，但以解析结果为准）。
  - 预印本 DOI（bioRxiv 等）与正式发表 DOI 是不同对象——引用正式版时要换正式 DOI。
- 解析失败 ≠ 不存在：先排除网络/前缀拼写，再标记"待核"。

## PMID / PMCID 验证

- PMID：文献库记录号；核对该 ID 返回的标题/作者/期刊/年份与引用一致（ID 真实但张冠李戴也常见）。
- PMCID 只在开放获取语境使用，不替代 PMID。
- 注意 PubMed 上"已被撤回/已更正"状态：撤回文献引用必须显式标注。

## URL 验证

- 访问 + 记录（访问日期、页面标题、关键内容片段）；期刊/机构页面比个人页可靠。
- 用"与正文声称匹配的内容快照"做证据，不只"能打开"。
- 失效链接：先试 archive 服务快照（记录快照日期）；仍不可得 → 标"无法验证"。
- 临床试验注册号（注册平台编号）：在注册平台验证编号与试验信息一致。

## 中文文献验证

- 通过中文文献库（CBM/CNKI/万方/维普）记录号或题录信息验证；CNKI 链接需注明数据库与日期。
- 中文文献同名/同作者混淆率高：核对作者机构、年份、期刊卷期。
- 学位论文、会议论文、标准（GB 编号）各有定位字段，按类型给全。

## 批量核查策略

- 先用脚本/工具对全部 DOI 做批量解析初筛（状态码 + 标题比对），再对可疑项人工复核。
- 抽样原则：优先核查——直接支撑关键论断的引用、异常具体的数字/机制声称、以及 AI 生成文本段的引用。
- 全量核查时给出核查日志（哪些过了自动化、哪些需人工），不宣称未做的验证已完成。

## 验证失败分级

| 级别 | 情形 | 处理 |
|---|---|---|
| 可修复 | DOI 大小写/URL 笔误、卷期页差 | 修正后复验 |
| 需标注 | 预印本/撤稿/版本差异 | 标注状态或换正式版 |
| 无法验证 | 无标识、链接全失效、库中查无 | 移除或改引可验证来源；绝不留存"查无此文"的引用 |
