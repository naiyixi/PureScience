# 检验与模型选择决策树（文字版）

> 先回答三个问题再翻表：**结局是什么类型？比较结构是什么？有没有需要同时调整的协变量/分层？**

## 决策树

### 结局 = 连续

1. 单组与已知值比较 → 单样本 t（正态）或 Wilcoxon 符号秩。
2. 两独立组 → **Welch t 检验（默认）**；严重偏态/离群 → Mann-Whitney U 或置换检验；小样本且关心均值 → 置换/bootstrap 敏感性。
3. 配对（前后/同对）→ 配对 t 或 Wilcoxon 符号秩。
4. ≥3 独立组 → 单因素 ANOVA；方差不齐 → Welch ANOVA；偏态 → Kruskal-Wallis。显著后的事后两两比较必须校正（Tukey/ Dunnett 与对照组比较/ Dunn-Bonferroni 等，按场景选并说明）。
5. 重复测量/随机区组/嵌套（如多位点、多中心、多次随访）→ 混合效应模型（随机截距起步），不把同一受试者多条记录当独立样本。
6. 需要调整协变量 → 线性回归/ANCOVA；先看"调整了什么、为什么"，避免把中介变量当混杂调整（过度调整）。

### 结局 = 二分类

- 两独立组 → 卡方检验；期望频数 <5 → Fisher 精确检验（或说明使用条件）。
- 配对二分类（McNemar 场景）→ McNemar 检验。
- 调整协变量/多因素 → 逻辑回归（报告 OR 与 CI）；队列/随访 → 也可用相对风险回归。
- 分层设计 → 分层卡方（Mantel-Haenszel）/带层变量的回归。

### 结局 = 有序

- 两组 → 秩和思路；多组 → 有序数据的秩方法或比例优势模型；趋势 → 趋势检验（Cochran-Armitage 类）。
- 不建议把有序当作连续直接 t/ANOVA（除非类别多且近似连续，需说明）。

### 结局 = 计数 / 率

- 计数（事件数、随访时间不同）→ 泊松回归/负二项；暴露时间不同用率（offset）。
- 二分类率的差异场景见上；率比/率差报告 CI。

### 结局 = 时间-事件

- KM 曲线 + log-rank（组间粗比较）；调整 → Cox 比例风险（报告 HR 与 CI）。
- 检查比例风险假设；违反时说明（分层 Cox/时间依赖/限制平均生存时间 RMST 替代）。

### 相关/一致性

- 两连续变量相关 → Pearson（线性、正态）或 Spearman（单调）；报告相关系数与 CI。
- 测量一致性（同一对象两次测量/两种方法）→ Bland-Altman 或组内相关系数（ICC），不是 Pearson 就够。

## 假设核查实操

- **正态性**：先看 QQ 图/直方图；Shapiro-Wilk 仅作辅助（小样本敏感、大样本对轻微偏离不敏感）。没有"必须 p>0.05"的准入制。
- **方差齐性**：Levene 检验或 F 比；不齐 → Welch/稳健法。
- **独立性**：由设计保证——同一受试者多次测量、来自同一巢（窝/批/中心）的样本都不独立；设计上无法保证时如实说明。
- **样本量与功效**：分析前已知不足 → 缩小模型/预设探索性；不要事后用功效分析为已得阴性结果辩护。

## 稳健性与敏感性

- 主要分析 + 敏感性分析（不同假设/不同缺失处理/剔除离群）结构；结论稳健性随敏感性一致程度表述。
- 探索性分析与确认性分析分开标注；探索性发现一律不写成确认结论。
