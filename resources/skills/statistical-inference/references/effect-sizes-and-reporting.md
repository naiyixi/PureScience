# 效应量、置信区间与透明报告

## 效应量速查

| 场景 | 常用效应量 | 备注 |
|---|---|---|
| 两连续组均值差 | 均值差 + Cohen's d（d≈0.2/0.5/0.8 小/中/大，仅为经验参照） | 报告原始单位差值更有解释力，d 作补充 |
| 相关 | Pearson r / Spearman ρ（r≈0.1/0.3/0.5 经验参照） | 报告 CI |
| 二分类 | 风险差 RD、风险比 RR、比值比 OR | 队列报告 RR/RD；病例对照 OR；均给 CI |
| 时间-事件 | HR（含 CI） | 需比例风险假设 |
| 解释方差 | R²/调整 R² | 注明是模型级 |

## p 值的正确语言

- p 值 = "在零假设与模型假设下，观察到当前或更极端结果（检验统计量）的概率"。
- 不是：效应为 0 的概率、结果可重复的概率、临床重要性的度量。
- 报告"效应量 + 95% CI + p"三件套；单给 p 不给效应量视为不完整。
- 语言模板：`组间差 X（95% CI a–b），p = 0.03` → 说"差异有统计学意义"，不说"证明有效/有显著疗效"。
- 边界 p（0.04–0.06）不做"临界显著"叙述，给区间与效应量让读者判断。

## 多重比较与多重性

- 先统计**实际执行的推断次数**（含事后比较、多个终点、亚组、中期分析）。
- 确认性：预先声明的少数主要终点，按预设策略控制（如 Bonferroni/Holm 族系错误率）。
- 探索性：大量筛选用 FDR 类（Benjamini-Hochberg）控制错误发现率，并标注探索性质。
- 亚组分析默认探索性；交互作用检验（而非分组内 p 值）才是判断"效果是否不同"的正路。
- 中期分析/序贯设计需预设耗散函数或界值——没有预设就不能事后改规则。

## 贝叶斯替代（何时提示）

- 需要直接表述"参数在某区间的概率"、先验信息确实存在且可辩护、小样本且希望结合先验时，可提出贝叶斯分析（报告后验均值/区间与先验敏感性）。
- 不做"把 p 换成贝叶斯就自动更严谨"的暗示；先验选择必须可审计。

## 透明报告要素（分析段落应包含）

1. 数据来源与纳入/排除后样本量（含缺失，缺失处理方式）。
2. 主要分析与敏感性分析的预设/实际顺序（探索性标注）。
3. 软件与版本、关键函数/包、随机数种子（若涉及）。
4. 假设核查结果与违背后的选择。
5. 效应量+CI+p、多重比较策略。
6. 可复现命令或脚本路径。

## 审计他人分析时的红旗清单

- [ ] 只报 p 不报效应量/CI
- [ ] 事后换检验直到显著、或"去掉离群点后显著"未预先声明
- [ ] 配对/重复数据按独立样本分析
- [ ] 多重比较未校正且比较数未交代
- [ ] 把相关当因果、把观察性结论写成因果语言
- [ ] 用事后功效分析为阴性结果辩护
- [ ] 数字位数超过数据支持（假精度）
