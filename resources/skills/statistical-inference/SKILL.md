# 统计推断与检验选择

## 目标

把"怎么分析这批数据"变成**可辩护的选择链**：结局类型 → 比较结构 → 假设核查 → 检验/模型 → 效应量与区间 → 报告。每个选择给出理由，让审阅者能复现决策。

## 核心工作流

1. **先弄清数据形态**（缺一不可，否则拒绝往下走）：
   - 结局：连续 / 二分类 / 有序 / 计数 / 时间-事件
   - 结构：几组、独立或配对/重复测量、有无协变量、有无分层/整群
   - 样本量与缺失情况、分布形态（先看图：直方图/箱线图/QQ 图）
2. **假设核查**：独立性（设计决定，不可用检验弥补）、正态性（按组看，小样本更关键）、方差齐性；列出核查方法但不搞"p>0.05 即正态"的教条。
3. **选检验/模型**：先按决策树选经典检验，再评估稳健替代（见 references/choosing-a-test.md）：
   - 两独立组连续 → t 检验（默认 Welch，不默认等方差）；违背后考虑秩和或置换。
   - 配对 → 配对 t / Wilcoxon 符号秩。
   - ≥3 组 → 方差分析（ANOVA）/Kruskal-Wallis；事后比较要校正。
   - 分类 → 卡方/Fisher（小期望频数）；有序 → 趋势检验/秩和思想。
   - 计数/率 → 泊松/负二项；时间-事件 → 生存分析（KM + Cox）。
   - 有协变量/混杂 → 回归框架（线性/逻辑/cox），不把连续变量粗暴二分化。
   - 重复测量/嵌套 → 混合模型优先于"把个体当独立样本"。
4. **效应量与区间**：报告效应量（差值/Cohen's d/OR/RR/HR）与 95% CI，与 p 值并列。
5. **多重比较**：先问"比较总数是多少"；探索性分析用 FDR 类控制，确认性用预设的强控制；不搞"只看显著的几个"。
6. **报告**：方法与假设、软件与版本、缺失处理、敏感性分析；结论语言与证据强度匹配（见 evidence-grading 交接）。

## 红线

- 不做"p<0.05 即结论"式报告；p 值不是效应大小也不是假设为真的概率。
- 不为了得到显著结果换检验（p-hacking）；换分析必须事前说明或标注为探索性。
- 不把重复测量/配对数据当独立样本（伪重复）。
- 不隐瞒未通过的假设：说明并给稳健替代或敏感性分析。
- 缺失数据不默认"删掉再说"：说明缺失机制与处理（完整案例/多重插补/模型法）及局限。
- 样本量不足时不硬做高维模型并宣称可靠。

## 交接语义

- 设计阶段（未采集数据）的样本量/功效 → study-design。
- 检索策略 → literature-search-strategy；证据强度表述 → evidence-grading。
- 不确定度/单位数值审计 → uncertainty-units-audit。
