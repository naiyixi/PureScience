# 临床数据脱敏与合规

## 目标

产出一份**可分享**的数据集，配套一份**可审计**的脱敏记录；并明确写出"这不是匿名数据"的边界。

## 零、先确认合法性与授权（不能跳过）

- 数据来源：院内 HIS/EMR、随访系统、注册库、公开数据集——各自的授权范围不同。
- 伦理：批件号、是否需要知情同意或有豁免、是否允许数据出院/出境。
- 合规口径（中国）：**去标识化 ≠ 匿名化**。按《个人信息保护法》，去标识化后仍属个人信息，重识别风险不为零；对外提供通常需要单独同意或满足法定情形之一。**不要把"已脱敏"写成"已匿名、无法识别"**，除非做过正式的重识别风险评估。

## 一、分类与排序（先列清单，再动手）

1. **直接标识符**：姓名、身份证号、住院号/门诊号、医保号、手机号、家庭住址、工作单位、照片、指纹、生物样本编号。
2. **准标识符**：出生日期、入院/出院日期、邮编、职业、民族、性别 + 年龄（组合可重识别）。
3. **自由文本**：主诉、病程记录、手术记录、病理报告、出院小结——**最容易漏**，姓名常出现在正文里。
4. **影像/信号**：DICOM 头（PatientName、PatientID、StudyDate、InstitutionName、AccessionNumber）、截图水印、超声/内镜画面上的姓名条。
5. **衍生文件**：导出的 Excel 文件名与工作表名、图表标题、PDF 元数据（作者、标题）。

## 二、处理步骤

1. **ID 重映射**：生成随机研究号（如 `S0001`），**映射表单独保存、不随数据集发布**。
2. **日期处理**：不要简单删日期（会毁掉随访间隔与时间序列分析）。用**每人一个随机偏移（±N 天，均匀分布）**统一平移该人所有日期，保持间隔与相对顺序；年龄只保留到年或分段。若研究需要绝对日历时间（如季节性），保留月份与年份但去掉日。
3. **自由文本**：先用规则（正则匹配姓名、住院号、电话、地址关键词）再人工复核；**必须双人复核抽样**，并记录抽了多少、命中多少。去掉/替换为占位符（如 `[NAME]`）。
4. **影像头**：用 DICOM 匿名化工具批量改写；**烧录在像素里的文字要单独裁切或遮挡**，改头文件不够。
5. **小样本再识别检查**：对关键组合（年龄 + 性别 + 诊断 + 入院月份）做计数，任何一格 <k（如 k=5）就合并分箱或删除。
6. **留痕**：每一步记录"谁、何时、对哪一列、做了什么、影响多少行"。这份记录是投稿"数据可用性声明"与内部审计的依据。

## 三、产出

- 脱敏数据集 + 数据字典（每列的含义、是否处理过、处理方式）。
- 映射表（单独保存，不入包）。
- 脱敏报告：标识符清单与处置方式、日期处理策略、文本复核抽样结果、k-匿名检查结果、遗留风险。
- 一段可放进论文/知情同意/合作协议的措辞（**明确"去标识化"而非"匿名"**）。

## 常见失败（逐条自检）

- [ ] 只删姓名列，正文与文件名里仍有姓名。
- [ ] 直接删日期，导致无法做生存/纵向分析，或反过来保留完整日期导致重识别。
- [ ] 「去标识化」被写成「匿名化、无法识别」。
- [ ] DICOM 只改头文件，像素上的姓名条没处理。
- [ ] 映射表与数据集放在同一个压缩包里一起发出去。
- [ ] 没有记录处理动作，审稿人或伦理委员会问起无法复述。
- [ ] 用真实姓名出现在图表标题、工作表名、PDF 作者元数据里。
