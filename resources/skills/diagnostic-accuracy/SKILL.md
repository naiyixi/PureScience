# 诊断试验与阈值

## 目标

回答三个不同的问题，并**分别**给出答案：

1. 判别力：这个指标能不能把有病/没病分开？（AUC、敏感性、特异性）
2. 校准：它说"30% 概率"的时候，真实发生率是不是 30%？
3. 临床有用：在什么阈值下用它，净收益是否超过"全治"或"全不治"？

把三者混成一句"模型很好"是本技能要阻止的头号错误。

## 输入

- 逐例：金标准结果（有病/无病，且金标准定义写清）、待评指标原始值（**连续值，不要只给已分好的二分类**）、以及指标的测量时间与测量者盲法情况。
- 若是预测模型：训练/验证/外部验证的划分方式，以及验证集是否独立。

## 步骤

1. **先复算 2×2 表**：给定阈值下的 TP/FP/FN/TN，再算敏感性、特异性、阳性/阴性似然比。**预测值（PPV/NPV）随患病率变化**，报告 PPV 时必须同时给出该人群的患病率。
2. **ROC 与 AUC**：给出 AUC 与 95% CI；不要用 AUC 比较"哪个更好"就下结论——不同指标在临床相关的阈值区间可能反转。若两个模型相关样本，用 DeLong 检验而不是比较两个独立 AUC 的 z。
3. **选阈值**：先说清代价结构（漏诊的代价 vs 误诊的代价）。可选：Youden 指数（等权，常不贴合临床）、固定敏感性下限（筛查场景，如 ≥95%）、以及**基于决策曲线的净收益最大化**。**不得**用"使 AUC 最大"或"让 P 值最小"来选阈值。
4. **校准**：画校准图（预测概率分箱 vs 观察发生率），报告校准斜率与截距、Brier 分数。判别好但校准差的模型不能直接用于个体决策。
5. **决策曲线（DCA）**：横轴阈值概率，纵轴净收益，与"全部干预""全不干预"两条参考线比较。只有当曲线在**临床确实会用的那个阈值区间**高于参考线，才能说"有净获益"。
6. **报告规范**：回顾性按 STARD，预测模型按 TRIPOD（+AI 若适用）。写清样本量、事件数、缺失处理、是否有阈值预先注册。

## 产出

- 2×2 表 + 敏感性/特异性/似然比（含 CI）。
- ROC 图与 AUC（含 CI），并在图上标出所选阈值点。
- 校准图与 Brier。
- DCA 图 + 一句话："在 X%–Y% 阈值区间内，用它比全治/全不治多出 Z 的净收益"。
- 明确的适用人群（患病率、入排标准）。

## 常见失败（逐条自检）

- [ ] 只在病例对照样本里算 PPV/NPV 并当成临床预测值（患病率被人为拉高）。
- [ ] 用 Youden 指数选阈值却声称"临床最优"。
- [ ] 报告 AUC 提升 0.02 就宣称"更优"，没有 CI、没有配对检验。
- [ ] 阈值在验证集上再选一遍，然后报告该阈值下的性能（阈值泄漏）。
- [ ] 校准完全没做，只报 AUC。
- [ ] 金标准本身不完美（无病理/随访不全），却把它当无误差真值；需讨论 differential verification bias。
