# 真实世界证据与倾向评分

## 目标

把一份观察性数据变成一个**明确定义过的目标试验**的模仿（target trial emulation），并诚实地标注残余混杂的量级。结论的措辞强度必须与设计强度匹配。

## 步骤

1. **先写目标试验的七要素**（写在分析之前，不是写在讨论里）：
   入选条件 / 治疗策略（A vs B，含"不治疗"）/ 分配（这里只能是观察）/ 时间零点 / 随访起止 / 结局 / 因果对比（意向治疗式 vs 符合方案式）。七项中任何一项含糊，后面的模型都白做。
2. **定时间零点**：必须是"具备入组条件且策略可被识别"的那一天（首次处方日、诊断日）。**不要**用"第一次有可用检验结果"——这会把治疗组的时间往后推，制造 immortal time。
3. **排除时间零点点之后的变量做基线协变量**：时间零点之后测的指标既可能是中介也可能是碰撞变量，纳入会引入偏倚。若必须纳入，改写为时依协变量。
4. **建倾向评分**：以治疗为因变量、基线协变量为自变量（logistic）。**不要**把结局相关但不受治疗影响的变量当"instrumental"塞进去。
5. **平衡诊断，而不是模型诊断**：看**标准化均差（SMD）**，匹配/加权后 |SMD| < 0.1 视为平衡。**不要用 PS 模型的 AUC 或协变量 p 值当平衡证据**——那说明的是判别力，不是平衡。
6. **估计**：匹配（1:1 最近邻 + caliper 0.2×SD(logit PS)）、IPTW（稳定权重，报告权重分布的极值与有效样本量）、或重叠权重。**检查 positivity**：某些患者不可能接受某一策略时，加权估计外推到了不存在的区域，必须截断或改设计。
7. **敏感性分析（至少两项）**：
   - **阴性对照结局**（与暴露无关、机制上不可能受影响的结局）：若它也"显著"，说明残余混杂或检测偏倚存在。
   - **E-value**：需要多强的未测量混杂才能把观测关联解释掉；把 E-value 与已知混杂强度比较。
   - 附加：不同 caliper、不同加权、排除高权重个体后结论是否稳定。
8. **措辞校准**：观察性设计下限定为"与…相关""在调整后可观测混杂后估计为…"；只有设计上排除了主要偏倚（新使用者、活性对照、阴性对照均通过）才允许"提示因果"。措辞分级交给 evidence-grading 的 claim-language。

## 产出

- 目标试验七要素表。
- 基线表：加权/匹配**前后**各一列，并给 SMD。
- 主分析估计值（HR/OR/RD + CI）+ 有效样本量。
- 敏感性分析表（阴性对照、E-value、替代权重方案）。
- 一段"残余混杂可能的方向与量级"说明。

## 常见失败（逐条自检）

- [ ] 用 PS 模型 AUC 0.85 证明"混杂已控制"。
- [ ] 把时间零点设在治疗开始后第 30 天，并要求"存活到第 30 天"才能入组（immortal time）。
- [ ] 加权后没看权重极值，有效样本量掉到几十还照报。
- [ ] 结局是"是否住院"，却在门诊数据里数住院次数（检测机会不均等）。
- [ ] 阴性对照结局阳性却只写"值得进一步研究"。
- [ ] 只做 1:1 匹配就丢掉 70% 样本，不讨论选择偏倚。
