# figure-style —— 出版级图表正确性清单

本技能是**正确性规则**，不是审美偏好。五条规则逐条核对，任何一条违规都会让
审稿人/读者产生误导或困惑。产出任何科学图表前加载本技能；完成后用
`figure_review` 工具做结构化复查（agent 侧 MCP 工具）。

## §1 数据保真（最高优先级）

- 从面板**排除的行**（离群值、QC 失败、对照组外的数据）**不得进入任何摘要统计**：
  均值、计数、百分比、置信区间、检验统计量。
- 排除是**可见的**：图中标注 n（如 "n=12 per group, 3 excluded"），或图例说明。
- 若摘要统计与图形不一致（例如图里画了 12 个点但文字说 n=15），这是造假级别的错误。

## §2 标签经济

- 每个轴必须有轴标签（含单位）；每条系列必须在图例或直接标注中有名称。
- 标签密度上限约 12 个/轴——超过就旋转、缩写、或移入图例，防止碰撞。
- 数值轴默认从 0 开始除非有明确理由（比率、对数）；截断的轴必须用断轴记号。

## §3 色彩串线

- **同一类别在跨面板时必须用同一颜色**（面板 A 的 "treated" 是红色，面板 B 的
  "treated" 也必须是红色）。
- 调色板 ≤ 8 个可区分色相；超过就分组或分面（facet），不要硬塞。
- 色盲安全优先：红绿对比需附加形状/线型编码（dashed vs solid）。

## §4 按数据形态选图

| 数据形态 | 正确图型 |
|---|---|
| 时间/有序序列 | line（离散间隔可用 bar） |
| 类别比较 | bar / box / heatmap |
| 分布 | histogram / box |
| 双连续变量关系 | scatter（可加趋势线） |
| 矩阵/热力 | heatmap |

- 单点图（strip/swarm）适合小样本展示原始分布，标注 n。

## §5 渲染后逐面板自检

- 渲染后**逐面板目视检查**：标签被裁剪？条柱被截断？图例遮挡数据？点重叠不可辨？
- 每个面板确认已渲染 + 已检查后才算完成。检查不到的维度不要声称已检查。

## 使用流程

1. 画图前：加载本技能，按 §1-§4 规划（数据形态 → 图型 → 颜色 → 标签）。
2. 画图后：渲染，按 §5 逐面板自检。
3. 用 `figure_review` 工具提交面板的结构化描述，修复全部 error 级违规后重跑。
