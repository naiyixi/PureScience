# 证据分级与论断校准

## 目标

把"证据体 → 结论语言"这条链路做成可辩护的：先按维度给证据体定确定性（高/中/低/极低），再按确定性选择结论措辞，杜绝"一篇观察性研究就写'证明'"。

## 核心工作流

1. **先定位证据体形态**：系统评价/Meta 分析 > 大样本 RCT > 小 RCT > 队列 > 病例对照 > 病例系列/专家意见（作为起点排序，不是机械金字塔——具体问题看适用性）。
2. **按维度降级（GRADE 式五个降级域，逐域判断并记录理由）**：
   - 偏倚风险（随机/分配隐藏/盲法/失访，观察性：混杂与选择偏倚）
   - 不一致性（异质性：点估计方向/CI 重叠/I² 结合临床判断）
   - 间接性（人群/干预/对照/结局与研究问题错位；替代终点）
   - 不精确性（事件数/样本量/CI 宽度 vs 最小有意义差异）
   - 发表偏倚（小研究缺失、阴性结果缺失的怀疑）
3. **升级因素（观察性证据或强效应时考虑）**：效应量很大且稳定、剂量-反应关系、混杂若存在只会削弱效应（负向混杂）。
4. **给出确定性**：高/中/低/极低 + 一句话依据（如"降两级：偏倚风险高 + 间接结局"）。
5. **校准论断语言**（见 references/claim-language.md）：措辞表与证据强度绑定；给"推荐写法"与"禁止写法"。

## 输出格式

- 证据体确定性：`高 / 中 / 低 / 极低` + 各维度判定表（维度/判定/理由）。
- 结论句（按确定性给一版推荐措辞）。
- 若单篇或证据体不足以支撑任何确定性 → 明确"证据不足，不给出结论性表述，只能作研究建议"。

## 红线

- 不把单篇研究（尤其观察性）包装成高确定性证据。
- 不把"统计显著"当"证据充分"；两者分属不同概念（显著=随机误差小，充分=偏倚/间接/不一致都可接受）。
- 不在证据不足时用"可能有效/或许有用"式安慰性措辞代替明确的不确定性声明。
- 对降级理由不编造（如不假装检查过未取得的灰色文献）；缺哪项就标"未评估"。

## 交接语义

- 单篇偏倚风险评价（随机化细节、失访追踪等）→ 循证证据综合专家质量评价环节。
- 检索完整性 → literature-search-strategy；效应量数值 → statistical-inference。
- 论文/报告写作措辞落地 → methods-writing-audit。
