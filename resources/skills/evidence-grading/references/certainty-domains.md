# 确定性降级/升级维度的操作化判定

## 降级域（每域判定：不降 / 降一级 / 降两级，并写理由）

### 1. 偏倚风险
- 实验性：随机序列生成是否充分、分配隐藏、盲法（对象/治疗者/评估者）、失访与 ITT。
- 观察性：混杂控制是否充分、选择偏倚、暴露/结局测量偏倚。
- 多个研究同向偏倚 → 至少降一级；单一领域严重缺陷且核心研究均受影响 → 可降两级。

### 2. 不一致性
- 看方向与临床意义，不只盯 I²：点估计是否同向、CI 是否重叠、异质性是否有可解释来源（人群/剂量/时长）。
- 无法解释的实质性异质性 → 降一级；若结论方向相反 → 常降两级或"不合并，分别呈现"。

### 3. 间接性
- 人群/干预/对照/结局四要素与目标问题的错位程度；替代终点（如以生物标志物代临床结局）→ 视错位程度降级。
- 网络 Meta 或间接比较额外考虑传递性假设。

### 4. 不精确性
- 关键判据：CI 是否跨越"无效应"且同时跨越"有临床意义效应"（即连最小有意义差异都区分不了）。
- 事件数少（如 <300 事件量级，非硬性阈值）或样本量远低于功效需求 → 提示不精确。
- OIS（optimal information size）思路：样本量连功效计算需求都达不到 → 降级。

### 5. 发表偏倚
- 小研究缺失（漏斗图不对称，需 ≥10 研究才可靠）、注册库显示有未发表研究、行业资助方向单边。
- 怀疑但无法证实 → 降一级并标注"基于发表偏倚风险的怀疑"。

## 升级因素（观察性证据或大效应时）

- 效应量很大（如 RR/OR >2 或 <0.5 且 CI 不含 1，视领域惯例）且跨研究稳定。
- 存在剂量-反应梯度。
- 残余混杂方向分析：若有混杂只会把效应推向无效（负向混杂），实际效应可能更大 → 可升级。

## 常见误判

- 把 Meta 分析一律当高确定性（纳入研究本身偏倚高 → 仍低）。
- 把"无统计学异质性"当"一致性证据"（I² 低但各研究都小且方向含糊 ≠ 强证据）。
- 把注册号齐全当无发表偏倚。
