# 证据强度 ↔ 中文论断措辞对照

> 规则：**结论语言永远不超前于证据确定性**。下表是措辞上限；宁可保守一级。

## 措辞对照表

| 证据确定性 | 允许的论断动词/句式 | 禁止（超卖）写法 |
|---|---|---|
| 高（系统评价/一致的多中心 RCT） | 「可降低/可改善/证实」「有充分证据表明」 | 仍需避免「绝对/必然/100%」 |
| 中 | 「有证据提示/表明」「很可能」「倾向于」 | 「证明」「确定」 |
| 低 | 「可能」「有限的证据提示」「初步提示」 | 「表明/证实」级别的肯定句 |
| 极低/不足 | 「证据不足，无法判断」「仅能作为假设」「有待验证」 | 任何肯定性或否定性结论句（包括「无效」），除非安全性问题明确 |

## 结构性写法模板

- 高：`基于 N 项随机对照试验的系统评价，干预 X 可降低结局 Y（相对风险 0.7，95% CI 0.6–0.8），证据确定性高。`
- 中：`现有证据提示干预 X 可能与结局 Y 改善相关（…），但存在偏倚风险（降级理由），确定性中等。`
- 低：`有限的观察性证据提示 X 与 Y 存在关联；受混杂与测量误差限制，仅作假设生成。`
- 不足：`当前证据不足以评估 X 对 Y 的影响；需要设计良好的前瞻性研究。`

## 观察性研究的固定措辞

- 关联表述：`与……相关/有关联`；可加 `与因果解释一致，但不排除残余混杂`。
- 禁止：`导致/造成/证明 X 有效`（除非是罕见的自然实验级证据且经论证）。
- 负面结果：`未观察到 X 与 Y 的关联（HR 0.95，95% CI 0.8–1.1）`——说"未观察到"，不说"证明无关联"（除等效性设计按界值判断外）。

## 面向不同读者的降格

- 学术论文：按确定性直接给语言，附降级理由表。
- 面向患者/公众：再加一层缓冲（如「对大多数人可能…；个体请咨询临床决策」），不省略不确定性。
- 监管/决策摘要：给出确定性 + 剩余不确定性 + 需要哪些额外证据；不使用营销式肯定句。

## 审计他人论断时的红旗

- [ ] 摘要/标题的结论比正文证据强（摘要夸大是重灾区）
- [ ] 单篇观察性研究用「证明/导致」
- [ ] Meta 分析未报纳入研究偏倚风险就说「证据确凿」
- [ ] 阴性结果写成「证明无效」（无等效设计支撑）
- [ ] 「可能有效」用于掩盖证据不足而不声明不确定性
