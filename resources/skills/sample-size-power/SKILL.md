# 样本量与把握度

## 目标

给出一段**可以复算**的例数说明：设计、主终点、效应量及其来源、α（单/双侧）、把握度、失访率、以及最终入组数。任何一项缺失，这个数字就不该被引用。

## 输入（先固定这些，再算）

1. **设计类型**：平行对照 / 交叉 / 单臂 / 队列 / 病例对照 / 诊断准确性 / 非劣效。
2. **主终点**：只能有一个（次要终点不参与例数计算，除非做 multiplicity 校正）。
3. **效应量**：优先来自**同类研究或预实验**，并说明来源；不要用"我们希望能检出"的期望值当依据。
4. **最小临床重要差异（MCID）**：与效应量分开写。效应量可以大于 MCID，此时要说明"检出的是不是有价值的差异"。
5. **α 与把握度**：通常双侧 0.05 / 80% 或 90%；非劣效需给出界值（margin）及其临床理由。
6. **失访率**：按同类研究的实际失访估计，并在结果里**除以 (1 − 失访率)**，同时说明这是入组数不是分析数。

## 步骤

1. **选公式族**：
   - 两组均数：`n/组 ≈ 2σ²(z_{1−α/2}+z_{1−β})² / Δ²`。
   - 两组率：用合并率与差值，或直接调用精确检验近似。
   - 生存：**算事件数不是算人数**，事件数 ≈ `4(z_{1−α/2}+z_{1−β})² / (ln HR)²`；再由事件率反推人数与随访时长。
   - 诊断准确性：按目标敏感性/特异性的置信区间宽度反推阳性/阴性例数。
2. **把参数写成一行可复算的式子**，并在旁边标注每个数来自哪篇文献/哪次预实验。
3. **给出敏感性表**：效应量 ±20%、失访率 ±10% 时例数怎么变。只有一个点估计的样本量说明是不可审的。
4. **多重性**：主终点只有一个就不用；有多个主终点/中期分析时，用 α 消耗函数（如 O'Brien–Fleming）并写出总 α 如何分配。
5. **事后把握度不要算**：研究做完后用观测效应量算"把握度"是循环论证。要么报 CI，要么做**等价性/精度**陈述。
6. **写成一段话**：设计 + 主终点 + 效应量来源 + α/把握度 + 失访 + 最终 n。这段话应能直接放进方案或申报书。

## 产出

- 参数表：设计 / 主终点 / Δ 或 HR / σ 或事件率 / α / 把握度 / 失访率 / **计算得 n 或事件数**。
- 敏感性表（3 行即可）。
- 一段 6 句以内的样本量说明。
- 若结论是"现有数据不足"：给出需要补多少例，或需要多长的随访。

## 常见失败（逐条自检）

- [ ] 用观测到的效应量反算把握度，并称"把握度 0.62，所以不显著"。
- [ ] 生存研究按人数算例数，忽略了事件数才是决定量。
- [ ] 失访率写在正文却没进入计算。
- [ ] 非劣效界值没有临床理由，只写"取 0.1"。
- [ ] 交叉设计忽略 washout 与期内相关。
- [ ] 三组比较按两两 t 检验算例数，不做整体 α 校正。
