# 实验设计类型与样本量/功效要点

## 随机对照试验（RCT）的变体

- **平行**：最常见。要点：随机化单元 = 分析单元（个体/整群）；分配隐藏（中心随机/密闭信封/中央系统）；盲法（单/双/三盲，写明谁不知道什么）；分层随机化用于少数强预后因子。
- **交叉**：每受试者先后接受两种干预。适用：慢性稳定状态、干预无残留（或洗脱期可处理、可验证）、可接受顺序效应。前提：无残留效应或可洗脱 + 携带效应可检验；不适合急性可治愈疾病。
- **析因**：同时研究两个（或多个）干预维度。要点：判断交互是否存在；有交互时主效应解释受限；部分析因慎用（需预设混淆结构）。
- **整群随机**：干预天然作用于群体（社区/学校/病区）。要点：样本量要按群内相关系数（ICC）膨胀；分析必须用混合模型/整群校正，不能把个体当独立。

## 非劣效/等效设计

- 需要预设非劣效界值（Δ，临床可接受损失）——界值必须有依据，不得事后调整。
- 样本量通常大于优效设计；报告双侧置信区间与界值比较，不用"p 不显著所以非劣"的错误逻辑。

## 样本量与功效（设计期）

- 输入要素：α（默认双侧 0.05）、功效（1-β，常用 0.8–0.9）、最小有意义差异（连续 = 均值差，二分类 = 率差/OR/RR，生存 = HR）、变异（SD）或事件率（来自文献/前期数据，需注明出处或"待获取"）、设计效应（整群/重复测量）。
- 连续两均数（两独立组、等样本）：每组 n ≈ 2·(z_{1-α/2}+z_{1-β})²·σ²/δ²（σ=SD，δ=最小差异）。用软件算时给出公式与输入核对。
- 二分类：按率差与合并率公式；生存：按事件数（如 80% 功效需事件数 ≈ 4·(z_{1-α/2}+z_{1-β})²/ln(HR)² 量级）——给公式、不凭记忆报精确表。
- 加入失访/不可评估比例：n_final = n / (1 - 失访率)。
- 参数拿不到：输出公式 + 输入清单 + 敏感性扫描建议（不编数）。
- 软件：写明用哪个（如 R 包/在线计算器），版本与公式一致。

## 随机化方案要点

- 随机序列生成（软件+种子）、分配隐藏机制、揭盲规则；方案中写明谁生成、谁执行、谁评估。
- 简单随机 vs 区组随机（区组大小随机化防猜测）vs 分层随机——按样本量与预后因子选。

## 分析计划（SAP）骨架（设计期定稿）

1. 主要/次要/探索终点与各自分析集（ITT/mITT/PP 定义）。
2. 主要分析方法（预先指定检验或模型）。
3. 缺失数据与偏离方案处理规则。
4. 亚组与交互分析清单（探索性标注）。
5. 中期分析/停止规则（若有，必须预设）。
