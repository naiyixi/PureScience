# 研究设计（实验/队列）

## 目标

在**数据采集之前**把研究问题变成可执行、可辩护的方案：选对设计类型、控制偏倚与混杂、算清样本量、写清纳入排除与终点定义，让结果在采集后经得起审阅。

## 核心工作流

1. **研究问题定型**：PICO/PECO 要素 + 确认性/探索性定位 + 主要终点（预先指定，防终点漂移）。
2. **设计类型选择**：
   - 因果问题、可行 → 随机对照（平行/交叉/析因/整群，按干预性质选）；无法随机 → 观察性设计并明确因果语言边界。
   - 暴露-结局时序清楚、罕见暴露 → 队列；罕见结局、需快速 → 病例对照（含巢式）；现况描述 → 横断面。
3. **偏倚控制设计**：
   - 实验：随机化（含分配隐藏）、盲法（谁盲、如何保持）、意向性治疗 vs 符合方案集的事先定义。
   - 观察：明确目标人群与抽样、对照选择（人群对照/内部对照）、信息采集与结局判定盲法、失访处理预案。
4. **混杂处理（观察性）**：先列潜在混杂（含时变），设计上匹配/限制/分层，分析上回归/倾向评分/工具变量按需选——方案里写清楚策略与适用性，不把倾向评分当万能。
5. **样本量与功效**：给出主要终点的最小可检出差异（临床/科学上有意义的界值，不是任意假设）、预期变异/事件率、α（默认双侧 0.05）、功效（常用 80–90%），写出功效计算式与软件；失访/无效比例预加。算不出参数时给公式与所需输入，不编数。
6. **伪重复防护**：明确分析单元（受试者/样本/批次/田块/孔位）；同一分析单元的重复不是样本量。
7. **方案产出**：纳入排除、分组与盲法、干预/暴露定义、终点与测量时间窗、统计分析计划（SAP）骨架、数据管理与质量措施。

## 红线

- 不做回顾性功效分析为已发生的阴性结果辩护（样本量在设计阶段定）。
- 不把观察性设计写成可因果断言；语言与设计强度匹配。
- 不为了凑样本量把伪重复当真重复。
- 主要终点与分析计划不事后漂移；确需变更 → 记录版本与理由。
- 受试者安全/伦理底线优先：方案不得建议不安全干预；伦理审批与注册（临床试验注册）在方案中列为前置条件。
- 缺失主要参数（如最小有意义差异、预期事件率）时不瞎填默认值，保持符号并列出获取途径。

## 交接语义

- 分析计划执行 → statistical-inference。
- 观察性数据库实操（真实世界数据源）→ rwe-research-specialist 领域包。
- 终点定义细化 → 对应领域专家（临床研究设计专家的专有环节）。
