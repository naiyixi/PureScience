# 系统综述与 meta 分析

## 目标

产出一个**别人能重跑**的合并结果：检索可复现（含日期与库）、筛选有计数、提取有交叉核对、模型选择有理由、异质性与偏倚被量化而不是一句"异质性较大"。

## 步骤

1. **检索与流程计数**（PRISMA 2020）：每个库的检索式与检索日期、去重后条数、标题摘要筛除数与排除理由、全文阅读数与排除理由（**分类计数要相加等于总数**）、最终纳入数。任何一步缺计数，流程图就不成立。
2. **提取**：效应量（RR/OR/RD/HR/SMD/MD）、方差或 CI、样本量、随访、调整变量。**双人独立提取 + 分歧记录**；单人提取要在局限里写明。
3. **能否合并的判断**（临床与方法学同质性）：
   - 人群、干预、对照、结局定义、效应量尺度是否可比。
   - 若结局定义或尺度不同（如不同量表），用 SMD 并说明解释的局限。
   - **不能合并时**（临床异质明显）改为叙述性综合 + 分亚组，不要硬合并成一个数。
4. **模型选择**：默认**随机效应**（DerSimonian–Laird 或 REML），并报 τ²；固定效应用在"研究间差异仅来自抽样误差"有依据时。**不得按 I² 高低决定用哪个模型**——I² 高不代表必须随机效应，只代表研究间方差占比大。
5. **异质性**：报 I²、τ²、Cochran Q 的 p；解释 I² 的临床来源（人群、剂量、随访），做预设亚组与 meta 回归（研究数 ≥10 才做回归）。亚组分析必须是**事先指定**的。
6. **偏倚**：漏斗图 + Egger 检验（研究数 ≥10 才做）；小样本效应（small-study effects）与发表偏倚不是同义词，要分辨。trim-and-fill 只作为敏感性，不当作校正后的真值。
7. **敏感性**：留一法、剔除高偏倚风险研究、改变效应量尺度、固定 vs 随机。
8. **确定性**：把合并结果交给 evidence-grading 的 GRADE 维度（不一致性、不精确性、发表偏倚）打分，不要在本文里自创分级。

## 产出

- PRISMA 流程图 + **每一步的计数表**。
- 森林图（含总体估计、I²、τ²）。
- 偏倚评估表（每项研究的偏倚风险维度）。
- 一段结论：合并估计、置信区间、确定性等级、以及"这个结论在什么人群里才成立"。

## 常见失败（逐条自检）

- [ ] 只用 PubMed，不用中文库/预印本/试验注册库，却称"系统综述"。
- [ ] 流程图计数不自洽（筛除数 + 纳入数 ≠ 去重后总数）。
- [ ] 按 I² 选模型。
- [ ] 把 OR 和 RR 混在一个森林图里。
- [ ] 研究数 <10 仍做 Egger 并当作发表偏倚证据。
- [ ] 亚组分析是看到结果之后才分的（data dredging）。
- [ ] 同一批患者的多篇报告当独立研究重复计入（double counting）。
