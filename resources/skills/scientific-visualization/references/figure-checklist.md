# 图表提交前检查表

> 每张图过一遍；任何一项"否"都要求修改或明确说明理由。

## 数据与编码
- [ ] 图形编码与数据一致（柱高=数值、点位置=坐标、无面积双倍编码）
- [ ] 柱状图基线为零；截断轴已显式标注并说明
- [ ] 无未经说明的双 y 轴；无 3D/饼图滥用
- [ ] 对数轴已标注，刻度标签为真实值
- [ ] 平滑/插值/拟合线已说明，外推区有区分

## 误差与统计
- [ ] 误差棒标注 SD/SE/CI 及样本量，语义与正文一致
- [ ] 显著性标注规则与正文方法一致，多重比较校正状态注明
- [ ] 不显著结果未隐藏；森林图含全部研究
- [ ] 单位与量纲正确（数值轴带单位）

## 可读与可访问
- [ ] 字高/线宽在出版尺寸下可读（≥6-7pt）
- [ ] 颜色色盲安全，且不单独依赖颜色编码
- [ ] 图例自明（组名、单位、时间点）
- [ ] 多面板编号一致、坐标统一
- [ ] 语言与正文一致（中/英），字体无乱码

## 出版规格
- [ ] 分辨率 ≥300 dpi（位图）或矢量格式（PDF/SVG/EPS）
- [ ] 尺寸匹配目标期刊栏宽；字体已嵌入
- [ ] 图与数据文件可追溯（数据路径/版本记录）
- [ ] 图注含：设计（n=？、分组）、统计方法、误差棒定义

## 严重问题清单（任一命中即"不得发表，先修改"）
- 静默截断坐标轴制造显著假象
- 误差棒语义错误（SE 当 CI 等）且影响结论
- 双轴/面积编码误导读者得出数据不支持的比较
- 显著性标注与正文不符或未校正的多重比较
