# 生存分析与竞争风险

## 目标

给出一个**能被别人复算**的生存分析：时间零点说得清、删失假设写得出、竞争事件没有被当成删失、模型与问题匹配。不是"跑个 KM 出个 p 值"。

## 输入（缺一项就先回去补，不要往下走）

| 项 | 要求 |
|---|---|
| 时间零点（index date） | 入组/首次用药/诊断/手术的具体日期，并且**所有人用同一个定义** |
| 事件日期 | 终点事件的实际发生日；死亡与失访分开记 |
| 事件类型 | 至少区分：主终点、竞争事件、删失原因（失访 / 研究截止 / 停药） |
| 分组变量 | 暴露/治疗，且**在时间零点已确定**（时间零点之后才出现的分组会产生 immortal time） |
| 协变量 | 与暴露同期测量；时间零点之后的变量不得作为基线协变量 |

## 步骤

1. **先把时间算对**：`随访时长 = 事件日或删失日 − 时间零点`。负值或 0 时长要逐条查，不要静默丢掉——0 时长往往意味着时间零点选错了。
2. **判断是否存在竞争事件**：同一患者不可能再发生主终点的事件（死亡、复发前的其他死因、出院转院）就是竞争事件。若竞争事件在随访期内**不可忽略**（发生比例不低），单终点 KM 会**高估**累积发生率，因为把"已经不可能发生主终点的人"继续留在风险集里。
3. **选估计量**：
   - 只要**病因/机制**问题（"治疗是否降低了发生主终点的瞬时风险"）→ **cause-specific hazard**（把竞争事件当删失的 Cox），报告 csHR。
   - 要**绝对风险/预测/决策**问题（"5 年内有多少人会得这个结局"）→ **Fine–Gray subdistribution hazard**，报告 sHR；累积发生率曲线用 Aalen–Johansen/Fine–Gray。
   - 两个都报的时候，必须**分别说明它们回答的是不同问题**，不得混用一句话概括。
4. **检查删失是否可信**：删失独立性不可检验，只能靠设计论证。写清"删失的原因是什么、是否与预后相关"。若停药与预后相关（信息性删失），把停药当删失就会偏，改用时依协变量或把停药作为竞争事件。
5. **检查 PH 假设**（仅 Cox）：Schoenfeld 残差检验 + log(−log) 图；违反时给出时依系数、分层 Cox 或限制性立方样条。**不要在违反 PH 时照报一个常数 HR**。
6. **报告绝对量**：至少给某个时间点的累积发生率（含 CI）与组间绝对差；只有 HR 没有绝对风险，读者无法判断临床意义。
7. **敏感性分析**（至少一项）：landmark 分析（排除早期事件）、改变时间零点、E-value 或未测量混杂的定量偏倚分析。

## 产出

- 一张表：每组 n / 事件数 / 竞争事件数 / 删失数 / 中位随访（逆 Kaplan–Meier 法，不要用"平均值"）。
- 一张图：KM 或累积发生率曲线 + **风险人数表在下方**（没有 at-risk table 的生存曲线视为未完成）。
- 模型表：HR 或 sHR、95% CI、调整了哪些变量、PH 检验结论。
- 一段"这些数字回答了哪个问题"的说明：病因 vs 预测。

## 常见失败（逐条自检）

- [ ] 把竞争事件当删失后仍称"累积发生率"——这是**发生率的高估**，不是保守估计。
- [ ] 时间零点取在"第一次有检验结果"——引入 immortal time，治疗组被人为延长生存。
- [ ] 只报 HR，不报事件数与绝对风险。
- [ ] 中位随访写成随访时长的算术平均。
- [ ] 多组比较不做校正，事后挑最显著的一组讲故事。
- [ ] 事件数太少仍上 10 个协变量：每个变量至少 ~10 个事件（EPV），不够就减变量或做惩罚回归（Firth）。
