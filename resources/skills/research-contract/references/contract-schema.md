# 研究契约字段模板

> 契约以结构化文本呈现，字段齐全才可锁定。缺失字段用「待澄清」占位，不代填。

## 契约正文模板

```
研究契约 v{版本} · {日期}

1. 研究问题（拟主张）
   - 问题：
   - 范围边界：
   - 非目标（本轮明确不做）：

2. 设计要素
   - 人群（P）：
   - 暴露/干预（I/E）：
   - 对照（C）：
   - 结局（O）：
   - 场景与时间：
   - 设计类型（如适用）：

3. 定位：□ 确认性  □ 探索性（二选一，探索性结论语言降格）

4. 数据源白名单（每条含版本/日期标识）：
   - …（未列入者不得使用；申请新数据源须走契约变更）

5. 数据切分规则（建模场景）：
   - 训练/调优/验证/外部验证；时间或个体切分方式：

6. 证据检索纳入/排除规则（如本轮含检索）：
   - 库与检索式版本：…（引用检索策略技能产物）
   - 纳入：…；排除：…

7. 主要终点 / 主要评估指标（预先指定）：
   - 定义与时点：
   - 次要终点：
   - 禁止事后新增主要终点（只能新增为探索性）

8. 硬性闸门（四类，任一不过即停/降级）：
   - 有效性：…
   - 伦理：…
   - 隐私与数据安全：…
   - 可复现性：…

9. 预算
   - 计算上限：…；时间上限：…；检索次数上限：…；迭代轮数上限：…

10. 最小有意义改进与停止规则
    - 最小有意义改进（数值或语义定义）：
    - 停止规则：a) 达到最小有意义改进且稳定；b) 连续 N 轮无改进；c) 预算用尽；d) 闸门失败不可修复

确认与锁定：用户确认后本契约生效，本轮不得变更。
变更：任何要素改动 → 新版本契约（说明原因、影响、对预算与结论的含义）。
```

## 常见遗漏项（建契约时逐项自查）

- [ ] 非目标没写（范围会悄悄膨胀）
- [ ] 结局只写"指标"没写"时点与定义"（终点漂移温床）
- [ ] 数据源版本没固定（重跑结果对不上）
- [ ] 确认性/探索性没定位（结论语言没依据）
- [ ] 停止规则没写（预算耗尽的"再来一轮"）
- [ ] 隐私/伦理闸门空白（涉及患者数据时必须填写）
