# 孟德尔随机化

## 目标

给出一个**假设被逐条检查过**的 MR 结果：工具变量怎么选、三个假设各自怎么被数据支持、多效性怎么被识别与量化、结论的措辞该有多强。

## 三个假设（每一个都要单独回答"凭什么成立"）

1. **关联**：工具变量与暴露强相关。用 F 统计量（个体层面 `F = β²/SE²`，汇总层面近似 `F ≈ (β/SE)²`），**每个 SNP 的 F > 10**；弱工具变量会把估计拉向零并使 CI 失真。
2. **独立性**：工具变量与暴露-结局的混杂因素无关。人群分层（population stratification）、 assortative mating、家系效应都是威胁；用**同祖先人群**的 GWAS、检查 genomic control（λ）、必要时做家系内 MR。
3. **排他性**：工具变量只能通过暴露影响结局（**水平多效性**不存在）。这条不可直接检验，只能用设计（cis 变异优于 trans、生物通路合理性）与统计（MR-Egger 截距、MR-PRESSO、留一法）去**降低**风险，不能证明。

## 步骤

1. **选工具**：与暴露在全基因组显著（通常 p < 5e-8）、LD 剪枝（r² < 0.001，窗口 10 Mb）、剔除与结局直接相关的变异（若已知）、剔除回文变异或做链方向校正。记录**每个工具来自哪个 GWAS、人群、样本量**。
2. **检查样本重叠**：两样本 MR 中暴露与结局 GWAS 若有样本重叠，会引入偏倚（重叠越多，偏倚越大）。写明重叠情况；有重叠时做校正或改用无重叠数据。
3. **主分析**：IVW（随机效应，默认）。给出每个 SNP 的 Wald 比与森林图。
4. **稳健性**：
   - **MR-Egger**：截距显著偏离 0 提示方向性多效性（但功效低、且要求 InSIDE 假设）。
   - **加权中位数**：允许部分工具无效（<50%）。
   - **MR-PRESSO**：识别离群 SNP，给出剔除后的估计。
   - **留一法**：单个 SNP 是否驱动结论。
   - **Steiger 方向性检验**：确认因果方向是暴露→结局，而不是反过来。
5. **多效性搜索**：把工具变量放到**阴性对照结局**（不可能受暴露影响的结局）上跑一遍；若显著，记录并解释。
6. **报告**：按 STROBE-MR 清单；给出暴露与结局的 GWAS 来源（作者/年份/人群/n）、工具数、每个方法的估计（OR 或 β + CI）、以及"这个估计对应多大临床效应"的换算（例如每 1-SD 暴露的 OR）。

## 产出

- 工具变量表：SNP / 效应等位基因 / β_exposure / SE / p / F / 是否回文。
- 方法表：IVW、Egger（含截距）、加权中位数、PRESSO、留一法结论。
- 一段方向性与多效性的判断，以及**措辞**（"遗传预测的 X 与 Y 相关"而不是"X 导致 Y"）。

## 常见失败（逐条自检）

- [ ] 工具变量 F 统计量不报，或只报"总体 F"。
- [ ] 用与结局高度相关的变异（如 pleiotropic hotspot）当工具，不做敏感性。
- [ ] 只跑 IVW，结论写"因果成立"。
- [ ] 暴露与结局 GWAS 来自不同祖先人群却混用。
- [ ] 两样本 MR 未提样本重叠。
- [ ] 把"每 1-SD 遗传预测暴露"直接说成"干预降低暴露 1 SD 的效果"（MR 估计的是终生暴露，不能等同于短期干预）。
- [ ] 用 MR 结果替代 RCT 作为临床决策依据而不做等效性讨论。
