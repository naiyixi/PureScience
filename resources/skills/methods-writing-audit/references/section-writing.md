# 方法/结果章节写作骨架（按研究类型）

## 随机对照试验（对齐 CONSORT 要素）

**方法**：设计（平行/交叉/析因，单/多中心）→ 受试者（来源、纳入排除、招募时间窗）→ 随机化（序列生成方法、分配隐藏、实施者）→ 盲法（谁盲、如何验证破盲）→ 干预（剂量/疗程/对照/合并用药规则）→ 终点（主要/次要定义与测量时点）→ 样本量（α/功效/最小差异/SD 或事件率来源，失访加计）→ 统计方法（分析集定义 ITT/PP、主要分析、缺失处理、亚组与校正）→ 注册号与伦理。

**结果**：受试者流程（筛查→随机→各组完成/失访 n）→ 基线表 → 主要终点（组间差 + CI + p）→ 次要终点 → 危害/不良事件 → 敏感性分析。

## 观察性研究（对齐 STROBE 要素）

**方法**：设计一句话 → 设置与数据来源（含数据库名称与版本/时间段）→ 参与者（来源、纳入排除、匹配规则）→ 变量（暴露/结局/混杂定义与测量，含编码规则）→ 偏倚控制（如何防选择/信息偏倚）→ 样本量说明 → 统计方法（模型、协变量选择依据、缺失、敏感性分析）。
**结果**：参与者数与流程 → 基线（暴露组对比）→ 主分析（效应量 + CI）→ 分层/敏感性 → 亚组（探索性标注）。

## 系统评价/Meta（对齐 PRISMA 要素）

**方法**：检索（库名、检索式、日期——引用 literature-search-strategy 产物）→ 筛选与纳入标准 → 数据提取（双人独立？分歧处理）→ 偏倚风险评价工具 → 效应量与合并模型（固定/随机及选择理由）→ 异质性与发表偏倚方法。
**结果**：PRISMA 流程图数字 → 纳入研究特征表 → 偏倚风险总结 → 森林图（各研究+合并）→ 亚组/敏感性 → 发表偏倚评估。

## 通用写作要求

- 时态与语态：方法用过去时陈述已做之事；不给"将要"式残留（除非预注册引用）。
- 缩写首次出现给全称；变量命名正文/表/图一致。
- 把"做了什么分析"写在方法，把"分析得到什么"写在结果——两者边界不串。
- 结果段每段首句给主发现，后跟数值支撑；不写解释性评论（那是讨论的事）。
- 单位/转换规则在方法交代（含换算系数），结果直接用统一单位。
