# 数字一致性核对流程

> 核对顺序固定：**先锁流程数（n 链），再锁统计数（效应量/p），最后锁格式**。全部通过才放行。

## 1. 流程数闭合（n 链）

- 试验：`筛查数 → 随机数 → 各组随机数`；`随机数 = 完成数 + 失访 + 中止 + 排除分析`。
- 观察性：`来源总数 → 排除（按原因）→ 纳入 → 各分析集（完整案例/插补后）`。
- 每个排除原因给出数字；"其他"类占比过大（>10%）需说明。
- 每一处 n 变化都能在前一段找到对应说明（n 不能凭空消失或出现）。

## 2. 统计数一致

- 同一结果在多处出现（摘要/结果段/表/图）→ 均值、SD/SE、CI、p、n 完全一致。
- 表中 CI 与 p 逻辑自洽：CI 含无效值则 p 应 ≥0.05（方向一致前提下）——发现矛盾优先怀疑数据录入错。
- 图与表同源：同一森林图/柱状图的数字与表一致。
- OR/RR/HR 的小数与换算：风险差与相对风险不混写。

## 3. 格式与单位

- 同一指标精度全文统一（如血清肌酐统一到整数 µmol/L，别处不出现小数）。
- p 值：`p<0.001` 与 `p=0.032` 规则统一；不写 `p=0.000`。
- 单位统一（mmol/L 或 mg/dL 全文选一，换算在方法说明）。
- 百分号与 n 匹配：`12/40 (30%)` 格式一致。

## 4. 自动化辅助

- 若稿件附带数据/表格文件：用脚本抽数比对（如对每个"n=X"、"95% CI"做文本与数据文件交叉验证）。
- 无数据文件时：人工逐项核对并给核对记录（哪几处已核对/哪些数字无源可核需标出）。

## 常见陷阱

- 摘要里的数字是早期版本（改正文忘了改摘要）。
- 表格用了另一亚组的 n（复制粘贴错误）。
- 百分比四舍五入后合计 ≠100%（可接受但要说明，如"因舍入"）。
- 把中位数（IQR）与均值（SD）混排在同一比较句。
- 森林图 CI 与正文文字方向相反（保护性/危险性方向写反）。

## 审计输出

- 每条不一致给出：位置（摘要第 X 句/表 2 第 3 行/图 1B）、双方数值、建议以哪边为准（以数据文件/原始分析为准，不能以正文为准）。
- 无源可核的数字列出清单，交作者提供来源后再放行。
