# 方法与结果写作审计

## 目标

方法与结果章节的验收标准只有两条：**方法可复现**（给足信息别人能照做）、**结果无出入**（正文/表/图数字一致、陈述不超数据）。

## 方法段写作要点（按研究类型套报告规范要素）

- 通用骨架：设计概述 → 设置与时间 → 参与者/样本（纳入排除与来源）→ 干预/暴露/分组 → 终点与测量 → 样本量 → 随机化与盲法（实验）→ 统计方法 → 伦理与注册。
- 统计方法段必须覆盖：软件与版本、主要分析与敏感性分析、缺失处理、多重比较策略、显著性阈值——与 statistical-inference 的输出一一对应。
- 复现性自检：让"不认识作者的同行"按方法段能重跑；含关键参数（随访时长定义、测量时点、换算系数）不省略。
- 对齐的报告规范（作为要素清单使用，不逐条复制其条文）：随机对照 → CONSORT；观察性 → STROBE；系统评价 → PRISMA；诊断准确性 → STARD；动物实验 → ARRIVE。

## 结果段写作要点

- 顺序：受试者流程（筛选/纳入/排除，含各阶段 n）→ 基线特征 → 主要终点 → 次要/探索 → 敏感性/亚组（标注探索性）。
- 每个结果 = 数值 + 效应量 + CI（+p），与 statistical-inference 的报告格式一致。
- 正文不重复表格全部数字：写模式与关键值，细节进表。
- 负面/不显著结果同权呈现，不藏在补充材料。

## 数字一致性审计（逐项核对）

1. 同一指标在摘要/正文/表/图/补充材料中数值一致（n、均值、率、CI、p）。
2. 流程数字闭合：随机 n = 各组 n 之和 = 分析 n + 失访 + 排除（加减对得上）。
3. 表内小计与合计一致；百分比与 n 一致（25/40 不能写 62% 之类）。
4. 图与表同一数据点不冲突；误差棒语义（SD/SE/CI）在方法或图注中写明且全文一致。
5. 小数位统一（同一指标同一精度）；p 值写法统一（如 p<0.001 或 p=0.03 规则）。
6. 单位全文一致（正文与表用同一单位，或换算处注明）。

## 常见写作问题清单（审计命中即提出）

- 方法段缺软件版本/种子/缺失处理（不可复现）。
- 结果段写了方法段没定义的分析（方法-结果不对应）。
- "数据未显示"式省略关键阴性结果。
- 摘要数字与正文不符（摘要夸大优先查）。
- 事后分析不标注（探索性/事后必须明说）。
- 因果语言出现在观察性结果段（交 evidence-grading 校准）。

## 交付格式

逐节审计：判定（通过/需修改：定位到句/表/图 + 具体问题 + 改法）。数字不一致一律"必须改"级。
