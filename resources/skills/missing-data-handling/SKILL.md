# 缺失数据的机制与处理

## 目标

把"缺失"从一句"数据有缺失，已剔除"变成一份**可复查的报告**：缺失比例、缺失模式、机制假设、处理方法与敏感性分析。

## 第一步：描述，不要先填

1. **每个变量的缺失率**，按组分别报（暴露组 vs 对照组）。**组间缺失率不同**本身就是偏倚信号。
2. **缺失模式**：单个变量孤立缺失 / 成组缺失（同一份检验整套缺）/ 整段随访缺失。成组缺失往往指向流程（未开单、转院），不是随机。
3. **缺失与观测变量的关系**：把"是否缺失"当成一个二分类结局，用观测变量去预测它。能预测 → 不是完全随机缺失。

## 第二步：机制判断（只能假设 + 论证，不能检验）

| 机制 | 含义 | 处理 |
|---|---|---|
| MCAR | 缺失与任何变量（含未观测）无关 | 完整病例分析无偏，但仍损失效率 |
| MAR | 给定已观测变量后与缺失值无关 | 多重插补 / 逆概率加权 / 似然法 |
| MNAR | 与缺失值本身有关（如病情重者不测） | 需敏感性分析（delta 调整、模式混合模型），并说明无法从数据内识别 |

**关键**：MAR 与 MNAR 的区分**不能从数据检验**，只能靠领域知识与设计论证。写"经 Little 检验 p>0.05，故为 MCAR"是错的——该检验功效低，且不检验 MAR。

## 第三步：方法选择

- **完整病例分析**：仅在缺失极少（如 <5%）且机制可辩为 MCAR/MAR 时可用；必须在局限里写明并做敏感性。
- **单一插补**（均值/中位数/末次观测结转）：**会人为缩小方差、低估不确定性**。末次观测结转在纵向数据里会制造"平台期"，除特定注册研究惯例外不推荐。
- **多重插补（MI）**：默认选择。要点：
  - 插补模型要包含**结局变量**与所有分析变量（" congenial "模型）；不含结局会稀释关联。
  - 插补次数按缺失比例，通常 m ≥ 缺失百分比（如 20% 缺失 → m ≥ 20），或按 Rubin 规则以 FMI 定。
  - 插补后按 Rubin 规则合并；**报告 FMI 与相对效率**。
  - 不要对插补后的数据再做"逐步回归挑变量"（会破坏方差估计）。
- **逆概率加权（IPW）**：适合缺失与观测变量关系明确、且缺失率不太高的情形。
- **MNAR 敏感性**：delta 调整（把插补值整体平移 δ）、模式混合模型、或"最坏情况"边界。

## 产出

- 缺失率表（按组、按变量）。
- 缺失模式图（缺失矩阵或 UpSet）。
- 机制假设与理由（一段话，引用设计事实，不用检验下结论）。
- 处理方法与参数（m、插补模型变量清单、合并规则）。
- **至少一项敏感性分析**（不同 m、delta 调整、完整病例对比），并说明结论是否改变。

## 常见失败（逐条自检）

- [ ] "剔除含缺失的 132 例" 而不报这 132 例与保留者的差异。
- [ ] 用均值填补后照常报 p 值（方差被低估，p 偏小）。
- [ ] 插补模型里没有结局变量。
- [ ] 只插补一次（m=1）并称"多重插补"。
- [ ] 缺失率 40% 仍只做 MI，不做 MNAR 敏感性。
- [ ] 把 Little 检验当作 MAR 的证据。
- [ ] 分组缺失率差异明显（30% vs 8%）却不讨论选择偏倚。
