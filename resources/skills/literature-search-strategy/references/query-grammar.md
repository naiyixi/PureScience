# 数据库检索语法速查（PubMed / Embase / CENTRAL / 中文库）

> 用途：把检索式写到具体数据库时核对字段与算符。语法以各库现行官方帮助为准；给出通用骨架，遇到存疑算符先查库内帮助再交付。

## PubMed

- 字段标签：`[tiab]` 标题/摘要、`[Mesh]` 主题词、`[Mesh:noexp]` 不扩展下位词、`[pt]` 出版类型、`[la]` 语言、`[ti]` 标题、`[au]` 作者、`[dp]` 出版日期（如 `2020:2026[dp]`）。
- 主题词：`"Diabetes Mellitus"[Mesh]` 默认自动扩展下位词；需要精确到该词本身用 `[Mesh:noexp]`。
- 短语与自由词：`"cardiac arrest"[tiab]`；不加引号的词会被自动拆词。
- 截词：`therap*`（注意会截到 therapy/therapies/therapeutic…，需评估误检）。
- 邻近：`term1[tiab:~2] term2`（2 词以内相邻，顺序不限）。
- 布尔：`AND OR NOT` 大写；加括号分组。
- 排除 MEDLINE 重复：Embase 查完后在 PubMed 用 `NOT medline[sb]` 补查 PubMed 独有记录。
- 系统评价用 RCT 过滤：Cochrane Highly Sensitive Search Strategy（HSSS）是公开标准式，直接引用其 2008/2023 版本式样，不自创。
- 执行后记录：检索式、日期、命中数。

## Embase（Ovid/Elsevier 平台）

- 主题词为 Emtree（`/exp` 扩展、`/` 精确、`/mj` 主要主题），词表与 MeSH 独立——**每个概念必须在 Emtree 重新映射**。
- 字段：`.ti,ab.`（Ovid 语法）、`/de`、`/dm` 等。
- 药物相关检索可利用 Emtree 药物副主题（如 `/ae` 不良反应），属 Embase 特有优势。
- 与 PubMed 语法不互通；不得把 PubMed 式直接粘贴进 Embase。

## Cochrane CENTRAL

- 检索界面支持简单布尔与字段；Cochrane 库收录 RCT/临床试验记录为主，检索以自由词 + 有限的受控词为主。
- 常与 PubMed/Embase 结果合并去重；记录各库命中数供 PRISMA 流程图使用。

## 中文生物医学库（CBM / CNKI / 万方）

- CBM（中国生物医学文献库）：有主题词表（《医学主题词表》中文版），支持 `"词"[中文标题/摘要]` 式字段限定与布尔算符；中文同义词、简称（如 "乙肝"/"乙型肝炎"）要显式列出。
- CNKI：专业检索支持字段（`SU=` 主题、`TI=` 篇名、`AB=` 摘要）与 `AND/OR/NOT`（部分界面用 `* / + / -`）。
- 万方：支持主题/题名/关键词/摘要字段检索；算符兼容性以当前界面为准。
- 中文库不做英文主题词直译检索；中文疾病/药物名称、别名、俗称需在自由词里穷举（如 "慢阻肺/COPD/慢性阻塞性肺疾病"）。
- 平台检索式通常不可分享为稳定 URL——务必把完整检索式与日期存档进过程台账。

## 通用注意事项

- 短语、括号、截词在移植到另一库前逐项核对；同一布尔逻辑在不同平台对引号/通配符的解析不同。
- 记录每库"检索日期 + 检索式 + 命中数 + 去重后数"，四要素缺一不可复现。
- 检索式交付前做一次"自问自答"验证：已知 1-2 篇应命中的关键文献，把其关键特征代入检索式确认能命中（召回自检）。
