# 文献检索策略构建

## 目标

把一个研究问题转化为**可执行、可复现、可审计**的数据库检索式与检索计划，供循证证据综合、临床研究设计、真实世界证据研究等专家在检索执行环节直接使用。

## 输入与输出契约

- 输入：研究问题（一句话或 PICO/PECO 要素）；目标数据库（未指明则默认 PubMed + Embase + CENTRAL，中文研究另加 CBM）；灵敏度/精确度取向（系统评价默认高灵敏度）。
- 输出：
  1. 每库一份检索式（含主题词与自由词、字段/过滤器、日期与库名）
  2. 概念拆解表（每个概念：主题词、同义词、入口词）
  3. 检索执行单（库清单、每库的检索式、预计去重与记录要求）
  4. 过程台账（版本、日期、决策理由）

## 核心工作流

1. **澄清问题**：先确定研究类型（干预/诊断/预后/病因/定性）与框架（PICO/PECO/PEO/SPIDER）。要素缺失时逐项追问，不得替用户假设人群或干预。
2. **拆概念**：每个 PICO 要素成为一个概念组；排除研究类型限定词（RCT/队列等）作为独立过滤器而非概念组。
3. **选库**：按问题类型给默认库集并说明理由；罕见病/药物警戒类补查专业库（如毒理、药械注册库）。
4. **主题词 + 自由词双轨**：每个概念 = MeSH/Emtree（含下位词自动扩展，说明是否 explode）+ 自由词（标题/摘要字段 + 同义词/拼写变体/缩写）。中文库用 CBM 主题词与中文同义词，不机械照搬英文检索式。
5. **布尔组合**：概念内 OR，概念间 AND；需要排除时显式写出 NOT 并说明误伤风险。
6. **过滤与权衡**：默认不加语言/时间过滤（除非用户明确）；系统评价场景说明"高灵敏度优先，宁多勿漏"的取舍并提示去重负担。
7. **留痕**：输出每库检索式、检索日期占位、执行后需回填命中数与去重后纳入数。

## 检索式语言要点（速查，详见 references/query-grammar.md）

- PubMed：`("term"[MeSH Terms] OR term[tiab]) AND ...`；字段 `[tiab] [Mesh] [pt] [la]`；邻近 `A[tiab:~2] B`；截词 `*`；`NOT medline[sb]` 用于 Embase 补查；RCT 过滤用 Cochrane HSSS 高度敏感式（正当标准，无需自创）。
- Embase：主题词为 Emtree，词库与 MeSH 不同，须重新映射，不可照抄 PubMed 式。
- 中文库：CBM 用主题词（中图分类法医学主题词表），CNKI/万方支持主题/篇关摘字段与逻辑算符；注意各库算符差异（如 `*` 截词支持度）。
- 通用：短语加引号；注意单复数/英美拼写在自由词中显式列出（tumor/tumour）。

## 常见错误清单（自检用）

- 把研究类型限定词当概念组 AND 进去（过度限定漏检）。
- 只写自由词不写主题词（漏掉未用关键词表述的相关文献）。
- 不同库共用同一检索式（MeSH/Emtree 词表不同，必须逐库重映射）。
- 检索式未记录版本/日期就交付（不可复现）。
- 声称"已检索到 N 篇"——本技能只产出检索式与计划，执行结果必须来自真实检索。

## 交接语义

- 检索式执行 → 交给多库文献收集环节（连接器实际检索后回填命中数）。
- 产出纳入文献的质量评价 → 循证证据综合专家的评价环节，本技能不做。
- 若用户只问"怎么搜某主题"且不需要可执行检索式，给简要策略即可，不必输出完整执行单。
